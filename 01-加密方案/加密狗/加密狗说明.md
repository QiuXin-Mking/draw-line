# 加密狗（Hardware Dongle）说明

## 一、什么是加密狗

加密狗是一种 **USB 硬件密钥**，外形类似 U 盘，插在电脑上用于软件授权验证。软件启动时检测加密狗是否存在、是否合法，验证通过才允许运行。

核心价值：**软件可以随意复制，但没有加密狗就无法使用**，从而实现防盗版。

## 二、工作原理

```
┌──────────┐     USB 通信      ┌──────────┐
│  软件程序  │ ◄──────────────► │  加密狗   │
│ (客户端)  │   挑战-响应验证    │ (硬件密钥) │
└──────────┘                  └──────────┘
```

### 验证流程

1. **软件启动** → 调用加密狗 SDK，向硬件发送一个随机"挑战"数据
2. **加密狗内部** → 用烧录的密钥/算法对挑战数据进行加密运算，返回"响应"
3. **软件校验** → 验证响应是否正确，正确则放行，否则拒绝运行或进入演示模式
4. **运行中** → 定时重复验证（防止启动后拔掉加密狗）

### 关键技术点

| 机制 | 说明 |
|------|------|
| 挑战-响应（Challenge-Response） | 每次发送不同随机数，防止重放攻击 |
| 硬件唯一 ID | 每个加密狗有不可篡改的序列号 |
| 内部加密算法 | 算法烧录在芯片中，无法提取 |
| 存储区 | 可写入授权信息（到期时间、功能模块等） |
| 远程升级 | 部分品牌支持通过网络更新加密狗内的授权 |

## 四、本项目集成方案

根据 PRD，本项目（皮革排样软件）计划采用加密狗保护知识产权。

### 推荐选型：深思洛克 SenseIV

理由：
- C#/.NET SDK 成熟，与推荐技术栈匹配
- 国内购买方便，技术支持响应快
- 支持 Windows 桌面应用，文档齐全

### 集成步骤

```
1. 购买加密狗硬件（批量采购单价更低）
2. 安装厂商提供的开发工具包（SDK + 管理工具）
3. 在加密狗中烧录：加密密钥 + 授权参数（如有效期、功能级别）
4. 在软件中集成验证代码：
   ├── 启动时验证
   ├── 关键功能调用前验证
   └── 定时心跳验证（如每 5 分钟）
5. 验证失败处理：
   ├── 拒绝启动 → 提示插入加密狗
   └── 运行中断 → 保存当前数据后退出 / 进入只读模式
```

### 代码集成示例（伪代码）

```csharp
// 启动时验证
bool isValid = DongleSDK.Verify(
    vendorCode: "xxxx-xxxx-xxxx",
    featureId: 1  // 功能模块编号
);

if (!isValid) {
    ShowMessage("请插入有效的加密狗");
    Exit();
}

// 运行中定时验证
Timer.Every(5.Minutes, () => {
    if (!DongleSDK.Heartbeat()) {
        SaveCurrentWork();
        ShowMessage("加密狗已移除，软件将在 30 秒后退出");
        Exit(30.Seconds);
    }
});
```

## 五、加密狗的优缺点

### 优点

- 防盗版效果好，硬件级保护难以破解
- 可以控制授权数量（卖多少狗 = 卖多少套）
- 支持灵活的授权模式（试用、按年、永久、按功能模块）
- 客户感知明确——"买软件 = 收到一个硬件"

### 缺点

- 硬件成本（每个 20-100 元）
- 物流成本（需要快递给客户）
- 客户可能遗失或损坏加密狗
- USB 口占用（笔记本用户可能介意）
- 存在被模拟破解的风险（高级攻击者）

## 六、替代方案对比

| 方案 | 安全性 | 成本 | 用户体验 | 适用场景 |
|------|--------|------|---------|---------|
| **加密狗** | 高 | 中（硬件） | 需插 USB | 工业软件、高价软件 |
| **在线激活 + License** | 中高 | 低 | 好 | SaaS / 联网软件 |
| **机器码绑定** | 中 | 低 | 好 | 中小软件 |
| **混合方案（加密狗 + 在线验证）** | 最高 | 高 | 一般 | 大型企业软件 |

## 七、本项目建议

1. **Phase 1（当前）**：先用加密狗做基础保护，快速上线
2. **Phase 2**：加入代码混淆（如 .NET 用 ConfuserEx）增加反编译难度
3. **Phase 3**：考虑混合方案，关键算法做服务端验证

> 加密狗不是万能的，但配合代码混淆 + 法律手段（软件著作权），可以形成足够的保护屏障。
