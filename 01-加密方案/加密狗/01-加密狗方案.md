# 加密狗方案调研

> 调研时间：2026-08-07 | 项目：Windows 皮革排样软件

## 一、加密狗怎么卖的

### 商业模式

```
开发者注册 → 购买开发套件 → 集成SDK → 批量采购用户锁 → 随软件发给客户
```

1. 在加密狗厂商平台**注册为软件开发者**
2. 购买**开发套件**（含 1 把控制锁 + N 把测试用户锁）
3. 获取**定制 SDK**（每家开发者的锁都是唯一的，别人的锁插上也无效）
4. 集成到软件中：启动时/定时检查 USB 口有没有你的锁
5. 软件发布后，按需**批量采购用户锁**，每卖一套软件配一把锁

## 三、加密狗的局限性

加密狗能确保"没有锁不能运行"，但**不能阻止**：

| 攻击方式 | 说明 |
|----------|------|
| 锁物理传递 | 同一把锁在多台机器间拔插使用 |
| 内存 dump + 绕过 | 找到检查点，直接跳转/修改判断逻辑 |
| 代码反编译 | Python 字节码极易反编译，去掉检查代码只需几分钟 |
| 虚拟机破解 | 将软件放在 VM 中，锁直通 VM，拷贝整个 VM |

**应对措施：**
- 代码必须编译为机器码（C# IL 加混淆、或 C++ native），不能纯 Python
- 关键算法逻辑分散在多个检查点，绕过一处不足以解锁
- 结合硬件指纹做二次验证
- 加壳（如 VMProtect、Themida）防反编译

## 四、替代方案——不用物理加密狗

### 方案 A：硬件指纹绑定（零硬件成本）

```
安装时：采集 CPU 序列号 + 主板序列号 + 硬盘序列号 → 生成唯一机器码
激活时：用户发机器码给开发者 → 开发者用私钥签名 → 返回激活码
运行时：校验机器码与激活码是否匹配
```

| 优点 | 缺点 |
|------|------|
| 零硬件成本 | VM 可伪造硬件指纹 |
| 不需要 USB 口 | 换硬件需要重新激活 |
| 用户无感知 | 比加密狗容易被破解 |

### 方案 B：离线 License 文件（参考 r-license 方案）

- Ed25519 非对称签名，开发者持有私钥
- License 文件绑定：硬盘序列号 + 系统 GUID + MAC 地址 + 过期时间
- AES-GCM-SIV 加密，防篡改
- 反时钟回滚检测（防用户改系统时间绕过过期）
- 防 VM/容器检测
- 完全离线，零网络依赖

### 方案 C：CodeMeter CmAct（商业软件锁）

德国 Wibu 的方案，用软件容器（绑定机器指纹）代替物理加密狗：
- 与物理加密狗同等级安全
- 纯软件，不需要 USB 设备
- 适合 OEM 大批量分发
- 价格高于国产加密狗

### 方案 D：在线激活 + 离线宽限期（推荐 ⭐）

**前提：** 允许机器首次激活时联网，之后周期性联网校验。

**流程：**

```
首次安装 → 用户输入激活码 → 联网验证 → 服务器签名授权文件 → 本地离线使用
之后每隔 30 天 → 后台静默联网校验一次 → 刷新授权 → 继续使用
如果断网超过 60 天宽限期 → 功能降级（只能查看，不能导出/排样）
```

**技术实现：**

```
┌─────────────────────────────────────────────────────┐
│  用户安装软件                                          │
│  ↓                                                    │
│  软件采集机器指纹（CPU+主板+硬盘序列号+MAC）              │
│  ↓                                                    │
│  用户输入激活码 → HTTPS 发到你的服务器                    │
│  ↓                                                    │
│  服务器校验：激活码是否有效？剩余激活次数？                 │
│  ↓                                                    │
│  服务器用你的 Ed25519 私钥签名：                          │
│    机器指纹 + 到期时间 + 功能权限 + 签发时间戳              │
│  ↓                                                    │
│  返回签名授权文件 → 存到本地加密存储                       │
│  ↓                                                    │
│  之后每次启动：校验授权文件签名 + 机器指纹是否匹配            │
│  ↓                                                    │
│  后台线程每隔 30 天尝试联网刷新授权                        │
│  ↓                                                    │
│  超过 60 天未刷新 → 功能降级（只能查看，不能导出/新建排样）   │
│  超过 180 天未刷新 → 拒绝运行，提示重新激活               │
└─────────────────────────────────────────────────────┘
```

**与加密狗的对比：**

| 维度 | 加密狗 | 在线激活方案 |
|------|--------|------------|
| **你的成本** | 20-200 元/把 | **0 元/套** |
| **防盗版** | 锁丢了客户可插到别的机器 | 授权绑定机器，换机器要重新激活 |
| **防超用** | 一把锁没法限制装几台 | 一个激活码只能用 N 次，次数用完拒绝 |
| **续费控制** | 一次性卖断，续费靠自觉 | 授权到期自动降级，想继续用得续费 |
| **追踪能力** | 不知道谁在用、用多久 | 激活记录、使用频率、机器信息全掌握 |
| **丢失/损坏** | 补锁要发快递，客户停工等 | 在线自助重置，秒级完成 |
| **客户体验** | 插 USB 设备，可能丢、可能不识别 | 激活一次，无感知 |
| **多机器** | 换一台拔过去就行 | 每个激活码绑定一台机器 |

**你的服务器成本：**

| 项目 | 费用 |
|------|------|
| 云服务器（阿里云/腾讯云轻量 2C2G） | **~50-100 元/月** |
| 域名（可选） | **~50 元/年** |
| SSL 证书（Let's Encrypt） | **免费** |
| 激活接口开发（C# WebAPI + SQLite） | **一次性开发成本** |

**一年不到 1500 元，对比发 100 个客户加密狗要 2000-20000 元。**

**安全增强（可选叠加）：**

| 措施 | 作用 |
|------|------|
| 授权文件 AES 加密存储 | 防止用户直接修改授权内容 |
| 时钟回滚检测 | 防止用户改系统时间绕过过期 |
| 多机器指纹交叉验证 | 防止 VM 伪造单个指纹 |
| 激活码 + 机器指纹双重绑定 | 换机器必须先在线解绑 |
| 激活频率限制 | 防止一个激活码短时间大量尝试 |

**为什么适合工厂场景：**
- 排样软件通常在**办公室/技术科电脑**使用（联网条件好）
- 即使车间偶尔断网，60 天宽限期足够覆盖任何停产检修周期
- 老板能看到"谁在用、用了多久"，便于内部管理

## 五、最终推荐：方案 D（在线激活）为默认，加密狗为溢价选项

### 分层保护策略

| 层级 | 方案 | 目的 | 成本 |
|------|------|------|------|
| **第 1 层** | C#/.NET 编译 + 代码混淆（ConfuserEx/Obfuscar） | 提高反编译门槛 | 免费 |
| **第 2 层** | 在线激活 + 硬件指纹 + 授权文件签名 | 控制使用权限，追踪客户 | 服务器 50-100 元/月 |
| **第 3 层** | 关键算法分散 + 多检查点 | 防止单点绕过 | 开发成本 |
| **第 4 层（可选）** | 加壳（VMProtect/Themida） | 防专业逆向工程 | ~2000 元/套 |
| **溢价选项** | 加密狗（域天/深思） | 给"必须完全离线"的高端客户 | 20-200 元/把 |

### 分阶段执行

1. **内测阶段**：在线激活方案（第 1-3 层），零额外成本
2. **正式商用**：在线激活为主，客户无感知
3. **大客户/离线客户**：提供加密狗版本，价格上浮（覆盖加密狗成本）
4. **高价值版本**：加壳保护

### 对皮革排样软件的建议：分层保护

| 层级 | 方案 | 目的 |
|------|------|------|
| **第 1 层** | C#/.NET 编译 + 代码混淆（如 ConfuserEx、Obfuscar） | 提高反编译门槛 |
| **第 2 层** | 加密狗（域天或深思，20-100 元/套） | 物理密钥，防止未授权运行 |
| **第 3 层** | 关键算法分散 + 多检查点 | 防止单点绕过 |
| **第 4 层（可选）** | 加壳（VMProtect） | 防逆向工程 |

### 分阶段执行

1. **开发/内测阶段**：硬件指纹绑定（零成本快速验证）
2. **正式商用阶段**：采购加密狗，配发给付费客户
3. **高价值客户**：加密狗 + 加壳双重保护

### 为什么加密狗对工厂客户反而是加分项？

- 中国工厂场景，一把物理锁 = "专业的正版软件"
- 心理层面：花了几万块买的软件，有一把锁更觉得"值"
- 实操层面：工厂电脑通常不联网、USB 口充裕、专人保管
- 丢了补锁收费（又是一笔收入）
