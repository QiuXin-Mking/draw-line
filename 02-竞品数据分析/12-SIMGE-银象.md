## 产品线

根据公开信息，SIMGE 主要做两大类产品：

| 产品 | 说明 |
|------|------|
| **智能画线机** | 在皮革上自动投射/绘制裁片轮廓和切割线，替代人工划线 |
| **智能裁切机** | 按画线路径自动切割皮革 |

**技术推测**：画线机工作原理可能是：
1. 上位机软件导入裁片 DXF → 排样 → 生成画线路径
2. 通过投影仪将排样结果投射到皮料上
3. 工人沿投影线手动裁切，或连接自动切割机

## 为什么 SIMGE 是核心对标对象？

### 证据链

```
你的项目名叫 "划线软件-叔叔"
你的竞品数据在    "划线/" 目录
竞品DXF文件名     38.DXF ~ 45.DXF（鞋码）
SIMGE的产品叫     "智能画线机"（画线=划线）
SIMGE所在行业      鞋业制造
```

→ 几乎可以确定，`划线/38-45.DXF` 就是 SIMGE 画线机输出的排样划线文件。

### 竞品 DXF 输出特征（已分析）

```
格式: POLYLINE（R10 旧格式）
图层: 仅 '0' 层
内容: ~39-40 个闭合多边形（裁片轮廓）+ ~42-44 个开放路径（画线走刀路径）
标注: 无文字、无标签、无利用率
尺寸: 约 290-330 × 870-960mm（随鞋码递增）
输出: 每个鞋码独立一个 DXF 文件
```

### SIMGE 软件的功能推演

基于其 DXF 输出反推，SIMGE 的上位机软件至少具备：

1. **裁片导入**：支持导入鞋面裁片的 DXF 轮廓
2. **尺码管理**：支持 38-45 共 8 个鞋码
3. **排样引擎**：在给定的皮革区域内自动排布裁片（每张皮约 39-40 个裁片 ≈ 4-5 双鞋）
4. **画线路径生成**：生成开放路径（切割工具的运动轨迹）
5. **DXF 导出**：输出为 R10 POLYLINE 格式，直接被画线机读取

**不具备的功能**（至少 DXF 中没有体现）：
- 利用率报告
- 裁片标注/标签
- 图层管理
- 可视化预览
- 订单数量管理

## SIMGE 的优劣势分析

### 优势
- **软硬一体**：软件 + 画线机 + 切割机，客户一站式采购
- **行业深耕**：香港鞋业商会会员，有鞋厂客户基础
- **价格优势**：相比 Zünd/Lectra 等国际品牌价格低得多，适合国内中小鞋厂
- **简单直接**：功能聚焦在"能画线就行"，不追求花哨

### 劣势
- **网上信息极少**：连产品详情页都搜不到，品牌建设和市场推广弱
- **软件体验可能较为原始**：从 DXF 输出看，没有标注、没有分层、没有报表——可能是"能用就行"的水平
- **只支持旧 DXF 格式**：R10 POLYLINE 而非 R2000+ LWPOLYLINE
- **没有可视化**：纯切割路径，没有 PNG 预览
- **可能只绑定自家硬件**：不开放给第三方切割机

## 对我们的关键启示

### 1. SIMGE 的产品逻辑很简单

他们的软件极有可能就是：
```
导入裁片 DXF → 选择鞋码 → 排样 → 生成画线路径 → 输出 DXF → 传给画线机
```

没有多余的"高级功能"——这说明软件的**门槛可能比想象中低**。如果我们能做出比 SIMGE 更好的排版效果 + 更现代的 UI + 更丰富的输出，完全有机会取代它。

### 2. 竞品 DXF 的开放路径是关键

最需要搞清楚的是那 ~42 个开放路径的生规则：
- 它们是否优化过刀头移动路径（最短路径问题）？
- 是否包含进刀/退刀动作？
- 是否关联特定切割机型号？

### 3. 我们能做的比 SIMGE 更好

| 维度 | SIMGE（推测） | 我们可以做 |
|------|-------------|----------|
| DXF 格式 | R10 POLYLINE | R2010 LWPOLYLINE |
| 图层 | 仅 0 层 | 裁片/皮料/标注 分层 |
| 利用率 | 无 | 可视化利用率 + 报表 |
| 标注 | 无 | 裁片编号 + 角度标注 |
| 预览 | 无 | PNG 实时预览 |
| 订单模型 | 无（推测） | 支持数量配比 |
| UI | 推测较为简陋 | Avalonia 现代 UI |
| 授权保护 | 绑定硬件 | 在线激活，更灵活 |
| 价格 | 捆绑硬件 ¥数万-几十万 | 纯软件 ¥2000-5000 |
