# Comelz Caligola-4 — 意大利鞋业 CAD

> 来源: vulongeng.com, comelz.com | 国家: 意大利

## 公司概况

Comelz 是意大利老牌鞋业 CAD/CAM 厂商，Caligola 是其鞋业设计软件，已迭代到第四代。在意大利和中国都有用户基础。

## Caligola-4 核心功能

### 图案设计
- 从数字化仪、图像、DXF/PDF/HPGL/PAT/SHOE 多种格式导入
- 半透明叠加、多色共享线、抗锯齿滤镜、自动标签

### 级放（Grading）
- 复杂级放规则：靴子、软皮鞋、凉鞋、鞋带、鞋跟、Logo
- 支持自定义参数

### 排样（Caligola NP 模块）
- 自动排样优化材料使用
- 直接驱动切割绘图仪
- 导出 PDF、HPGL

### 数据管理
- 材料、配件、工艺数据库导入/导出
- PDM 集成

### 输出格式
- DXF、XML（Assomac 标准）、PDF、HPGL

## 关键启示

1. **鞋业专用 CAD 是排样的上游**：Caligola 的用户是在 CAD 里设计鞋面 → 直接排样 → 切割，一站式工作流
2. **Assomac 标准**：鞋业专用的 XML 数据交换格式，国内用得少但国际是标配
3. **级放是鞋业 CAD 基本功**：一个鞋款要放 7-8 个尺码，级放速度和精度决定效率

## 对我们 Phase 1 的参考价值

- **低**。Caligola 是完整的鞋业 CAD，排样只是其中一个模块。但它的级放 + 排样一体化设计思路值得参考。
