## 三、技术路线深度分析

### 3.1 AI 识别与视觉方案

GBOS 在 ITS 系列中采用了自研的 **AI VisionScan（SCCD）** 视觉系统，核心特征如下：

- **深度学习大模型**：GBOS 宣称使用自研深度学习 AI 大模型，可"一键提取皮革轮廓与瑕疵"，无需人工调整参数。支持多种皮革类型和多种瑕疵标记颜色（不同颜色的粉笔/标记）。
- **框架推测**：官方未公开深度学习框架。从行业惯例和自研大模型的表述推断，大概率基于 PyTorch 或 TensorFlow 的底层框架，上层使用自研网络架构。考虑到工业部署环境（Windows + 本地化运行），推理侧可能使用 ONNX Runtime 或 TensorRT 做模型优化。
- **视觉硬件**：4000万像素高清工业相机（双摄）。相机品牌未披露。从像素规格推断，可能使用 Sony IMX 系列传感器或国产方案（如海康机器人、大恒图像）。
- **LCCD 动态视觉**：低端机型使用 LCCD 相机支持动态捕捉，两个摄像头可独立工作识别不同皮革。
- **SCCD 超相机**：高端机型搭载 SCCD 系统，支持更快图像采集和加速处理速度。
- **投影预览定位**：部分机型配备投影仪，将排版结果实时投影到皮革上，操作员可直接在皮料上看到排版效果并手动插入裁片。

**值得注意的关键技术点：**
- 自研 + 欧洲团队联合开发，号称有"30年算法优化经验"
- 轮廓提取时间：<5秒
- 支持皮毛走向识别（ITS3特色功能），这对真皮排版是一大技术难点
- 最多支持16个分区，按A/B/C/D等级自动排版

### 3.2 排样算法

- **自研排版引擎**：GBOS 强调其排样算法为自主研发，支持多种排样策略：
  - 0间距排版（zero-pitch nesting）
  - 成对排版（paired-double）
  - 超长排版（extra-long）
  - 分区排版（partition nesting）
  - 混合排版（mixed nesting — 多部件按设定数量混排）
  - 颜色匹配排版（color-matched — 适用麂皮）
  - 皮毛方向排版（hair-direction — ITS3特色）
- **多张皮同时排版**：支持多张皮革不间断连续排版
- **超级算法服务器**：ITS3 可配置超级算法服务器，1套系统配3套以上切割机
- **手动干预 + 自动融合**：允许操作员手动调整排版方案，系统自动重新计算利用率

**算法能力评估：**
- 利用率 >=85% 在行业中处于较高水平，但并非顶尖（行业领先者可达90%+）
- "50% speed improvement"的宣称暗示这是近期的架构重构
- "30 years of algorithm optimization"的说法强烈暗示其核心团队有来自欧洲排样软件公司的背景

### 3.3 软件开发框架推测

官方未公开具体开发技术栈。基于产品特征推断：

| 层面 | 推断 | 依据 |
|------|------|------|
| **UI层** | C#（WinForms/WPF）或 C++（Qt） | Windows平台、工业触摸屏交互、DXF/PLT格式支持 |
| **Vision SDK** | 自研（SCCD/LCCD）或基于 Halcon/OpenCV 二次开发 | 工业视觉的通用技术路线 |
| **排样引擎** | C/C++ | 计算密集型，需要极致性能 |
| **AI推理** | ONNX Runtime / TensorRT | 本地Windows部署，需要硬件加速 |
| **数据库** | 本地 SQLite 或 SQL Server Express | 单机部署，OEE数据看板需要数据持久化 |
| **通信** | IoT Bridge 平台（自研），支持 REST API | 官方宣布免费API开放兼容 |

**二次开发能力：** GBOS 已推出 IoT Bridge（桥）平台，宣称面向全球制造企业"免费API开放兼容"。这意味着：
- 有基础的 API 层，可对接 MES/ERP 系统
- 第三方设备可通过 API 接入其 ANALYTICS 系统
- 但 SDK 文档是否完善、API 粒度是否足够，目前存疑


## 七、UI 使用方式与用户体验

### 7.1 操作流程

根据抖音演示视频及官网描述，典型操作流程如下：

```
步骤1：铺皮 → 将整张皮革铺在排版台上
步骤2：拍摄 → 双高清相机自动扫描，5秒内完成轮廓提取
步骤3：标记 → AI自动识别瑕疵和等级分区（支持人工补标）
步骤4：排版 → 系统自动排样，投影预览到皮面
步骤5：微调 → 操作员在触摸屏上手动干预调整
步骤6：打印 → 排版完成后打印条形码，贴在皮料背面
步骤7：切割 → 将皮料移至切割机，扫码自动匹配排版数据
步骤8：收料 → 全皮回传装置自动收取切好的裁片
```

### 7.2 交互方式

| 交互方式 | 支持情况 |
|----------|----------|
| **触摸屏** | 核心交互方式，用于手动排片调整 |
| **键盘鼠标** | 标准PC操作 |
| **投影预览** | 排版结果实时投影到皮革上，所见即所得 |
| **条形码/QR码** | 排版数据与皮料通过条码绑定，无缝流转至切割工序 |

### 7.3 OEE 数字看板

ITS5 配备了 OEE（Overall Equipment Effectiveness）数字看板，提供：
- 设备综合效率可视化
- 生产数据透明度
- 历史利用率追踪

### 7.4 用户体验评估

**优势：**
- "一键"操作理念（一键提取轮廓、一键排版），降低学习门槛
- 视觉反馈丰富（投影+屏幕+看板）
- 手动干预功能灵活，老师傅的经验可以最大化利用率
- 支持24小时连续作业

**可能的不足（基于用户反馈缺乏推断）：**
- Windows 工控机 + 触摸屏的组合在工业环境中可靠性需要关注
- 超级算法服务器额外占用空间和成本
- 软件升级可能依赖厂商远程服务（行业通病）
- 第三方设备接入是否如宣传般顺畅，有待验证

## 九、关键洞察与战略启示

### 9.1 技术层面

- GBOS 的核心壁垒在于 **AI视觉 + 排样算法 + 切割控制的垂直整合**，而非单一技术点
- "自研深度学习大模型"是营销语言，实际更可能是基于开源框架的定制模型
- Super Server 的架构意味着排样算法仍有性能瓶颈，需要专用硬件加速
- 4000万像素相机在2025年已不稀奇，关键是图像处理pipeline的工程优化

### 9.2 商业层面

- **硬件+软件捆绑**是主流模式，软件难以单独销售盈利
- 54%的毛利率说明软件价值已被pack进硬件价格
- 真正的recurring revenue来自耗材（刀片）和维护合同，而非软件授权费
- 出海是增长核心驱动力——跟随鞋业/汽车供应链向东南亚转移

### 9.3 值得关注的趋势

- 汽车内饰（尤其是新能源车）对真皮座椅的需求可能催生新一轮设备采购
- 纯软件排版SaaS（不绑定硬件）可能成为搅局者
- 计算机视觉的进步（SAM、YOLO等）可能让排样算法门槛持续降低
- 国产替代趋势下，国内竞品之间的竞争将加剧

### 9.4 对友商的参考价值

如果你在做类似的智能排版软件产品，需要重点关注的维度：

1. **视觉识别精度和速度**：这是用户感知最强的技术指标
2. **利用率**：85%是及格线，90%+是竞争优势
3. **操作简便性**："一键"体验 + 手动干预的灵活性
4. **上下游集成**：能否与主流切割机品牌对接
5. **数据管理**：OEE看板、条码追踪、MES对接
6. **定价策略**：GBOS 的硬件绑定模式意味着如果你只做软件，需要找到差异化的价值主张
