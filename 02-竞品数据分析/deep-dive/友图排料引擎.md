## 二、技术路线

### 2.1 编程语言与开发环境

| 维度 | 详情 |
|------|------|
| **核心语言** | C++11 |
| **编译器** | VS 2017 Community (MSVC)，可选 Mingw/GCC |
| **核心库** | yotu.dll（Windows），理论上可编译为 Linux .so |
| **接口风格** | C 风格导出函数，便于各语言（C#/Python/Java 等）通过 FFI 调用 |
| **多线程** | Windows 使用 win32 线程，Linux 使用 pthread，未使用 C++11 std::thread |
| **第三方依赖** | 仅 Clipper（开源，用于源数据预处理如 offset）；引擎内核无第三方依赖 |
| **坐标精度** | Point2F 浮点结构，小数点后3位有效数字 |

### 2.2 排样算法方案

友图引擎采用的是**基于重叠移除（Overlap Removal）的不行解法**，核心算法组合包括：

- **重叠移除算法（Overlap Removal）**：核心引擎，动态调整裁片位置逼近利用率理论极限
- **BLF 算法（Bottom-Left-Fill）**：经典排料启发式
- **捕食搜索（Predatory Search）**：元启发式搜索策略
- **非线性优化**：针对排料问题的数学优化
- **贪婪算法 + 匹配算法**（新版）：突破大规模排料关键技术瓶颈

**算法特点**：
- 中小规模排料对比国际顶级引擎（AutoNester、Gemini、ShapeShifter、NestFab）有较明显优势
- 对服装领域的避色差、对格对条等特殊需求原生支持（本质是分区排料）
- 明确不采用 GPU 像素/扫描线方式，以保证高精度和大规模运算能力

**真皮排料特有算法支持**：
- 自由排料（不规则形状皮料）
- 带瑕疵排料（标记瑕疵区域并自动避开）
- 5 档优先级控制（0-4 级）
- 部件成双（强制裁片成双排入，解决色差/皮质差异问题）
- 子区域排料（按质量分区依次调用引擎）

### 2.3 AI 视觉集成

**未发现友图引擎集成 AI 视觉功能**。搜索"友图 真皮 排料 AI 视觉 瑕疵 识别"等关键词均无结果。

友图的瑕疵处理方式是**人工标记瑕疵区域后，由排料引擎自动避开**，而非通过 AI/计算机视觉自动识别皮革瑕疵。这与力克（Lectra）等国际高端方案形成差异——后者往往集成扫描仪+视觉系统实现自动化瑕疵检测。

### 2.4 DXF 处理方案

- **支持导入**：DXF 和 ESI 两种格式
- **DXF 图元支持**：Line、Polyline、Arc（**不支持 Curve 曲线类型**）
- **数量识别**：通过文件名括号标识，如 `202003(8).dxf` 或 `202003{8}.dxf` 表示 8 个
- **合并规则**：No Merge（默认）/ Merge By R0（相同合并）/ Merge By R180（旋转180度相同合并）
- **预处理**：使用 Clipper 库处理 offset 等几何操作
- **要求**：零件轮廓/内孔必须封闭且无自交，否则程序可能崩溃
- **关于导出**：公开资料未明确提及排料结果导出为 DXF 的功能，项目保存格式为 `.gnf` 专有格式

## 三、软件框架

### 3.1 产品形态

友图排料引擎**既是独立桌面软件，也是 SDK/库**：

- **独立软件**：YotuNester 桌面应用，面向最终用户（工厂），提供完整 GUI 操作界面

## 六、UI 与使用方式

### 6.1 软件界面

YotuNester 桌面软件采用**四 Tab 页布局**：

| Tab | 功能 |
|-----|------|
| **Import（导入）** | 导入 DXF/ESI 数据源文件，设置合并规则 |
| **Pieces（样片/部件）** | 编辑每个样片的个数、旋转角度/步长、数据源单位（mm/cm/inch）、间距 |
| **Nester（排料）** | 添加矩形板材，设置 LRBT 边距、排料模式（阵列/混排）、排料时间，实时查看结果 |
| **About（关于）** | 公司信息 |

### 6.2 操作流程

```
导入 DXF/ESI → 编辑样片属性 → 设置板材 → 选择排料模式 → 运行排料 → 查看结果
```

1. 导入数据源文件（支持 DXF 和 ESI）
2. 在 Pieces 页编辑样片参数（数量、旋转、单位）
3. 在 Nester 页添加矩形板材，设定尺寸和边距
4. 选择排料模式（阵列/混排），设定排料时间
5. 点击开始，实时查看排料结果（利用率、板材数、未放入零件数）
6. 结果列表中可对比多次运行结果，选择最优方案
7. 保存为 `.gnf` 项目文件

### 6.3 排料模式

- **阵列模式（Lattice）**：适合每种零件个数较多的情况，速度快
- **混排模式**：适合零件种类多、每种个数少的小规模测例，利用率更高

### 6.4 交互体验特点

- 实时更新排料视图，可视化展示排料过程
- 支持多次运行结果对比
- 支持框选批量编辑样片属性
- 支持缩放查看排料图细节

### 6.5 SDK 使用方式（面向开发者）

对于二次开发集成场景，直接调用 yotu.dll 的 C 风格 API，流程为：

```
初始化引擎 → 导入样片数据 → 设置材料参数 → 配置排料参数 → 运行排料 → 获取结果
```

详细 API 文档在 CSDN 博客《友图自动排料引擎 V1.0 开发指南》（2020年1月发布）中有说明。

## 八、竞品定位与优劣势

### 8.1 竞品版图

| 层级 | 代表产品 | 价格区间 |
|------|----------|----------|
| **国际一线** | AutoNester（德国）、NestFab（英国）、Gemini（罗马尼亚）、ShapeShifter（新西兰）、Lectra/力克（法国）、SigmaNest | ¥30,000-100,000+ |
| **友图** | YotuNester | ¥3,000-10,000 |
| **国内其他** | SmartNest、和鹰、青鹤（引擎来源不确定） | 不详 |

### 8.2 友图优势

1. **利用率比肩国际一线**：在小规模排料上甚至略有超越
2. **价格优势明显**：约为 NestFab 的 10%-30%
3. **真皮排料专门优化**：瑕疵避让、成双、优先级、子区域等真皮特有功能
4. **完全自研**：引擎内核无第三方依赖，可控性高
5. **提供 SDK**：面向 CAD 厂商二次开发，支持 C 风格 API
6. **持续迭代**：从 2020 年 V1.0 至今持续更新，2024 年仍有版本更新

### 8.3 友图劣势与风险

1. **公司规模极小**：注册资本 50 万（实缴 0），单人公司，抗风险能力弱
2. **无 AI 视觉集成**：瑕疵仍需人工标记，与国际高端方案（力克等）有差距
3. **无公开客户案例**：搜索不到任何具名客户，信任度打折扣
4. **格式支持有限**：DXF 不支持 Curve 曲线，导出功能不明确
5. **操作系统覆盖窄**：Windows 为主，Linux 支持有限，macOS 仅理论可行
6. **文档与社区薄弱**：技术文章主要由创始人个人在 CSDN/知乎发布，无正式文档站或开发者社区
7. **联网依赖**：Demo 需联网运行，可能暗示在线激活机制
8. **真皮排料缺乏视觉方案**：真皮瑕疵检测+排料的一体化自动化方案缺失
