## 二、技术路线分析

### 2.1 Diamino 排料引擎

#### 核心算法思路

Diamino 是 Lectra 的传统强项，经过 30+ 年迭代，其排料算法属于 **启发式 + 几何优化** 混合路线：

- **交互式排料（Interactive）**：操作员手动拖拽摆放裁片，系统提供碰撞检测、吸附对齐、旋转翻转等辅助。这种模式在高端定制、小批量复杂款式中仍是主流。
- **全自动排料（Automatic）**：基于 DRL（Diamino Rapid Layout）算法，对裁片进行几何匹配和全局优化。系统生成多个排料方案，按面料利用率排序供用户选择。
- **批量云端排料（Quick Nest）**：将排料任务分发至 Azure 云端并行计算，可同时处理数十个 Marker 列表。

#### 关键特性

| 特性 | 说明 |
|------|------|
| 内部刀口保护 | 仅对内部 Notch 区域做保护间距（非全局），兼顾排料效率和裁片质量 |
| 融合块排料（Fuse Block） | 自动识别并组装需要热熔衬的裁片组合，大幅减少手工操作 |
| 面料方向约束 | 支持单向/双向/无方向等多种纹理约束 |
| 条格对位 | 支持条纹和格纹面料的自动对条对格 |
| 多尺码混排 | 一个 Marker 内混合多个尺码，最大化面料利用率 |

#### DRL 算法的技术推测

公开信息未披露 Diamino 的具体算法实现，但综合行业观察可做以下推断：

- 底层极大概率基于 **C++** 编写（性能密集型计算），核心几何库采用 Polygon Boolean Operations 和 No-Fit Polygon（NFP）方法
- 排料策略采用 **Bottom-Left-Fill** 启发式 + 模拟退火/遗传算法进行全局优化
- Quick Nest 的云端并行架构基于 **任务分片（Sharding）**——将 Marker 列表拆分为独立任务，分发到多个容器实例并行运算，最终汇总结果

### 2.2 皮革排样特殊算法

皮革排样与面料排样有本质区别：

| 区别维度 | 面料排料 | 皮革排料 |
|----------|----------|----------|
| 材料形态 | 规则矩形卷材 | 不规则兽皮轮廓 |
| 缺陷处理 | 通常无缺陷（或瑕点极少） | 每张皮有天然瑕疵（伤疤、虫眼、色差等） |
| 纹理约束 | 经纬向限制 | 各部位纹理/厚度/弹性不同 |
| 排样策略 | 矩形内最优排列 | 不规则区域内避开缺陷的最优排列 |
| 利用率基准 | 通常 80-90%+ | 通常 55-75%（受皮料质量影响大） |

#### Versalis 的皮革排样算法

Versalis 采用 **多张皮联合优化（Multi-hide Nesting）** 策略：

1. **皮料数字化**：通过高拍仪扫描整张皮革，0.8mm 分辨率，同时识别皮料轮廓
2. **缺陷分级**：操作员在扫描图上标记瑕疵，系统支持多达 4 个缺陷等级
3. **裁片预排**：基于裁片几何形状和皮料可用区域，使用启发式搜索在每张皮的可用区域中放置裁片
4. **多皮联合优化**：关键差异化能力——不是逐张排样，而是将多张皮的可用区域作为一个整体进行全局优化，实现跨皮料的裁片分配
5. **成本模拟**：在实际切割前模拟不同排样方案的皮革消耗和成本

结果：据客户案例，Versalis 的皮革利用率提升幅度在 2-15% 之间，典型值为 3-5% 的提升。

#### LeatherNest（Gerber）的排样算法

LeatherNest 集成在 Gerber Taurus II 系统中：

- 与 RapidScan 联动：扫描完成后数秒内生成排样方案
- 基于裁片几何特征的智能匹配：考虑每片裁片的独特形状，在缺陷区域周围自动寻找最佳放置位置
- 宣称皮革利用率提升 5-10%
- 支持手动微调模式（操作员可在自动结果基础上调整）

#### CLS Auto 的 AutoNest（汽车专用）

面向汽车座椅/内饰的连续流水线方案：

- 传送带式连续生产
- AutoNest 自动规避皮料缺陷，材料节省 5-10%（对比刀模裁断）
- Offload 软件引导工人分拣，额外节省 2-5%

### 2.3 收购 Gerber 后的技术整合

收购至今（~5 年），Lectra 采取了 **双品牌并行 + 后台整合** 策略：

| 层面 | 整合方式 |
|------|----------|
| **销售/服务** | 统一渠道，Gerber 客户纳入 Lectra 服务体系 |
| **云基础设施** | 统一迁移至 Microsoft Azure |
| **PLM/数据** | Kubix Link 作为统一数据平台，整合 Gerber YuniquePLM |
| **裁床硬件** | 保持双线（Versalis + Taurus），各自主攻不同细分 |
| **排料算法** | Diamino 和 LeatherNest 仍各自独立，未见算法层面融合 |
| **供应链** | Gerber eSTORE 整合入 Lectra 备件体系 |

注意：**两套排料引擎目前并未真正融合**。Diamino 专注面料、LeatherNest 专注皮革，底层算法和数据结构完全不同（矩形 vs 不规则区域）。短期内看不到算法合并的可能性。

- **桌面端**：MFC / Qt 风格的传统 Windows 桌面应用，C++ 核心

- **数据互通**：与 Modaris 共享 Variant（裁片规格数据），通过文件路径（Access Paths）管理

### 3.2 Versalis 架构

Versalis 是一个 **软硬件一体化解决方案**：

```
┌──────────────┐    ┌──────────────┐    ┌──────────────┐
│  RapidScan   │───>│  Nesting     │───>│  Cutting     │
│  (扫描)       │    │  Engine      │    │  (裁床执行)   │
└──────────────┘    └──────┬───────┘    └──────────────┘
                           │
                  ┌────────┴────────┐
                  │  ERP / MES      │
                  │  (数据对接)      │
                  └─────────────────┘
```

核心模块：
- **RapidScan**：高拍仪硬件 + 图像处理软件，捕捉皮料轮廓和缺陷
- **Nesting Engine**：多皮联合优化算法
- **Digital Marking**：替代粉笔标记的数字投影系统
- **Offload**：裁片分拣引导

### 3.3 ERP/PLM 接口

| 接口产品 | 方式 | 适用场景 |
|----------|------|----------|
| **Kubix Link API Toolkit** | REST API + 预置连接器 | ERP/CMS/WMS/Excel 对接 |
| **Lectra Easy Connect** | 预配置连接器 | ERP/CRM 即插即用 |
| **CAD Connectors** | 专用插件 | Adobe Illustrator/Photoshop/CLO3D |
| **MES Integration** | 定制接口 | Versalis 产线数据对接 |

整体架构为 **API-first**，支持与 SAP、Oracle 等主流 ERP 对接（虽然未发现官方 SAP 专用连接器的公开文档）。

### 3.4 与 Vector 裁床的集成

- Diamino 生成的 Marker 文件直接导入 Vector 裁床控制器
- 裁床读取 Marker 中的裁片路径、刀口位置、面料方向等信息
- 支持 Marker 在裁床上的投影（Projector 模式），供操作员微调
- 数据格式：Lectra 自有封闭格式（.MDL / .PLX），不直接兼容第三方裁床

## 六、UI 使用方式与交互特色

### 6.1 Diamino 操作流程

Diamino 的操作流程高度结构化，遵循 "Modaris → Variant → Marker → Nesting" 的链式工作流：

1. **Modaris 创建 Variant**：定义裁片、面料类型、数量
2. **Marker Manager**：配置面料约束（方向、纹理、缩水率）
3. **创建 Marker**：选择款式、尺码、数量
4. **Interactive Processing**：将裁片加载至排料窗口
5. **排料操作**：拖拽摆放 / 自动排料
6. **保存/导出**：生成裁床可读的 Marker 文件

### 6.2 交互特色

| 特色 | 描述 |
|------|------|
| **键盘快捷键驱动** | 高度依赖键盘快捷键（1-9 数字键对应推、拉、翻、旋转等核心操作），熟练用户双手不离键盘 |
| **双模式切换** | 交互式手动排料和全自动排料可随时切换，自动结果可手动微调 |
| **颜色编码** | 不同面料类型（面料/里料/衬）用不同颜色区分裁片 |
| **实时利用率显示** | 排料过程中即时显示当前面料利用率 |
| **裁片吸附/碰撞检测** | 拖拽时自动检测重叠和边界越界，无重叠才能放置 |
| **云按钮嵌入** | Quick Nest 按钮直接嵌入 Diamino 界面，一键提交批量排料至云端 |
| **Modaris 深度集成** | Variant 数据无缝同步，无需导出/导入 |

### 6.3 Versalis 数字标记系统

Versalis 的 UI 创新集中在"数字标记"环节：

- **投影替代粉笔**：通过投影仪将排料方案直接投射到皮革表面，操作员按投影摆放裁片
- **双工位并行**：两个操作员可同时在同一张皮上进行标记作业，效率 +25%
- **触摸屏操作**：扫描、标记、调整均通过触摸屏完成

### 6.4 与 Zund 的用户体验对比

> 注：Zund 主营数字裁床，其软件生态为 MindCUT Studio（排料）和 Zund Cut Center（裁床控制）。以下对比基于各自产品的公开信息和行业口碑。

| 对比维度 | Lectra (Diamino + Versalis) | Zund (MindCUT + ZCC) |
|----------|----------------------------|----------------------|
| **软件定位** | 深度垂直整合（设计→打版→排料→裁剪） | 开放生态（裁床为主，兼容多品牌软件） |
| **学习曲线** | 陡峭，需专业培训（尤其 Modaris 打版） | 中等，操作较直观 |
| **排料算法** | 30+ 年积累，皮革多皮联优是核心差异 | 依赖第三方（如 iCut、OptiNest），自身不强 |
| **云能力** | Quick Nest/Estimate 已商用 6+ 年 | 云功能相对保守 |
| **行业覆盖** | 服装 + 汽车 + 家具全覆盖 | 以广告/包装/皮革为主，服装较弱 |
| **UI 风格** | 传统桌面应用，快捷键密集 | 现代感稍强，但批量功能不如 Diamino |
| **锁定效应** | 强（封闭文件格式，生态内闭环） | 弱（开放接口，多品牌互操作） |
| **中文支持** | 完整中文版 + 上海 IATC 培训中心 | 有中文但培训资源较少 |
| **皮革专长** | Versalis/LeatherNest 双引擎 + 缺陷分级 | 通用裁床，皮革无专用引擎 |

**核心评价**：

- Lectra 的优势在于 **"一体化生态 + 皮革专用算法"**，从打版到裁剪形成闭环，用户一旦进入生态迁移成本极高。Versalis 的多皮联合优化和缺陷分级是皮革排样领域的技术壁垒。
- Zund 的优势在于 **"开放灵活 + 硬件精度"**，裁床本身机械精度和可靠性业内顶尖，但不绑定软件，给客户更大的选择自由度。对于不需要皮革深度优化的场景（广告、包装材料、复合材料），Zund 的 ROI 更好。
- 两者在皮革排样市场的直接竞争主要在高端家具和汽车内饰领域，Lectra 的 Versalis 有明显先发优势，但 Zund + 第三方软件（如 Crea Solution 的 Mind Cliche）也在蚕食份额。

## 七、竞争力总结

### 7.1 SWOT 分析

| 维度 | 内容 |
|------|------|
| **S - 优势** | 30+ 年排料算法积累；皮革多皮联合优化技术壁垒；打版-排料-裁剪完整闭环；全球 100+ 国家服务网络；中国深耕 30 年 |

| **O - 机会** | SaaS 转型打开中小客户市场；AI 排料（深度学习）可进一步提升利用率；中国市场家具/汽车皮革排料需求旺盛；Kubix Link 可作为跨产品数据中枢 |
| **T - 威胁** | Zund + 第三方排料软件的开放生态竞争；国产替代（如博克、ET 等中国 CAD 厂商）；AI 排料创业公司降低技术门槛；客户对 SAAS 订阅成本敏感度上升 |

### 7.3 对我们的参照价值

1. **皮革排料的算法壁垒来自缺陷处理**：Lectra 的 4 级缺陷分级 + 多皮联优是核心差异点，我们的皮革排样引擎需要在这两个维度对标
2. **桌面+云混合架构是过渡态**：Diamino 的 Quick Nest 模式（桌面操作 + 云端并行计算）是一个务实的架构路径
3. **行业版拆分思路可借鉴**：Diamino 按 Fashion / Furniture / TechTex 三个行业拆分的策略，针对不同行业的排料规则做定制化
4. **中国家具市场是皮革排料的主战场**：顾家、慕思、佳联等案例表明，中国大中型家具厂有真实的皮革排样软件需求，且愿意为 3-10% 的利用率提升付费
5. **价格锚点**：纯软件部分 €20,000-40,000 的定价，为我们的定价策略提供了对标参照
