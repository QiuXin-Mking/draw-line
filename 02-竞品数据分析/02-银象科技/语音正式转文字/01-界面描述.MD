## 1. 设备型号
- **S166Z切割机**

## 2. 电气系统
- **电源规格**: 380V 三相五线制
- **电线要求**: 6平方电线
- **总电源开关**: 位于机器上，用于控制整机电源

## 3. 气源系统
- **总进气接口**: 位于机器上
- **气管规格**: 16mm气管
- **工作气压要求**: ≥6公斤（6 bar）
- **气压保护**: 低于5公斤时设备自动停止工作
  > ⚠️ **气压保护机制** 待确认：[05-气压保护机制](../待确认概念/05-气压保护机制.md)

## 4. 投影系统
- **配置**: 双投影仪
- **投影对齐要求**:
  - 上下端对齐
  - 中间为两个投影的叠加部位
- **投影仪调节**:
  - **调节位置**: 机器顶部
  - **调节方式**: 松开铝件后可前后左右调节投影仪位置
  - **调节场景**: 运输过程中位置偏移时需要重新调节
  > ⚠️ **投影内容** 待确认：[04-投影内容](../待确认概念/04-投影内容.md)

## 5. 控制系统
- **电脑开关**: 位于机器正前方，用于开启电脑
- **显示屏**: 随电脑开关开启而启动
- **运动控制部分**: 开启后设备执行复位动作

## 6. 开机流程
1. 打开机器总电源开关
2. 打开投影仪
3. 打开电脑开关按键
4. 等待电脑屏幕启动
5. 开启运动控制部分
6. 等待设备完成复位动作
7. 检查投影仪对齐情况

# 软件

## 1. 软件启动
- **软件名称**: 排料软件（需双击桌面图标启动）

## 2. CAD工具模块

### 2.1 模板导入
- **入口**: 点击「CAD工具」
- **操作**: 打开文件夹 → 找到并选择模板文件（如：23105）→ 图案导入
  > ⚠️ **文件格式支持** 待确认：[07-文件格式支持](../待确认概念/07-文件格式支持.md)

### 2.2 部件选择
- **功能**: 从模板中选择本次切割任务对应的部件（如：鞋头部件）

## 3. 马牙工具模块

### 3.1 入口位置
- 通过「马牙工具」按钮进入

### 3.2 三种模式

| 模式 | 说明 |
|------|------|
| **常规** | 默认模式 |
| **自定义** | 手动选择方牙、半圆牙等具体牙型 |
| **使用库** | 调用预设的马牙管理库 |

### 3.3 自定义模式操作
- 在裁片边上点击，可选：方牙、半圆牙
- 选择自定义后，执行当前设置的牙型配置

### 3.4 使用库模式操作
- **规格范围**: 从00.5开始递增
- **操作流程**:
  1. 滚动条选择对应尺码（如：30码滚动到31码）
  2. 设置该尺码的牙型参数：
     - 尖牙个数
     - 半圆个数
  3. 依次设置各尺码：

| 尺码 | 牙型配置 |
|------|----------|
| 31码 | 1个尖牙 |
| 32码 | 2个尖牙 |
| 33码 | 3个尖牙 |
| 36码 | 1个方牙 + 1个尖牙（常规做法） |
| 37码 | 2个尖牙 + 1个方牙（常规做法） |

### 3.5 应用马牙设置
- 选择「管理部」→ 选择「使用」→ 应用设置

## 4. 码尺设置模块

### 4.1 操作步骤
1. 选择目标尺码（如：31码）
2. 输入码尺参数
3. 设置牙齿参数

## 5. 整体操作流程
1. 启动排料软件
2. 进入CAD工具导入模板
3. 选择本次切割的部件
4. 打开马牙工具
5. 选择模式（自定义或使用库）
6. 设置各尺码对应的牙型参数
7. 应用马牙设置
8. 进行码尺设置

# 整套功能完整业务流程文字总结

1. 软件启动后，在顶部主界面点击【CAD工具】按钮，进入码齿相关功能模块；

2. 弹出【码齿工具】配置窗口，提供两类使用模式：
   - ① **常规模式**: 手动自定义码数、齿宽、齿高、齿间距、半码间距，同时设置方形/半圆/尖角齿形的数量；
   - ② **使用库模式**: 读取预设码齿参数模板；
   - ③ **自定义模式**: 完全自定义齿形逻辑；

3. 点击弹窗内【管理库】按钮，打开【码齿库】表格窗口，库内存储多组预设码齿参数（码数、各类齿数量），可查看、调取历史预设参数用于快速配置码齿。
