# Lectra Diamino/Kubrix - 竞品分析

> 分析时间：2026-08-07

| 项目 | 内容 |

## 产品架构

```
Lectra 裁剪房方案
├── Diamino       → 排样软件（手动+自动）
├── Kubrix        → 智能裁床（含扫描+排样+切割）
├── Vector        → 自动裁剪系统（面料/皮革）
├── Versalis      → 皮革裁剪系统
├── AccuMark      → CAD 打版/放码
├── Kaledo        → 产品设计与开发
└── Optiplan      → 裁剪房规划与管理
```

## 核心功能（基于公开资料）

### Diamino 排样软件

- 手动排样 + 自动排样
- 面料和皮革双模式
- 支持瑕疵避让和质量分区
- 支持方向约束（毛向、纹理）
- 与 AccuMark CAD 深度集成
- 支持多订单多材料混合排样

### Kubrix 智能裁床

- 集成扫描、排样、切割于一体
- 自动皮革轮廓识别
- 瑕疵检测
- 投影辅助（将排样结果投影到皮革上）
- 人工干预和修正

### Versalis 皮革裁剪系统

- 专为天然皮革设计
- 高速数字扫描
- 自动质量分级
- 优化排样算法
- 高精度切割

## 商业模式

- **整体解决方案**：软件 + 硬件 + 培训 + 售后
- **许可证 + 年维护费**
- **估计价格**：€20,000-80,000+（软件），硬件另计
- **全球服务网络**：在 100+ 国家有办事处
- **中国市场**：在上海有办事处

## 优势

1. 全球裁剪房领域最大的公司之一
2. 50 年行业积累，技术最成熟
3. 端到端解决方案（从设计到裁剪）
4. 全球服务网络
5. 上市公司，财务稳定
6. 汽车行业客户基础大

## 劣势

1. 价格最高
2. 系统最复杂，学习曲线最陡
3. 通常需购买整套系统
4. 中国市场服务响应可能不如本土企业
5. 过于重量级，不适合小工厂

## 对本项目的威胁与机会

| 维度 | 分析 |
|------|------|
| 直接竞争 | 低——Lectra 面向大型企业 |
| 间接竞争 | 中——行业标准制定者 |
| 机会 | 大量中小企业用不起 Lectra |
| 学习点 | 完整的裁剪房工作流、投影辅助、CAD 集成 |
| 威胁 | 低——市场定位不同 |
