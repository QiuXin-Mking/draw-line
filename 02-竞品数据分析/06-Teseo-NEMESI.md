## 产品线

```
Teseo 软件体系
├── METI        → 本地版自动排样软件（20年积累）
├── NEMESI      → 云端 AI 版（METI + AI + 神经网络）
├── CAD-CAM     → 设计加工软件
└── 切割系统     → EOS 等切割设备
```

## NEMESI 核心特点

### 1. AI + 人工神经网络（ANN）

- **METI + AI + ANN = NEMESI**
- 专门针对皮革排样开发的 AI
- 识别皮革及其质量特征
- 策略学习：从全局经验中学习最优策略
- 皮革与产品的对比分析
- 基于 15 年以上、数十万张皮革的数据库

### 2. 神经网络架构

- 超过 **1000 个独立计算节点**
- 每个节点处理皮革的特定区域
- 节点之间通信协调整体优化
- 计算能力由 TKM（Teseo Knowledge Machine）提供

### 3. 极致速度

| 方式 | 排样时间 |
|------|---------|
| 传统单机 PC | ~60 秒/张皮 |
| NEMESI 云端 | **< 3 秒/张皮** |

### 4. 效率提升

- 比标准 METI 版本利用率高 **3%**
- 比竞品软件利用率高 **8%**
- 配合 EOS 切割系统，年节省 **€400,000+**

### 5. 云端 SaaS 模式

| 特点 | 说明 |
|------|------|
| 零投资 | 无需在客户现场安装基础设施 |
| 零改变 | 兼容所有 Teseo 切割设备和排样设备 |
| 零风险 | 仅在实现真实节省时付费 |
| 仅需网络 | 标准 Internet 连接即可 |
| 24/7 可用 | 冗余硬件保证可靠性 |

### 6. 数据安全

- VPN 加密通道
- **AES 256 位加密**（美国政府级别）
- Teseo 不保留任何几何或产品数据
- 数据仅用于排样计算后立即删除
- 签订保密协议（NDA）
- 统计数据存储在客户自己的数据库

## 商业模式

- **SaaS 按用量计费**
- **按节省金额分成**：仅在实现真实皮革节省时收费
- **无前期投资**：不需要购买硬件或软件许可
- **估计年费**：根据用量，但承诺年节省 €400,000+

## 优势

1. AI + 神经网络，算法最先进
2. 3 秒完成排样，速度碾压
3. SaaS 模式，零前期投资
4. 15 年数据积累，经验最丰富
5. 按效果付费，风险最低
6. 数据安全有保障

## 劣势

1. **必须联网**——工厂网络不稳定是致命问题
2. 数据需上传到云端，部分客户有顾虑
3. 意大利公司，中国本地支持有限
4. 依赖 Teseo 切割系统生态
5. 长期 SaaS 费用可能超过一次性购买
6. 不适合完全离线的工厂环境

## 对本项目的威胁与机会

| 维度 | 分析 |
|------|------|
| 直接竞争 | 低——云端 vs 离线，模式不同 |
| 间接竞争 | 中——定义了 AI 排样的行业标准 |
| 机会 | 中国工厂大多需要离线方案，云端不适用 |
| 学习点 | AI 策略学习、神经网络分布式计算、按效果付费模式 |
| 未来方向 | Phase 3+ 可考虑引入云端 AI 排样作为增值服务 |
