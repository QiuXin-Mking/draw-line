# MiriSys — 捷克排样与切割 CAM

> 来源: mirisys.com | 国家: 捷克

## 公司概况

MiriSys Software 专注于皮革和纺织品的自动排样与切割 CAM 软件开发。产品线覆盖排样、切割控制、生产管理。

## 产品矩阵

| 产品 | 功能 |
|------|------|
| **AutoNest** | 自动排样引擎（单核/多核版本） |
| **CutNest** | 排样 + 切割 CAM 一体 |
| **UniPDS** | 图案设计系统 |
| **MRP System** | 生产计划与切割车间管理 |

## AutoNest 特点

- 全自动排样，考虑缺陷和质量区
- 可调排样时间和每版测试次数
- 尝试数千种变体以达到最大利用率
- 组合自动 + 交互式优化

## CutNest 特点

- 模型导入（UniPDS 或其他 CAD）
- 排样参数调整
- 切割优化
- 自动 + 交互式排样
- 条纹/格子匹配
- 直接输出到切割和绘图设备

## 技术特点

- 支持 DXF、AAMA、ASTM、ISO 标准格式
- 多核 CPU 优化
- SQL 数据库连接
- 支持 CNC 切割机、激光、水刀、铣床、辊压机
- Windows 10/8.1/7（32&64 bit）
- 切割机品牌无关（不锁定硬件）

## 关键启示

1. **品牌无关的切割机对接**：不锁定特定切割机品牌，兼容几乎所有主流设备——这是纯软件厂商的核心竞争力
2. **多核版本单独售卖**：AutoNest 分单核和多核版，说明计算量确实大，且客户愿意为速度付费
3. **SQL 数据库集成**：说明面向中大客户，需要生产数据管理

## 对我们 Phase 1 的参考价值

- **中**。MiriSys 的"切割机无关"策略值得借鉴。Phase 2 做设备对接时，应该以 DXF/PLT 标准格式导出，而非绑定特定品牌。
