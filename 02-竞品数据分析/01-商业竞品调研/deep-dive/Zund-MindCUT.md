## 2. 技术路线

### 2.1 软件开发框架与语言

Zund 未公开发布 MindCUT 的开发语言或底层框架细节。但从其产品形态和生态结构可以做如下推断：

- **操作系统**：仅支持 **Windows** 平台（基于视频演示和行业惯例，未见 macOS/Linux 版本）。
- **CAD 数据交换**：支持行业标准格式的导入导出（DXF 等），与主流 CAD 软件（如 Lectra Modaris、Gerber Accumark 等）通过标准格式互通。
- **架构形态**：Mind 并非单体应用，而是一个**模块化套件**，由 MindCUT（核心切割控制）、MindGEST PDM（产品数据管理）、MindCAD Part Scan（样片扫描）三个独立但互通的应用组成。这种架构暗示内部可能采用**组件化/插件化设计**。
- **Web 技术栈**：Zund Connect（生产监控看板）是基于 Web 的仪表盘，说明 Zund 在辅助系统中使用了现代 Web 技术。
- **GPU 加速**：Dectura 视觉系统的 AI 推理跑在 **NVIDIA GPU 服务器** 上，暗示其深度学习推理管线使用了 CUDA 生态。

### 2.2 几何算法

自研能力是 MindCUT 的核心壁垒之一：

- **切割路径生成（Toolpath）**：MindCUT 需要为多种刀具（振动刀、圆刀、铣刀、冲孔工具等）生成优化路径。路径算法须处理内外轮廓区分、共线去重（common-line removal）、桥接保留、刀具半径补偿（V6.0 新增 router bit diameter compensation）等问题。这是典型的计算几何问题——**多边形布尔运算**（Clipper/Boost.Geometry 级别库可支撑）配合**刀具路径优化**（类似 TSP 变种，对切割顺序做最短路径规划）。
- **排版算法（Nesting）**：这是 MindCUT 最核心的算法价值所在：
  - **皮革排版**：处理**不规则外形真皮**，在每个皮料独特的轮廓内、在避开缺陷区域和质量分区的前提下，最大化排布异形裁片。这是一个 **2D irregular strip packing / bin packing** 问题，是运筹学中公认的 NP-hard 问题。Zund 的自研引擎显然在启发式算法（遗传算法、模拟退火、NFP/no-fit polygon 计算等方向）上做了大量积累。
  - **合成材料排版**：V6.0 引入了专门针对**卷材/片材合成材料**优化的排版引擎（Optimized Auto-Nesting Engine for Synthetics），V6.2 进一步增加了**外部排版引擎**，且系统可自动在两个引擎间择优选择——说明 Zund 采用的是多引擎策略，针对不同材料类型使用不同优化算法。
  - **图案对齐排版**：Pattern Matching 功能可自动对齐印花/编织图案进行排版，这涉及**图像配准算法**。
- **图像处理/计算机视觉**：MindCUT V6.0 的 Feature Recognition（特征识别）利用 AI 自动分析材料特征来定位标记，训练一次后可批量对齐。Dectura 的视觉分析更是深度学习驱动。

### 2.3 视觉方案：Dectura 技术细节

Dectura 是 Zund 与合作伙伴 **Mindhive Global** 联合推出的 AI 驱动真皮检测工作流。核心组件如下：

| 组件 | 详情 |
|------|------|
| **硬件** | 高分辨率相机阵列 + 机器视觉专用光源（machine-vision-specific lights） |
| **AI 引擎** | **Mindhive FinishSelect**，运行在 NVIDIA GPU 服务器上 |
| **模型基础** | 基于数万张图像训练的专有神经网络 |
| **检测精度** | 可达 **0.17 mm（约 0.0067 英寸）**，被描述为"毛囊级精度" |
| **检测速度** | 每张皮约 **15 秒**（扫描 + 全部分析 + 分级） |
| **班次产能** | 8 小时班次可处理 **1,000-1,920 张皮** |
| **可识别缺陷类型** | 20+ 种：疤痕、划痕、疣、虫咬、皱纹、孔洞、厚度变异、色差等 |
| **工作流集成** | 扫描条码 -> 高清扫描 -> AI 分析 -> 生成数字缺陷地图 -> 创建"数字孪生" -> 导入 MindCUT 进行智能排版 -> 投影到物理皮料 -> 精确切割 |
| **分级定制** | Natural Feature Guide（NFG），允许客户定义自己的分级标准和质量区域划分 |

**Dectura 对行业的意义**：传统真皮检测依赖人工目检，主观性强、一致性差、速度慢（约 10 分钟/张皮），且易疲劳。Dectura 用 AI 取代人工，报告称：
- 缝制前的**质量拒收率降低 90%**
- 每张皮节省**约 10 分钟**人工检查时间
- 消除粉笔标记（无后期清洗需求）
- 实现完全数字化追溯
- 支持集中化检测、减少工厂占地

V6.2 新增的 **Natural Leather Feature Guide Translator** 进一步将数字化天然皮革特征转换为分级质量材料（1-5 级）和缺陷标记，直接送给 Dectura 扫描方案使用。

### 2.4 排版算法深度推断

基于 MindCUT 的功能描述，其排版系统可以分为三个层级：

**层级一：规则材料排版（卷材/片材合成材料）**
- 输入：矩形/连续卷材 + 规则裁片（polygon）
- 算法类型：2D rectangular bin packing / strip packing
- 特殊约束：图案对齐（pattern matching）、色调区域（tonality zones）、裁片间缝合线对齐（proximity nesting for sewing alignment）
- 优化目标：材料利用率最大化

**层级二：不规则外形天然材料排版（真皮）**
- 输入：每张皮的独特轮廓（任意多边形）+ 缺陷区域（holes/blocked zones）+ 质量分区（quality zones）+ 裁片
- 算法类型：2D irregular nesting with defects 和 quality constraints
- 核心技术栈推测：NFP（No-Fit Polygon）计算 + 元启发式（模拟退火/遗传算法/粒子群）+ 碰撞检测（GJK 等）
- 这是切割排版领域最难的问题之一，Zund 30+ 年的积累在这里形成核心壁垒

**层级三：多张皮同时排版（Multi-hide Nesting）**
- 跨多个不规则轮廓同时优化
- 在 scan-to-stock（先扫描入库）模式下，从库存皮料中智能选取最优匹配的皮料
- 与 MindGEST PDM 深度耦合

**产品化功能亮点**：
- Bundle 功能（V5.4）：改善不同尺码服装裁片的朝向和放置
- Part Modifier（V6.0）：不修改 CAD 图纸即可插入排版要求
- Sequencing（V6.2 add-on）：排版顺序控制
- 手动/自动双模式：可先手动排关键裁片，再自动排剩余裁片

## 3. 软件框架

### 3.1 模块化架构详情

Mind 软件套件由以下核心模块构成：

```
Mind 软件套件
├── MindCUT                    [核心切割控制中心]
│   ├── MindCUT Studio         [工作室模块：数字化、排版、作业管理、切割控制]
│   │   ├── 材料数字化/分类
│   │   ├── 缺陷标记与处理
│   │   ├── 交互式排版
│   │   ├── 自动排版（皮革引擎 / 合成材料引擎 / 外部引擎）
│   │   ├── 切割控制（刀路生成、工具管理、材料输送）
│   │   ├── 相机/投影系统控制
│   │   └── 在线/离线报告
│   ├── MindCUT Model Prime    [原 Model Importer，V6.2 更名]
│   │   ├── Core（手动预处理）
│   │   ├── Advanced（导入规则）
│   │   └── Ruleset Editor（完整功能）
│   └── Add-on 许可证（独立售卖）
│       ├── Interactive Nesting
│       ├── Pickup Tool（拾取辅助）
│       ├── Camera（相机系统）
│       ├── Projectors（投影系统）
│       ├── Automatic Nesting Advanced Restrictions
│       └── Automatic Nesting for Quality Areas
│
├── MindGEST PDM               [产品数据管理]
│   ├── 集中化数据存储（矢量数据、数字化材料、排版布局、切割文件）
│   ├── 生产看板（dashboard）
│   ├── 版本控制
│   ├── ERP/外部系统接口
│   ├── 多切割机互联
│   ├── 自动导入导出
│   ├── 多实体报告（V6.2）
│   └── Material Collect App（V6.2，真皮离线采集引导）

├── Zund Connect               [生产监控/IoT]
│   ├── Monitor（免费，实时 OEE）
│   ├── Analyzer（付费，深度分析）
│   └── 基于 Web 的仪表盘（ZCC v3.4+ 支持）
│
└── Zund Cut Center (ZCC)      [切割机端控制软件，随机器捆绑]
```

### 3.2 与切割机的通信协议

- **MQTT 协议**：V6.1 明确支持 **MQTT 协议** 用于机对机通信（machine-to-machine communication）。这是工业 IoT 领域的主流轻量协议，暗示 Zund 系统的通信架构现代化程度较高。
- **机器人集成**：V6.1 支持与 **Robotfactory** 的机器人集成，可在 MindCUT 中直接配置外部机器人进行自动取料。
- **移动设备集成**：V6.1 支持 **EPA（Electronic Pickup Assistant）** — 专用平板 App，用于裁片拾取引导。
- **第三方集成**：
  - ICC/OCC 相机系统（用于套准标记识别和图案对齐）
  - Leibinger 喷墨系统（裁片标签打印）
  - PrimeCenter 及第三方 RIP 软件（多层 PDF 兼容）
  - SpencerMetrics CONNECT/LYNK 平台（多厂商 Industry 4.0 集成）
- **数据格式**：出入站支持 DXF 等 CAD 标准格式，以及 ZCC 原生格式的内部互传。

### 3.3 操作系统兼容性

- **MindCUT/MindGEST/MindCAD**：仅支持 **Windows**（行业标准平台，未见 macOS/Linux 版本信息）。
- **Zund Connect**：**基于 Web** 的仪表盘，跨平台浏览器访问。
- **EPA 移动端 App**：专用平板应用（推测为 Android/iOS 或工业平板定制系统）。

### 3.4 开放性与可扩展性

- **开放架构**：Zund 宣称 MindCUT 具有"开放架构"，支持与 CAD 软件、ERP 系统和第三方销售管理方案的无缝集成。
- **Inline 和 Offline 工作流**：既支持与切割机实时联动（inline），也支持离线处理（offline，如先扫描真皮入库，后续再排版切割）。
- **自动化能力**：MindGEST PDM 支持自动导入导出、V6.1 支持自动标签打印、自动套准标记读取、自动 Diva 设置、配置自动迁移等，自动化程度相当高。
- **模块化许可**：从 V6.0 开始，Interactive Nesting、Pickup Tool、Camera、Projectors 等变为独立 add-on 许可，实现按需购买。

## 4. 收费模式

### 6.2 典型操作流程

MindCUT 覆盖以下端到端工作流：

```
步骤 1: 材料数字化
  ├── 真皮：相机捕获皮料轮廓 -> 自动/手动标记缺陷 -> 定义质量区域 -> Dectura AI 自动检测
  ├── 卷材/片材：设定材料尺寸 -> 图案对齐（如有）
  └── 样片：通过 MindCAD Part Scan 扫描数字化

步骤 2: 排版（Nesting）
  ├── 导入裁片数据（来自 CAD 或 MindGEST PDM）
  ├── 选择排版引擎（皮革/合成材料/外部引擎）
  ├── 手动调整（关键裁片精排）-> 自动填充（剩余裁片）
  └── 实时可视化材料利用率和排版预览

步骤 3: 切割准备
  ├── 刀具路径生成（自动/手动调整）
  ├── 工具分配（多工具头自动切换）
  ├── 切割顺序优化
  └── 投影对齐验证

步骤 4: 切割执行
  ├── 发送至 ZCC（Zund Cut Center）
  ├── 实时监控切割进度
  └── Zund Connect 数据采集

步骤 5: 裁片拾取与质检
  ├── 投影/显示器色彩编码显示裁片信息
  ├── EPA 平板 App 引导拾取
  ├── 自动标签打印（Leibinger 喷墨）
  └── 质量追溯
```

## 8. 关键洞察与启示

### 8.1 对竞品策略的启示

1. **排版算法是核心战场**：MindCUT 的排版能力是三层递进的（规则材料 -> 不规则真皮 -> 多皮联合优化），引擎矩阵策略值得借鉴。如果你方也在做排版软件，建议评估当前算法在"不规则外形 + 缺陷避开 + 质量分区"这个最难场景上的表现。

2. **AI 视觉是差异化关键**：Dectura 的 AI 缺陷检测直接将传统 10 分钟的人工检查缩短到 15 秒，且降低 90% 拒收率。这种 ROI 极其清晰的功能，是说服客户升级/采购的杀手级卖点。如果你方产品缺乏类似的 AI 视觉能力，这是一个值得投入的方向。

3. **MQTT 协议是工业互联标准**：V6.1 引入 MQTT 说明 Zund 正在为智能工厂做准备。如果你方在开发类似的切割控制系统，建议原生支持 MQTT 协议和 OPC UA，便于与 MES/ERP 生态打通。

4. **模块化许可 + 硬件捆绑是可持续的商业模式**：Zund 的永久许可 + 年维护费 + 模块化 add-on 组合，既保证了稳定的经常性收入（维护费），又提供了增量收入空间（add-on）。软件独立化的 add-on 策略（V6.0 起）说明 Zund 正在将软件从硬件附庸升级为独立的收入引擎。

5. **中国市场存在空白**：Zund 在中国的中文声量极低，代理商信息不透明，且产品定价高端。这为本地化竞品留下了空间——如果能提供有竞争力的排版算法 + 合理的价格 + 本地化服务，中国市场的机会很大。
