## 三、技术路线深度分析

### 3.1 NEMESI 云端架构

#### 3.1.1 TKM 平台（Teseo Kilometer）

NEMESI 运行在 Teseo 自建的 **TKM 私有云** 上，而非使用 AWS/Azure/GCP 等公有云。这是一个非常关键的架构决策。

| 维度 | 详情 |
|------|------|
| **计算节点** | 1,000+ 台高性能 Linux 计算机 |
| **内部网络** | 超高速内部互联网络 |
| **互联网出口** | 1 Gbps 光纤 |
| **可用性** | 24/7 全天候运行 |
| **冗余设计** | 全功能硬件冗余 |
| **并发能力** | 同时服务数百家客户 |
| **数据中心位置** | 未公开披露（推测位于意大利总部或附近） |

**架构解读**：Teseo 选择自建私有云而非公有云，可能基于以下考量：
- **延迟控制**：排样计算需要在 3 秒内完成，自建网络可精细控制端到端延迟
- **数据安全**：客户（尤其是汽车 OEM）对皮革裁片数据有极高保密要求，私有云更易通过安全审计
- **成本结构**：1000+ 节点长期运行，自建可能比公有云按需付费更经济
- **但缺点是**：缺乏弹性伸缩能力、全球多区域部署困难（非中国客户可能面临较高延迟）

#### 3.1.2 人工神经网络（ANN）具体实现

NEMESI 的 ANN 架构是其核心技术壁垒：

```
ANN 排样流程（推测）
┌─────────────────────────────────────────────┐
│               输入层                          │
│  皮革扫描图像 + 缺陷标记 + 质量区域 + 裁片数据   │
└──────────────────┬──────────────────────────┘
                   ▼
┌─────────────────────────────────────────────┐
│              AI 识别层                        │
│  · 皮革类型识别（全粒面/修面/绒面等）             │
│  · 质量等级评估                                │
│  · 缺陷自动分类                                │
│  · 15+ 年 / 数十万张皮革数据库匹配               │
└──────────────────┬──────────────────────────┘
                   ▼
┌─────────────────────────────────────────────┐
│           算法选择层                           │
│  · 自动为每张皮革选择最优排样算法                  │
│  · 自适应逻辑引擎                              │
└──────────────────┬──────────────────────────┘
                   ▼
┌─────────────────────────────────────────────┐
│      人工神经网络（ANN）- 1,000+ 节点            │
│  ┌─────┐ ┌─────┐ ┌─────┐     ┌─────┐       │
│  │节点1│ │节点2│ │节点3│ ... │节点N│       │
│  │区域A│ │区域B│ │区域C│     │区域N│       │
│  └──┬──┘ └──┬──┘ └──┬──┘     └──┬──┘       │
│     │       │       │           │           │
│     └───────┴───────┴───────────┘           │
│              ▼                               │
│         节点间通信与全局优化                      │
│    (每个节点负责皮革特定区域的裁片最优放置)          │
└──────────────────┬──────────────────────────┘
                   ▼
┌─────────────────────────────────────────────┐
│              输出层                           │
│  最优排样结果 → 回传切割机                       │
│  (< 3 秒总耗时)                               │
└─────────────────────────────────────────────┘
```

**关键特征**：
- **分布式并行计算**：每个节点独立处理皮革的一个子区域，同时计算该区域内裁片的最佳位置
- **节点间通信**：各节点相互通信以平衡全局排样效果，避免局部最优陷阱
- **持续自学习**：全球系统的使用经验持续反哺 ANN，形成正向循环
- **混合排样策略**：AI + 传统启发式算法（METI 20 年积累）相结合

### 3.2 METI 桌面端技术栈

关于 METI 桌面端的具体开发框架，Teseo 未公开披露。以下为合理推测：

| 维度 | 推测 | 依据 |
|------|------|------|
| **操作系统** | Windows（几乎确定） | 工业 CAD/CAM 软件标准；Teseo 产品线描述中提及 PC |
| **开发语言** | C++（高概率） | 图形密集 + 性能敏感 + 工业软件行业标准 |

| **图形引擎** | 自研或 OpenGL | 2D 排样可视化需要高性能图形渲染 |
| **排样算法** | 自研启发式 + AI 增强 | 20+ 年迭代的专有算法 |
| **单机性能** | 约 60 秒/张皮 | 官宣数据 |

**关键假设**：桌面端 METI 和云端 NEMESI 的排样算法核心共享同一套代码基础，但 NEMESI 利用了云端的并行计算能力和 AI 增强。

### 3.3 数据传输与安全架构

```
客户现场                          TKM 云端
┌──────────────┐                ┌──────────────────┐
│  切割机/检测台 │                │  NEMESI 引擎      │
│              │   AES 256 VPN  │                  │
│  皮革扫描 ────┼───────────────▶│  排样计算         │
│              │   (加密传输)    │                  │
│              │                │  几何数据即刻删除  │
│  排样结果 ◀───┼────────────────│  (不留存)         │
│              │                │                  │
│  开始切割     │                │  统计数据留存      │
│              │                │  (客户自有数据库)  │
└──────────────┘                └──────────────────┘
```

| 安全维度 | 详情 |
|----------|------|
| **传输加密** | AES 256-bit VPN 加密通道 |
| **加密级别** | 美国政府和 NSA 用于"Top Secret"级别的加密标准 |
| **数据留存** | 产品/几何数据在排样计算完成后**立即删除**，Teseo 不留存 |
| **数据存储** | 详细的皮革统计数据存储在**客户自有数据库**中 |
| **法律保障** | 双方签署保密协议（NDA） |

**安全评估**：Teseo 采用了"AES 256 加密 + 即时删除 + NDA"三层安全保障，对于担心数据泄露的汽车 OEM 客户（通常是皮革排样领域最敏感的客户群体）具有说服力。但需要注意，"不保留几何数据"也意味着客户无法在云端回溯历史排样方案用于分析，需要自行在本地保存。

## 五、收费模式分析

### 5.1 定价策略

Teseo 对 NEMESI 采用**非公开定价 + 按效果付费**的双重策略：

| 定价维度 | 详情 |
|----------|------|
| **商业模式** | SaaS（Software as a Service） |
| **计费基础** | **按实际节省效果付费**（"only if you get real savings on the leather yield"） |
| **基础设施** | 无需客户投资任何本地基础设施 |
| **公开价格** | **无**——Teseo 不公开任何定价信息 |
| **报价方式** | 需联系 info@teseo.com 获取定制报价 |

### 5.2 价值主张

Teseo 的定价逻辑建立在其宣称的经济效益上：

| 指标 | 数值 |
|------|------|
| **vs 标准 METI** | +3% 皮革利用率 |
| **vs 竞品软件** | 最高 +8% 皮革利用率 |
| **配合 EOS 切割系统** | 年节省 > €400,000 |
| **单次排样耗时** | <3 秒（vs 60 秒） |

### 5.3 收费模式推测

基于"按节省付费"的声明，可能的收费模式包括：

1. **浮动分成模式**：按 NEMESI 实际带来的皮革节省金额的一定比例（如 20-30%）收费
2. **年费 + 节省分成**：基础年费覆盖基础设施成本 + 按节省金额的较小比例分成
3. **纯 SaaS 订阅**：固定月费/年费，不限用量（但 Teseo 明确强调"按效果付费"，此模式可能性较低）
4. **阶梯用量计费**：按排样次数或处理的皮革张数计费

**商业评估**：
- Teseo 的"按节省付费"是一个强有力的营销信号，降低了客户的试错风险
- 但这种模式的实际落地存在计量困难——如何界定"NEMESI 带来的额外节省"需要复杂的基准对比

## 七、UI 与使用方式分析

### 7.1 操作界面

由于 Teseo 不提供公开 demo，其 UI 细节主要来自产品文档的片段描述：

| 维度 | 推断 |
|------|------|
| **显示方式** | 排样布局同时显示在**显示器**和**实际皮革**上（投影系统） |
| **交互方式** | 操作员可以实时查看并进行**手动干预** |
| **学习曲线** | 据 Teseo 宣称，仅需"数小时指导即可操作" |
| **Web vs 桌面** | NEMESI 的云端调用可能集成在 METI 桌面客户端中，而非纯 Web 界面 |

### 7.2 典型操作流程

```
NEMESI + EOS 完整工作流程

1. 皮革准备
   ├── 皮革铺设在 MOB 检测台上
   ├── 使用彩色墨水/WOP/WiLD 标记缺陷和质量区域
   └── 放置 ROT 参考光学标签（如需转移切割）

2. 扫描 (3 秒)
   ├── 高清静态扫描（0.25mm 分辨率）
   ├── 自动识别缺陷标记
   └── 自动区分不同质量区域

3. 排样 (< 3 秒)
   ├── 扫描数据通过 AES 256 VPN 发送至 TKM 云端
   ├── AI 识别皮革类型和质量
   ├── AI 选择最优排样算法
   ├── ANN 1000+ 节点并行计算
   └── 排样结果回传

4. 切割
   ├── 排样结果加载至切割机
   ├── 动态真空系统激活
   ├── 多切割头并行工作
   ├── Sheplock 精确对齐（如有纹理/logo）
   └── 成品分拣（颜色投影辅助）

总耗时：从扫描到开始切割 < 10 秒
```

### 7.3 "3 秒排一张皮"的用户体验

这个 3 秒并非一个孤立指标，而是整个系统重新设计的结果：

| 对比维度 | 传统 METI（桌面） | NEMESI（云端） |
|----------|-------------------|----------------|
| **排样耗时** | ~60 秒 | < 3 秒 |
| **操作等待感** | 明显等待 | 几乎即时 |
| **连续生产** | 存在瓶颈（排样等待切割） | 无缝衔接 |
| **多皮同时排** | 不支持 | 支持（多节点并行处理多张皮） |
| **对操作员的影响** | 排样等待→闲置→节奏中断 | 即时反馈→专注切割→效率提升 |

**核心体验转变**：3 秒的排样时间本质上是将排样从"批处理等待"变成了"实时响应"。在配合 EOS 切割系统的"不停机切割"（非停止切割）模式下，整个生产实现了流水线化——扫描、排样、切割、分拣可以同时进行，消除了等待瓶颈。

### 7.4 投影辅助系统

Teseo 的切割机上配有**彩色投影系统**，直接在皮革上投影排样结果和成品归属信息（按颜色、尺寸、款号区分），大大降低了分拣出错率。这是 UI/UX 设计中一个重要但容易被忽视的亮点。

## 八、竞品对比框架

### 8.1 Teseo vs 其他厂商定性对比

| 维度 | Teseo (NEMESI) | Lectra | Gerber | 中国厂商 |
|------|---------------|--------|--------|----------|
| **AI 排样** | ANN 1000+ 节点，业界首创 | 有 AI 方案 | 有限 | 起步阶段 |
| **云端架构** | 私有云 TKM | 混合云 | 主要本地 | 极少 |
| **排样速度** | <3 秒 | 未知 | 未知 | 数分钟级 |
| **软硬件一体** | 是（全栈自研） | 是 | 是 | 部分 |
| **中国市场** | 几乎空白 | 有布局 | 有布局 | 主场 |
| **价格定位** | 高端（按节省付费） | 高端 | 中高端 | 中低端 |
| **皮革专注度** | 100% 皮革 | 多材料 | 多材料 | 多材料 |

### 8.2 Teseo 的核心竞争壁垒

1. **35 年皮革专业积累**：从 1987 年就专注于皮革，而非泛化的面料切割
2. **全栈自研整合**：CAD → 排样 → AI → 云端 → 扫描 → 切割，全链条自主控制
3. **ANN 定制架构**：非通用深度学习，而是针对排样场景的专用神经网络
4. **数据飞轮**：15+ 年 / 数十万张皮革的训练数据，且持续增长
5. **私有云部署**：满足汽车 OEM 的极端数据安全要求

### 8.3 Teseo 的潜在弱点

1. **私有云瓶颈**：无法像公有云一样全球弹性部署，非欧洲客户延迟高
2. **中国市场空白**：无中文支持、无本地团队、无中国客户案例
3. **封闭生态**：软硬件深度绑定，客户更换成本极高（也可能是优势）
4. **技术不透明**：大量技术细节（框架、语言、数据库、API）不公开，第三方集成困难
5. **定价不透明**：不利于客户快速决策
6. **创新可能放缓**：NEMESI 推出后未见重大更新（2020 至今），可能在吃老本

| **按效果付费** | 降低客户试用门槛 | 高——商业模式的差异化优势 |
| **投影辅助** | 切割后彩色投影辅助分拣 | 高——直接提升生产效率 |
| **数据积累意识** | 15 年数据库持续训练 | 高——越用越好的飞轮效应 |

| 方向 | Teseo 短板 | 中国竞品机会 |
|------|-----------|-------------|
| **中国市场** | 完全空白 | 先发优势、本地化服务 |
| **中文支持** | 无 | 天然优势 |

### 9.3 关键注意事项

1. **不要直接对标 Teseo 的硬件一体化路线**：中国厂商难以在短期内复制 Teseo 的检测台+切割机硬件体系
2. **纯软件路线是可行的**：如果排样软件能兼容多种品牌的扫描和切割设备，反而比 Teseo 的封闭体系更有市场吸引力
3. **AI 能力的建立需要时间和数据**：Teseo 的 15 年数据库是长期积累，中国竞品需要找到加速数据积累的路径
4. **汽车行业是兵家必争之地**：利润率最高、技术门槛最高、数据安全要求最高——需要专门的合规方案
