## 产品定位

AutoNester-L 是一个**纯算法引擎**，通过 API 集成到其他 CAD 系统中。它不是终端用户软件，而是面向**软件开发者和系统集成商**的排样核心能力。

同系列产品：
- **AutoNester-L**：皮革排样（不规则材料+质量区）
- **AutoNester-T**：纺织品排样（卷材规则材料）
- **CutPlanner**：纺织行业生产计划

## 核心功能

### 1. 排样能力

- 任意数量裁片在极短时间内完成最优排样
- 即使复杂约束条件下也能快速出结果
- 材料利用率与经验丰富的手工排版相当甚至更优
- 支持同时在多张皮革上排样

### 2. 质量分区

- 支持最多 **16 个质量等级**
- 皮革上的质量区域（不同部位质量不同）
- 裁片上的质量需求（不同区域要求不同质量）
- 裁片的每个质量区域必须放在皮革同等或更高质量的区域上

### 3. 约束支持

| 约束类型 | 说明 |
|---------|------|
| 孔洞避让 | 自动避开皮革上的孔洞和损伤 |
| 自由旋转 | 支持自由旋转角度 |
| 旋转容差 | 可调节旋转角度容差 |
| 毛向限制 | Nap restriction（毛向/纹理方向约束） |
| 翻转限制 | Flip restriction（是否允许镜像翻转） |
| 预放置件 | 可锁定已放置的裁片 |
| 拉伸区域 | Stretching zone support |
| 多部件裁片 | Multipart pieces |
| 捆绑支持 | Bundle support |
| 目标效率 | 可设定目标利用率 |
| 时间限制 | 可设定计算时间上限 |

### 4. 算法方法

- **模拟退火（Simulated Annealing）**的新变种
- **多次迭代贪心策略** + 高效启发式
- **快速高质量模式识别**
- 局部搜索中使用**全动态和统计方法**进行参数设置
- **分支定界算法 + 线性规划**计算排样质量保证

| 算法领先 | 基于 Fraunhofer 研究所的最新研究成果 |
| 无硬件依赖 | 纯软件，不绑定任何硬件 |

## 商业模式

- **API 授权费**：按项目或按产品授权
- **面向 B2B**：不直接面向终端用户
- **估计价格**：企业级定价，按需报价
- **目标客户**：CAD/CAM 软件开发商、系统集成商

## 优势

1. 算法水平业界领先（Fraunhofer 研究所背书）
2. 16 级质量分区，最精细
3. 约束支持最全面（旋转、毛向、翻转、孔洞、拉伸区等）
4. 纯软件，无硬件依赖
5. 计算速度快，即使复杂约束
6. 提供质量保证（分支定界+线性规划）

## 劣势

1. 不是终端用户软件，需要二次开发
2. 没有可视化界面
3. 德国公司，中国本地支持有限
4. 价格不透明
5. 仅支持 Windows

## 对本项目的威胁与机会
