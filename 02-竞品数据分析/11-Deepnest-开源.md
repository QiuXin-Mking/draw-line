# Deepnest — 开源免费排样软件

> 来源: github.com/deepnest-next/deepnest, deepnest.io | 开源协议: MIT-ish

## 项目概况

Deepnest 是目前最知名的开源、免费排样桌面应用。基于 SVGNest 开发，使用 C 语言编写核心排样引擎以实现高速运算。支持 Windows / Mac / Linux。

## 发展历程

```
Jack000/SVGnest → Jack000/Deepnest → Dogthemachine/Deepnest
→ cmidgley/Deepnest → deepnest-io/Deepnest（⚠️ 已废弃）
→ deepnest-next/deepnest（✅ 2024 年起活跃维护）
```

## 核心特性

- 🚀 全新排样引擎，核心用 C 语言编写，速度快
- 📐 合并公共切割线（激光切割优化）
- 📁 支持 DXF 文件导入
- 🧩 路径近似功能，可处理极其复杂的零件形状
- 🔄 支持零件旋转（自由角度）
- 📦 支持"零件套零件"（part-in-part 排样）
- 🖥 桌面应用，非浏览器端

## 皮革排样适用性

根据 2024 年俄罗斯高校发表的学术对比分析：

| 能力 | Deepnest | SVGNest |
|------|----------|---------|
| 皮革排样可行性 | ✅ 可行 | ❌ 零件重叠 |
| 非矩形材料排样 | ✅ 支持任意形状 | ❌ 不支持 |
| 固定方向排样 | ✅ 可固定角度 | ❌ |
| 与 Python 集成 | ✅ 可作为 Python 库 | ❌ |

### 关键优势
- 支持**任意形状材料轮廓**排样（而非仅矩形）
- 可将皮革划分为不同区域，分别放置不同优先级的零件
- 可固定多边形方向，适配皮革纹理各向异性
- 论文最终推荐将其作为 **Python 库集成到皮革切割机控制系统**

## 局限

- 不支持真皮瑕疵/质量分区（这是所有开源方案的共同短板）
- 不支持切割路径生成（只排样，不出刀路）
- 不支持 DXF 直接导出（需要转换）
- UI 较为简陋，不像商业软件
- DXF 支持有限，主要针对 SVG
- 没有订单模型、报表等功能

## 关键启示

1. **开源引擎可以作为我们的底层**：Deepnest 的排样引擎（C 语言）可以作为 Python/C# 库调用，减少从零开发的成本——但 Phase 1 不建议，因为我们已有自研引擎
2. **Part-in-part 排样是差异化功能**：把小件嵌在大件的孔洞里，进一步提升利用率
3. **任意形状材料排样是未来方向**：从矩形料 → 真皮不规则外形，这是产品升级的自然路径
4. **社区活跃度是关键**：选择 deepnest-next 分支而非已废弃的原版

## 对我们 Phase 1 的参考价值

- **中低**。Deepnest 是开源方案，功能不如我们的 Demo 完整（没有 DXF 导出、利用率报告），但它的排样算法设计思路值得参考：
  - 遗传算法 + 局部搜索的混合策略
  - Part-in-part 排样
  - C 语言加速核心计算
