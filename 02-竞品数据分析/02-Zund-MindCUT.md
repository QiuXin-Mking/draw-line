## 产品架构

```
Mind 软件套件
├── MindCAD Part Scan    → 裁片数字化扫描（特征识别）
├── MindGEST PDM         → 产品数据管理（订单、版本、工作流）
├── MindCUT Studio       → 排样与切割控制中心
│   ├── Model Importer   → 模型矢量文件导入与分类
│   ├── 材料数字化       → 皮革轮廓、瑕疵、质量区采集
│   ├── 排样引擎         → 手动/交互/全自动排样
│   └── 切割控制         → 控制 Zünd 切割机 + 投影 + 相机
└── Dectura              → 自动化皮革瑕疵检测（2025 新品）
```

## 核心功能详解

### 1. 皮革数字化（Material Capture）

- 自动检测皮革轮廓、瑕疵和最多 **5 个质量区**
- 支持交互验证和修正
- 可定义拉伸方向
- 精确计算皮革面积，与供应商面积对比控制成本
- 支持 inline（在切割机上）和 offline（独立工作站）两种工作流

### 2. 排样（Nesting）

- **手动排样**：鼠标拖拽旋转、排列
- **交互排样**：半自动辅助
- **全自动排样**：针对天然材料的高级算法
- 支持离线排样（多张皮分配多个订单）
- 考虑已定义的瑕疵区域和质量区
- 支持 scan-to-order 和 scan-to-stock 两种模式

### 3. 纺织品特殊功能

- **Pattern Matching**：自动识别格子、条纹等重复图案并精确对位
- **Printed Cut**：数码印花面料的轮廓切割
- **Feature Recognition**：自动识别图案特征并重复排列

### 4. 切割与分拣

- 控制 Zünd 全系列切割机
- 控制材料进给/推进系统
- 控制投影和相机系统
- 支持取料和后处理功能

### 5. 数据管理（MindGEST PDM）

- 集中管理设计、生产和切割数据
- 版本控制和测试数据功能
- 连接多台切割机
- ERP 软件接口
- Dashboard 监控切割流程

## 技术特点

| 特点 | 说明 |
|------|------|
| 模块化架构 | 按需购买模块，从样品到批量生产均可覆盖 |
| 开放架构 | 可与第三方 CAD/ERP/PDM 集成 |
| 独立运行或集成 | 可 standalone 也可接入生产线 |
| 在线+离线 | 支持 inline 和 offline 工作流 |
| 永久许可证 | 一次购买永久使用，年付维护费获取更新 |

## 商业模式

- **软件许可证**：一次性购买，永久使用权
- **年度维护**：年付，确保最新版本
- **捆绑销售**：常与 Zünd 切割系统一起销售
- **估计价格**：€15,000-50,000+（取决于模块配置）

## 优势

1. 行业标杆，全球鞋类和皮革行业最知名的切割系统
2. 软硬件深度集成，端到端解决方案
3. 模块化设计，灵活扩展
4. 强大的数据管理和工作流能力
5. 持续创新（Dectura 2025 新品）

## 劣势

1. 价格高昂，中小企业难以承受
2. 通常需搭配 Zünd 切割硬件（€50,000-200,000+）
3. 中国本地服务依赖代理商，响应速度有限
4. 系统复杂，学习曲线陡峭
5. 过于重量级，对于仅需排样软件的客户是"杀鸡用牛刀"

## 对本项目的威胁与机会

| 维度 | 分析 |
|------|------|
| 直接竞争 | 低——Zünd 客户通常购买整套硬件系统 |
| 间接竞争 | 中——Zünd 定义了行业标准，客户会拿我们与之比较 |
| 机会 | 大量中小鞋厂买不起 Zünd，但需要类似功能 |
| 学习点 | 质量分区、瑕疵避让、inline/offline 双工作流 |
