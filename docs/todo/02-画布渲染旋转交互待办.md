# 画布渲染：旋转角度 + 完整交互（待办）

> 状态：**规划中，暂缓实现**。本文件记录画布渲染的后续目标——支持**旋转角度**与**完整交互**（节点拾取、拖动、旋转手柄）。当前画布任务（`08-13-workbench-canvas-rendering`）只做**只读渲染 + 缩放平移**，本待办在此基础之上演进。

## 设计原则

1. **先看后编辑**：先让用户能看到裁片几何与位姿，再逐步加交互；本待办是「能看」之后的「能动手」阶段。
2. **旋转是排样的核心**：排样位姿含平移 + 旋转角，画布必须能可视化并编辑旋转，否则人工微调无法闭环。
3. **交互与几何分离**：命中检测、拖拽、旋转只改「位姿/节点」，不重写几何引擎；提交仍走统一的 `PlacementValidator`/命令校验。
4. **坐标系一致**：旋转角统一用度（CCW 为正），与 `Transform2D.RotationDegrees`、`placement.rotation` 对齐。
