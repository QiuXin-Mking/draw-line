## 现状概述

命令统一走 `AppShellViewModel`：

- `IsPlaceholderAction=true` → `Select(模块)` + `ShowTodo`（状态栏 TODO）。
- `IsPlaceholderAction=false` → 仅 `Select(模块)`；但中心 overlay 仅 M02 可见（`AppShellView.RefreshModuleOverlay` 里 `IsVisible = CurrentModule.Id == "M02"`），其余模块切换无可见效果。
- `Launch=NewBoardSettings` → 触发 `BoardSettingsRequested` 事件弹窗（「新建排版」已接）。

**关键差异（双轨现状）**：CAD 编辑类命令的**键盘快捷键**已通过 `CadWorkspaceHost.ExecuteShortcut`（`CadShortcutRouter` → `CadShortcutCatalog`）实现了一部分——撤销/回撤/取消/旋转/移动为真实调用，剪切/复制/粘贴/全选/反选/删除/镜像/组合/取消组合/导到订单/手动排版等仍落到 `default → ReportUnsupported`。而**菜单 / 右键菜单**入口则全部走 `ActivateMenuCommand → ShowTodo`，未与快捷键执行路径打通。接线时应复用 `ExecuteShortcut` 的已有真实路径，避免重复实现。

## 建议实施顺序

1. **接线已实现的编辑命令**：撤销/回撤/取消选择 → 让菜单/右键菜单走 `CadWorkspaceHost.ExecuteShortcut` 的既有路径（低成本、立即可用）。
2. **实现 CAD 编辑类剩余命令**：剪切/复制/粘贴/全选/反选/删除/镜像/组合/取消组合/导到订单/按类型选择/删除外部/清空全部 → 补齐 `ExecuteShortcut` 里的 `default` 分支并接线。
3. **导航类命令可见化**：把「订单管理 / CAD工具 / 范围缩放 / 设置窗口」等 `IsPlaceholderAction=false` 但无可见效果的导航，接到真实模块内容展示（`RefreshModuleOverlay` 目前只显示 M02）。
4. **排样/导出类**：开始/停止/取消排版、等宽长条、更新皮料、发送切割、导入/导出排版进度、导出统计报表 → 依赖真实求解器与导出能力。
5. **设置/帮助/工具类对话框**：设置窗口、系统配置、软件授权、关于、实时投影/看板、串口工具、语言切换。

## 验收约定

- 每接一条命令，把 `ShellTopCommands.cs` 中对应 `IsPlaceholderAction` 由 `true` 改 `false`（或加 `ShellCommandLaunch`），并同步更新 `TopCommandAreaTests` 的对应断言，防止「真实动作却被测试当作占位」。
- 禁止伪造成功：未接的命令必须继续走 `ShowTodo`，不得宣称完成。
