# 裁片模型统一待办

> 状态：进行中。snapshot session 已停止，#2–5 待认领。

## 背景 / 现状

当前两个裁片模型并存，字段重叠、迟早冲突：

| 类型 | 层 | 字段 | 问题 |
|---|---|---|---|
| `Application.Domain.Piece` | Domain | `Id, Name, Size, Outline` | 业务件，只有单条 `Outline`，无孔/内部线 |
| `Geometry.PieceGeometry` | Geometry | `Id, Outer, Holes, Lines` | 几何聚合，有完整几何，但无业务字段（Name/Size） |

`NestingProjectFactory.cs` 里用 `using PieceEntity = LeatherNesting.Application.Domain.Piece;` 别名临时顶着歧义。

## 决策（已定）

统一方向：**`PieceGeometry` 当纯几何值对象（无 Id，身份 = `Outer.StableId`），`Piece` 当业务实体引用它**。

```csharp
// Geometry 层（纯几何）
public sealed record PieceGeometry(Loop2D Outer, IReadOnlyList<Loop2D> Holes, IReadOnlyList<InternalLine> Lines);

// Application.Domain 层（业务实体）
public sealed record Piece(string Id, string Name, string Size, PieceGeometry Geometry);
```

理由：Geometry 层不放业务字段；Domain 已依赖 Geometry（`Outline` 是 `Loop2D`），引用 `PieceGeometry` 是自然延伸；Infrastructure 的 geometry reader 返回纯 `PieceGeometry`、不返回 Domain 实体，层间干净。
