# JSON 输出契约（待办）

> 状态：**暂缓实现 · 字段待定**。JSON 的具体字段尚未确定，需先与下游切片软件确认其实际接受的 schema（字段名、命名规范、坐标/单位约定）再冻结字段。下方字段清单为**草稿**，仅作设计参考，不代表最终契约。

## 设计原则（输出精神）

1. **通用性优先**：JSON 面向所有主流切片软件，字段语义通用，避免厂商私有字段。
2. **与 DXF 同构**：JSON 承载的信息与 DXF 输出一致，两者只是序列化形式不同，保证可互转、可对照。
3. **自描述**：字段命名清晰，显式带单位（毫米）、坐标系约定（原点/方向）、schema 版本号，下游无需猜测。
4. **可扩展**：预留扩展位（瑕疵区、纹路方向、part-in-part 等），新增字段不破坏旧版本解析。
