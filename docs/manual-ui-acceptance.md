## 1. 启动方式

在仓库根目录执行：

```bash
cd /Users/qiuxin/code/划线软件-叔叔
dotnet run --project src/LeatherNesting.Desktop/LeatherNesting.Desktop.csproj
```

首次运行需要恢复依赖时，先执行：

```bash
dotnet restore LeatherNesting.sln --locked-mode
```

自动测试和构建命令：

```bash
dotnet test LeatherNesting.sln --no-restore
dotnet build LeatherNesting.sln --no-restore
```
