## 2. 人工验收（手动冒烟）

启动程序：

```bash
dotnet run --project src/LeatherNesting.Desktop
```

按下面步骤操作，每一步对照「预期」。

### 步骤 2.1 启动
- **操作**：运行上面的命令。
- **预期**：窗口打开，进入 DXF 导入界面，无「缺少 .NET」弹窗，无未处理异常。

### 步骤 2.2 新建项目
- **操作**：新建项目，命名 `Stage1-Smoke`。
- **预期**：项目创建成功。

### 步骤 2.3 导入 `凉鞋.dxf`
- **操作**：选择 `凉鞋.dxf`（在仓库根目录）并执行「检查」。
- **预期**：列出声明单位、图层与诊断信息；能看到 9 个闭合裁片候选（不显示为空）。

### 步骤 2.4 确认毫米
- **操作**：确认单位按毫米处理。
- **预期**：项目 revision 变为 `1`，状态变为「未保存」，且恰好新增 1 条导入记录。

### 步骤 2.5 保存 → 重开
- **操作**：保存到**含中文和空格**的路径，关闭程序后重新打开该 `.lnproj`。
- **预期**：项目名、revision、来源 SHA-256 与导入记录都在。

### 步骤 2.6 再次保存 → 验证备份
- **操作**：改动后再次保存同一项目。
- **预期**：目录下出现 `.lnproj.bak`；打开它是上一份完整版本。

### 步骤 2.7 导入 `38.DXF`（异常样本）
- **操作**：选择 `03-测试数据/划线/38.DXF` 并检查。
- **预期**：报告阻断性的「开放 POLYLINE」诊断，**绝不**静默闭合、也**不**当成闭合裁片导入。

### 步骤 2.8 取消导入
- **操作**：在导入过程中「取消」。
- **预期**：不新增 revision、不新增导入记录，项目保持不变。
