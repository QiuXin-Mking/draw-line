# ADR：技术栈选择 C#/.NET + Avalonia（弃 C++/Qt）

Status: accepted（2026-08-15）

## 背景

皮革排样软件存在两条技术路线：

1. **C#/.NET + Avalonia**（本项目路线）—— 托管运行时，一套代码跨 macOS / Windows。
2. **C++/Qt**（参照软件 AXTNester 的路线）—— 原生编译，被 Windows 专有组件锁死在 Windows 单平台。

在启动排样软件开发前，需要对技术栈做出方向性决策，并明确其部署、跨平台、可维护性与逆向防护的权衡。

## Decision

**选定 C#/.NET + Avalonia 作为本软件的技术栈**，不采用 C++/Qt。

核心理由：

1. **macOS 原生开发** —— C#/.NET 可在 Mac 上原生编译、运行、调试，满足开发者在 Mac 上开发与验证的需求。
2. **端到端测试** —— 开发机（Mac）即可完成从 UI、几何计算到 DXF 输出、安装包的全链路端到端测试，无需依赖 Windows 环境。
3. **跨平台一套代码** —— Avalonia 一次编码，同时产出 macOS 与 Windows 版本。

## 理由与权衡

### 部署与安装（C# 更省事）

- **C#/.NET**：自包含发布（`dotnet publish -r osx-arm64 --self-contained` / `-r win-x64`）产出可双击的 `.app`（Mac）或文件夹（Win），目标机器**零运行时依赖**，升级即替换文件。唯一 Mac 特有成本是代码签名 + 公证（notarization），这是所有 macOS 应用都需面对的规则，非 .NET 特有。
- **C++/Qt（AXTNester 现状）**：手动 DLL 堆（40+ 个，257MB）+ `RegMxDrawX.bat` 注册 COM + `regDriver.bat` 装加密狗驱动 + 插 USB 加密狗，且仅 Windows。此部署方式更脆弱、更不可跨平台。

### CAD / DXF 能力（弃商业 OCX，选开源组合）

- 参照软件使用商业 MxDraw OCX（ActiveX，Windows-only，编辑版约 2.7 万元），与本项目跨平台路线冲突。
- 本项目采用 **`netDxf`（MIT，C# DXF 读写）+ `SkiaSharp`（矢量渲染）** 开源组合替代，零成本、零绑定、Mac/Win 通吃，满足「渲染 2D 轮廓、选中/移动/旋转、导出 DXF」的窄需求，无需完整 CAD 内核。
- DXF 输出约定（颜色码区分线角色、仅几何线不含刀路）见 [`01-dxf-adapter.md`](./01-dxf-adapter.md) 与 [`02-职责.md`](./02-职责.md)。

### 逆向防护（C# 相对 C++ 更易被反编译，属已知代价）

- C# 编译为 IL + 元数据，`dnSpy`/`ILSpy` 可一键反编译回接近源码；C++ 为原生机器码，需 Ghidra/IDA 反汇编，难度显著更高。
- 这是 .NET 固有特性，**不构成选型否决项**。缓解策略（后续商业化时按需启用）：
  - 混淆器（ConfuserEx / .NET Reactor）—— 挡外行，不挡内行；
  - **NativeAOT** —— 编译为原生机器码、不带 IL，逆向难度对齐 C++（Avalonia 的 AOT 支持尚不完全成熟，需验证）；
  - **核心排样算法下沉到 native（C++/Rust）+ C# 只做 UI** —— 保住开发效率的同时拿回 C++ 级防护；
  - **授权：加密狗 / 在线激活 / 授权服务** —— 保护产品而非代码，参照软件即采用此路线。

## Evidence and limits

- 参照软件 AXTNester（`07-逆向软件/`）为 Windows x64 PE，Qt5 + OpenCV 4.2 + MxDraw OCX，被加密狗与相机 SDK 锁死在 Windows；其 DXF 输出颜色码约定与本项目一致。
- 本项目已具备 DXF 适配器（`IDxfReader` / 自研 `AsciiDxfReader`），DXF 链路已起步，无需引入商业 CAD 控件。
- 逆向防护为开发期可缓，商业化前再定「是否下沉 native / 是否上加密狗」，当前不阻塞功能实现。

## Consequences

- 技术栈收敛为 C#/.NET + Avalonia，排样算法、几何计算（Clipper2）、DXF 输出均在托管代码实现，Mac 上可端到端验证。
- 部署采用自包含发布，发布矩阵为 `osx-arm64`（+ 可选 `osx-x64` / universal）与 `win-x64`；Mac 分发需走签名 + 公证。
- 逆向参照软件 AXTNester 的方法与边界见 [`04-逆向axenester算法.md`](./04-逆向axenester算法.md)。
- 若未来排样算法成为核心商业资产，再评估将算法下沉 native 或引入加密狗授权；当前不引入，保持 C# 开发效率与跨平台优势。
