# ADR：逆向参照软件 AXTNester 的排样算法思路

Status: accepted（2026-08-15）

## 背景

参照软件 AXTNester（`07-逆向软件/`）是同行商业皮革排样软件，Windows x64、Qt5 + OpenCV 4.2 + MxDraw OCX。本项目为独立实现的 C#/.NET + Avalonia 软件，需要提取 AXTNester 的**排样算法思路**（而非代码）来补充本项目尚未完善的排样能力。

逆向对象明确为**算法逻辑**，目标是把算法配方与思路还原成本项目可独立实现的规格，而非照搬二进制或源码。

## Decision

采用 **「参数解析 + 黑盒观测 + 关键函数定位」三管齐下** 的逆向方法，边界严格限定为「理解算法思路 → 独立实现」，**不照搬代码、不绕过其授权**。

### 方法与优先级

1. **参数解析（最值钱，已部分泄露）**
   解析 `ini/NestOnlyParam.ini`，还原优化目标函数、约束规则与等级体系：
   - 成本函数权重（`area_weight` / `level_weight` / `core_weight` / `uf_weight` / 各 `*_penalty_weight`）→ 反推搜索与评分结构；
   - 等级体系 A1 > B2 > C3 > D4 > E5 及裁片/皮料等级匹配、吃料/吃瑕疵规则（已在 `msg` 字段明文）。
2. **黑盒观测**
   在 Windows 真机/虚拟机运行参照软件，喂同一批裁片/皮料输入，观测 DXF 输出、`.axlog` 日志、`.axn` 生产进度，反推行为。
3. **关键函数定位**
   用 Ghidra + `strings`/符号分析核心 DLL（`AXTControler_x64.dll` / `AXYControler_x64.dll`），定位排样算法入口与关键类/函数名。

### 产出

- 排样算法**参数规格文档**（`docs/` 下），作为本项目排样模块的实现参考。
- 还原出的算法思路在本项目 C# 代码中**独立重新实现**，产出质量对齐，而非复制。

## Evidence and limits

- AXTNester 主程序与核心 DLL 为**未加壳/未混淆**的普通 x64 PE，可抽字符串；但算法逻辑在机器码中，完整逐行还原成本高（数周至数月）。
- `NestOnlyParam.ini` 已明文暴露优化目标函数与等级规则，逆向中最费劲的「目标函数长什么样」已免费拿到大半。
- DXF 输出颜色码约定与本项目一致（见 [`01-dxf-adapter.md`](./01-dxf-adapter.md)）。

## Consequences

- 逆向目标是「算法思路/配方」，不是「可运行的等价源码」；本项目排样模块为独立实现，避免法律风险。
- 逆向成果以文档形式沉淀，供排样算法实现阶段引用。
- 涉及商业软件的授权边界：不得绕过 AXTNester 的加密狗授权，不得复制其代码或资源。
