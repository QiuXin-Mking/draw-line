# UI 演示走查脚本（12–15 分钟）

## 演示边界

本脚本演示 12 个可导航模块和已有真实 DXF 导入链路。除 M02 的 DXF 检查、毫米确认、取消、项目保存和进入工艺工作台外，其余页面主要是显式标记为 `DEMO` / `TODO` 的交互原型。演示数据、模拟排样、质量报告预览和导出清单均不可作为生产结果。

建议使用仓库内合法 DXF 夹具，并提前准备一个临时 `.lnproj` 保存路径。不要在演示中把“模拟完成”“可审批（DEMO）”或 manifest 预览称为真实算法、审批或文件导出成功。

## 演示前检查（1 分钟，不计入主流程亦可）

1. 运行 `dotnet test LeatherNesting.sln` 和 `dotnet build LeatherNesting.sln --no-restore`。
2. 运行 `dotnet run --project src/LeatherNesting.Desktop/LeatherNesting.Desktop.csproj`。
3. 将窗口设为 1366×768、100% 缩放，确认左侧 12 个入口、顶部命令栏、右侧检查器和底部状态栏可见。
4. 另按“人工视觉验收”章节检查 125% / 150%；这两档不能由当前自动测试可靠证明。

## 主流程（约 13 分钟）

### 0:00–1:00　Shell 与能力边界

- 指出左侧 M01–M12 的稳定分组和顺序。
- 切换 M01 → M03 → M01，说明同一页面实例被缓存，切回后保留页面内可见状态。
- 指出状态栏的 `DEMO` 提示；点击顶部“运行”或“导出”，展示右侧检查器中的 `TODO · 尚未接入业务逻辑`，说明命令不会伪造成功。

### 1:00–2:00　M01 项目与订单

- 展示项目摘要、订单字段、版本时间线、最近变更、导出历史和状态轨迹。
- 点选历史版本查看只读差异。
- 点击“审批”或“恢复”，强调只出现 TODO 提示，不写入真实项目。

### 2:00–5:00　M02 真实 DXF 导入入口

- 新建项目，选择合法 DXF，点击“导入 DXF”。
- 展示声明单位、实体种类、候选裁片、图层和诊断等级；确认未确认单位时不能进入工艺工作台。
- 演示一次“取消导入”，确认检查结果被清除且项目没有半导入数据；重新检查后点击“确认毫米并导入”。
- 保存为临时 `.lnproj`，说明保存由真实项目存储实现完成。
- 点击“进入工艺工作台”，展示真实读取闭合轮廓后的工作台入口。
- 指出定位诊断、自动修复、批量图层映射、多文件和非 DXF 仍是 TODO。

### 5:00–6:00　M03 CAD 画布

- 展示深色画布、对象树、图层/类别、标尺、坐标和图例。
- 切换类别可见性并执行“全图”；说明当前几何是 DEMO，框选、多选和曲线编辑未接真实文档。

### 6:00–7:00　M04 几何修复

- 展示诊断问题、修复工具和修复前后差异预览。
- 演示预览、取消、提交后的撤销/重做状态。
- 强调手势工具、批量修复和项目持久化提交仍为 TODO；这里不等同于已保存修复。

### 7:00–8:00　M05 工艺与码齿

- 展示普通工艺特征与码齿规则库是两个独立模型，并展示已有剪口验证结果。
- 点击创建/保存/码齿生成/刀具映射，确认均显示 TODO 且不改变数据。

### 8:00–9:00　M06 裁片订单

- 展示缩略信息、搜索、排序、“仅未完成”、计划/已放/未放和放置约束。
- 修改一个演示数量或做批量选择；强调仅改模块内存，保存订单和真实排样回写未接入。

### 9:00–10:00　M07 材料

- 切换片料/卷料，说明字段差异；展示多材料摘要、边缘、间距、方向和层数。
- 输入空值或负数展示字段错误；有效修改也仅为 DEMO 内存状态，不会令方案真实过期。

### 10:00–11:00　M08 排样运行

- 展示策略、时间预算、角度、顺序、随机种子和小件填空选项。
- 推进准备 → 运行 → 发现更优 → 完成，并对比“停止保留演示最佳”和“取消回滚模拟进度”。
- 明确该时间线未调用自动排样算法、未生成生产方案，指标均为 DEMO。

### 11:00–12:00　M09 排样复核

- 展示材料画布、实例、完成率、利用率、未放原因和版本比较。
- 切换材料或版本，并打开碰撞叠加示例。
- 点击移动/旋转/镜像/锁定，确认仅出现 TODO；不得称为已通过真实碰撞或边界校验。

### 12:00–13:00　M10 校验与审批

- 切换“有阻断项”和“无阻断项”演示场景，展示错误/警告/提示、对象、规则与建议。
- 确认阻断场景禁用审批/生产出口；无阻断场景仍标 DEMO/TODO。
- 预览质量报告并说明真实全量校验、豁免签名、审批持久化和 PDF 均未接入。

### 13:00–14:00　M11 导出交接

- 展示 DXF、JSON/CSV、PNG/PDF 选择，命名、目录、单位、原点、图层映射和 manifest 预览。
- 切换阻断/可预览场景；说明“生成交接包”只生成内存预览，不写文件。
- 强调外部程序、PLT/DWG 和设备发送永不在此演示中执行。

### 14:00–15:00　M12 管理与收束

- 展示项目规则快照与最新预设的区别、审计时间线、角色权限和系统设置。
- 切换角色展示权限不足原因；编辑设置后指出仍未持久化。
- 收束：本轮完成的是可导航 UI 演示壳和真实 M02 入口，不等于父 PRD 的生产级自动排样、审批与导出已验收。

## 人工视觉验收（必须单独记录结果）

在 macOS 与 Windows x64（若可用）分别检查：

1. 1366×768、100%：12 页逐页进入，主要标题、主操作、TODO/DEMO 警示无截断；需要滚动的页面可以触达底部。
2. 1366×768、125%：左导航、顶部命令栏、检查器和状态栏不互相覆盖；横向密集表格仍可辨识或有可用滚动路径。
3. 1366×768、150%：同上，并确认 M02 的确认/取消/工作台入口、M08 的停止/取消、M10/M11 的阻断原因可见。
4. 键盘 Tab 顺序可到达主要按钮；错误、阻断和 TODO 不能只依赖颜色表达。

当前自动测试只证明默认窗口尺寸、模块构造/导航和实例缓存；它不证明操作系统 DPI 缩放后的像素布局。未实际执行上述人工步骤时，结果必须记录为“待人工验收”。
