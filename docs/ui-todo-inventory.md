# UI DEMO / TODO 台账

## 判定规则

- `真实`：当前 Desktop 组合入口实际调用已有 Application / Infrastructure / Geometry 能力。
- `演示`：只读样例或模块内存状态，必须显示 `DEMO` 或 TODO 说明，不得作为生产证据。
- `TODO`：未接业务逻辑；点击只允许解释、预览或改变演示状态，不得显示未限定的“成功”。

## 无伪成功核对清单

- M08 的完成/最佳结果同时可见 `TODO · 模拟状态` 和“未运行自动排样算法”。
- M09 的碰撞、利用率与完成率明确属于 DEMO，手调不会更改真实放置。
- M10 的“准备审批”和报告预览保留 `DEMO` / `TODO` 限定，未生成签名或 PDF。
- M11 的交接包只预览，不写文件、不启动外部路径、不发送设备。
- 所有未实现 Shell 命令通过 `TodoBadge.StandardText` 解释，不发布成功状态。
