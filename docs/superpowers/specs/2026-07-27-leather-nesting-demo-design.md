# 皮革鞋面自动排样 Demo 设计

## 目标

提供一个可离线运行的 Python Demo：读取 `凉鞋.dxf` 中的 9 个固定鞋面外轮廓，在三种矩形皮革规格内自动排样，并为每种规格输出 DXF、PNG 预览和利用率报告。

## 已确认的业务约束

- 输入材料：`凉鞋.dxf` 中的 9 个闭合 `LWPOLYLINE` 鞋面外轮廓；将其作为 9 个可重复的尺码供料。
- 皮革尺寸：`2000 × 1000 mm`、`2000 × 4000 mm`、`2000 × 9000 mm`。
- 摆放姿态：允许 0° 和 180°，不镜像。
- 默认工艺间隙：裁片之间和皮革边缘均为 `5 mm`，可由命令行参数调整。
- 首版不处理瑕疵、纹路/毛向、人工拖拽、裁片数量表和真实皮革轮廓；这些是后续扩展项。

`凉鞋.dxf` 的 DXF 头部单位标记为英寸，但其几何比例与鞋面毫米尺寸一致。因此 Demo 默认将坐标按毫米解释，并在命令行中明示这一假设。

## 方案选择

采用确定性的“按尺码循环的货架填充”启发式排样。

1. 从 DXF 提取闭合外轮廓并计算面积、边界框和顶点。
2. 按尺码轮次重复选择裁片，在当前货架行从左到右放置；行满后向上开启下一行，直到所有尺码均无法放入。
3. 以外接框分隔保证轮廓不相交和最小边距，并交替使用 0°/180° 姿态。
4. 将已放置的原始轮廓平移到结果 DXF；皮革边界、裁片编号和统计信息写入单独图层。

这是首版在可解释性、实现成本和对不规则轮廓支持之间的平衡。它不是全局最优算法；生产级版本可加入旋转/镜像约束、No-Fit Polygon、局部搜索或模拟退火。

## 组件与数据流

```text
凉鞋.dxf
   ↓  DXF 解析与校验
9 个 Polygon（毫米）
   ↓  固定方向候选生成 + 碰撞/间隙检查
每种皮革规格的 placements / unplaced
   ├─→ `2000x1000.dxf` 等生产交换文件
   ├─→ `2000x1000.png` 等验收预览
   └─→ terminal / summary.json（利用率、未放入项）
```

实现使用当前环境已有的 `ezdxf` 和 Pillow；几何碰撞与间距判定使用项目内纯 Python 实现，不要求联网或额外安装依赖。Pillow 用于避免 Matplotlib 首次构建字体缓存而拖慢现场演示。

## 命令行接口

```bash
python3 leather_nesting_demo.py \
  --input 凉鞋.dxf \
  --output-dir demo_output \
  --gap-mm 5 \
  --leather 2000x1000 2000x4000 2000x9000
```

程序为每种皮革规格生成同名 DXF、PNG 和汇总 JSON。重复执行会覆盖 `demo_output` 中同名的 Demo 产物。

## DXF 规则与错误处理

- 只接受至少 3 个点且闭合的 `LWPOLYLINE`；非闭合线和 `TEXT` 只记录为被忽略项。
- 少于一个有效外轮廓、皮革尺寸/间隙非正数、无效尺寸文本会显示可读错误并退出非零。
- 单个裁片无法装入时保留在 `unplaced`，不阻塞其他裁片排样。
- 输出文件使用毫米单位标记，并按图层区分皮革边界、裁片和标注。

## 验收与测试

- 单元测试覆盖：DXF 外轮廓提取、鞋面面积、边界和间隙碰撞、左下排序、无法装入时的行为、三种尺寸解析。
- 集成测试以 `凉鞋.dxf` 运行：产生 3 份 DXF、3 张 PNG、汇总 JSON；各已放裁片均在皮革边界内，任意两片无相交且间隙不小于设定值。
- 手工验收：打开 PNG 或 DXF，可清楚查看皮革矩形、9 个鞋面轮廓、编号和利用率。
