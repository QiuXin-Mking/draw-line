# F区域说明

F区域是“排版输出信息”统计面板，用于展示当前排版结果的利用率、材料尺寸及耗用统计。

## 界面内容

- 中央显示一个圆形占比图，当前利用率为 **0.00%**。
- 右下角图例包含两项：
  - 黄色：已利用
  - 青绿色：未利用
- 面板下方显示材料尺寸、层数、面积、片数、单耗、总耗和当前耗时等统计字段。

## 截图中可见的数据

| 字段 | 可见内容 |
| --- | --- |
| 材料尺寸（第一组） | 宽约 1.380 × 长约 1.600；层数 1 |
| 材料尺寸（第二组） | 宽约 1.509 × 长约 1.750 |
| 面积 | 已利用面积显示为 0.00 平方米；材料面积约 2.21 平方米 |
| 片数 | 0 |
| 单耗 | `inf` |
| 总耗 | 约 2.2080 |
| 当前耗时 | 截图中未显示具体数值 |

## 功能含义

当前截图反映的是一个尚未放置有效裁片的排版结果：已利用面积为零，因此利用率为 **0.00%**；材料仍有约 **2.21 平方米**的可用面积。片数为 0 导致单耗显示为 `inf`，该值属于无有效片数时的计算结果。

> 注：以上数据依据 `F区域.jpg` 中的可见文字整理，部分数字因截图分辨率有限，使用“约”表示。
