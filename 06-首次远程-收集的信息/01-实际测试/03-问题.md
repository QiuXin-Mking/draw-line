## A. 术语 / 命名不一致

### Q-01 「撤销 / 回撤 / 返回 / 撤回 / 反向撤回」术语混乱
- **位置**：A 区编辑菜单、CAD 右键菜单、设置快捷键、右上角工具栏
- **原文**：编辑菜单「撤销（Ctrl+Z） 回撤（Ctrl+Y）」；右键菜单「撤销 Ctrl+Z / 返回 Ctrl+Y」；设置「Ctrl+Y：回撤」；右上角「撤回 / 反向撤回」
- **问题**：Ctrl+Y（redo）出现「回撤 / 返回 / 反向撤回」三种叫法；而「回撤」「撤回」在字面上与「撤销」（undo）高度相近，极易混淆。Ctrl+Z（undo）也有「撤销 / 撤回」两种叫法。
- **建议**：统一命名，建议 redo 用「重做」，undo 用「撤销」，其余别名弃用。

### Q-02 组合相关命名不统一
- **位置**：右键菜单 vs 设置快捷键
- **原文**：右键菜单「组合模块 Ctrl+G / 取消组合 Shift+G」；设置「Ctrl+G：组合 / Shift+G：拆解」
- **问题**：同一功能两种叫法（「组合模块」=「组合」，「取消组合」=「拆解」）。
- **建议**：确认正式名称并统一。

### Q-03 「码 / 码数 / 40」语义不明
- **位置**：C 区、D 区、左上角排列表、术语关系
- **原文**：「码 是一个单位」「码数 40」「40 是表明还是组名」「一套鞋面 = 排样组 命名 40」
- **问题**：「码」到底指什么？是鞋码（尺寸）、材料长度单位（码/yard）、还是裁片编码？「40」与「码数」「DXF 名称」「排样组名」的关系不清。
- **建议**：结合 D 区列 3 与左上角排列表，确认「码 / 码数 / 40」三者分别对应哪个实体。

### Q-04 「第二行」一词双关
- **位置**：E 区
- **原文**：E 区「顶部：版型数量：7…第二行新建排版，可以创建，添加数量」
- **问题**：此处「第二行」指 E 区内部的第二行（新建排版按钮），与「B 区 = 第二行」的区域命名撞词，阅读易混。
- **建议**：在整理文档中区分「B 区（第二行工具栏）」与「E 区顶部第二行」，避免歧义。

### Q-05 「设备」疑应为「裁片」
- **位置**：其他记录（CAD 工具导入订单组）
- **原文**：「Cad 工具里面有一个导入订单组的功能，是把 Cad 内选择到的设备全部导入到 D 区域的工作组」
- **问题**：「设备」应为「裁片 / 被排样对象」的口误或笔误。
- **建议**：确认是否指「裁片」。
