## 7. 字段之间的深入联系与物理意义

> 本节为手工深挖（不依赖脚本），结论均由数据交叉验证得出。「观察」是事实，「解释」是推断。

### 7.1 坐标变换链（最核心的联系）

`X / Y / Rotate / Rxx·Rxy·Ryx·Ryy` 与 `Blocks[].Bound.Curve` 不是并列的字段，而是一条**变换链**——它们共同决定了每个部件落在皮革上的实际位置：

```
局部坐标 local=(x,y)   ← Blocks[].Bound.Curve（CAD 导出，带任意偏移）
      │  旋转 R = [[cosθ, −sinθ],[sinθ, cosθ]]，θ=Rotate（度）
      ▼
    R · local
      │  平移 +(X, Y)
      ▼
世界坐标 world = ( X + Rxx·x + Rxy·y ,  Y + Ryx·x + Ryy·y )   ← 面料(皮革)上的实际位置
```

- **X、Y 是「局部原点 (0,0)」在世界坐标里的位置（锚点），不是部件包围盒的角或中心。**
- 证据 1：`40_m8` 部件高约 202mm，其 Y 锚点最大到 16925，但变换后实际 Y 伸到 **16982**——记录的是锚点，几何在锚点之外还伸出一段。
- 证据 2：对全部 2600 条按上式变换，全部落在面料 `x[0.46, 1379.58] × y[0, 16982.48]` 内，无一散落。

### 7.2 Rotate 与旋转矩阵是冗余的

矩阵分量完全由 `Rotate` 推出（θ 单位度）：

| 分量 | 值 |
|------|-----|
| `Rxx` | cos θ |
| `Rxy` | **−sin θ** |
| `Ryx` | **+sin θ** |
| `Ryy` | cos θ |

- 对全部 2600 条校验，最大误差 ≈ 8.7×10⁻¹⁶（机器精度），说明二者是**同一旋转的两种写法**。
- det = Rxx·Ryy − Rxy·Ryx = 1 → **纯旋转，无缩放、无镜像**。
- 每条记录两套都存，纯粹是为了下游直接取用，不用重算三角函数。

### 7.3 Name 是「几何外键」，几何被去重

- 放置记录的 `Name` 字段 = 指向 `Blocks[].Name` 的**外键**，1:1 绑定部件几何。
- 10 个部件几何只在 `data[0]` 出现一次；其余 2599 条通过 `Name` 引用，不重复携带几何。这是典型的**一份几何 + 多份放置**。

### 7.4 Color 是纯展示属性

- `Name ↔ Color` 是**双射**（每个部件一个唯一颜色，反之亦然），不参与变换与几何，只用于画面里区分 10 个部件。

### 7.5 每部件固定「纹理角」，只允许 θ 或 θ+180°（最有物理意义）

| 部件 | 纹理角 θ | 实际放置角 |
|------|---------|-----------|
| `40_m6` | 0° | 0 / 180 |
| `40_m1` | 37.6° | 37.6 / 217.6 |
| `40_m5` | 50.4° | 50.4 / 230.4 |
| `40_m7` | 58.7° | 58.7 / 238.7 |
| `40_m3` | 70.8° | 70.8 / 250.8 |
| `40_m0` | 84.0° | 84.0 / 264.0 |
| `40_m8` | 86.6° | 86.6 / 266.6 |
| `40_m4` | 92.6° | 92.6 / 272.6 |
| `40` | 96.2° | 96.2 / 276.2 |
| `40_m2` | 102.8° | 102.8 / 282.8 |

- **观察**：全部 2600 条只有 **40 个**旋转值；每个部件只出现**一个基准角 θ 和它的 180° 对偶 θ+180°**（±0.03° 是上游 atan 运算的浮点噪声，如 50.44/50.47）。
- **解释（推断）**：皮革/面料有**纹理方向（毛向/grain）**，部件必须沿固定纹理角摆放，只能整体转 180°（掉头，纹理方向不变），不能任意旋转。所以 θ 因部件而异（每个部件在 CAD 里的自然朝向不同），但排样时每部件只有 θ / θ+180° 两个朝向。
- **印证**：`Flip` 全程 `False`——排样不用镜像（镜像会翻面、破坏纹理/毛向）。需要左右对称的部件会做成两个独立几何（`40_m0`…`40_m8` 的 m 编号即部件细分），而不是用 `Flip` 翻转。

### 7.6 字段名与取值的重叠（别混为一谈）

- `Size` / `StyleID` / `Fabric` 全是 `"40"`，且 `Name` 前缀也是 `40`（`40` / `40_m0`…`40_m8`）。本文件是**单款、单码（40 码）**的排样结果；`"40"` 在不同字段里分别代表尺码 / 款号 / 面料号——**恰好同值，但不是同一个概念**。
- `Material` / `MaterialID` / `OrderID` 全是 `"P_00030;ch 0"`：`P_00030` 是款/部件号，`ch 0` 疑似渠道/仓位（channel）0。

### 7.7 物理量纲与排样参数

- 单位是**毫米（mm）**。
- 面料**幅宽 ≈ 1380 mm**（X 锚点范围 [0.46, 1379.58]，与源文件名 `…幅宽1380…` 一致）。
- 排样**长度 ≈ 16982 mm**（Y 锚点最大 16925 + 最高部件 `40_m8` 的 202mm 余量）。
- 源文件名 `…间距1…` → 部件之间排样间距 **1mm**。
- 10 个部件、共 2600 个放置实例：7 个部件各 200 片、3 个部件（`m5/m6/m8`）各 400 片（每「套」用量翻倍，疑似成对/左右件）。
