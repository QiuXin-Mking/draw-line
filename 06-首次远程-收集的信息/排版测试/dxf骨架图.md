## 11. DXF 如何表示这张图（整体模型）

DXF 里**没有「部件」「排样」这些概念**，它只有最底层的二维图元。整张排样图被拆成：

```
平面画布（幅宽 1380 × 长度 6173，模型空间 ENTITIES 段落）
  ├─ LWPOLYLINE × 8400   部件外轮廓 / 切割线 / 标记线
  └─ TEXT × 1000         每个部件旁的尺码标签「40」
```

**没有块、没有 INSERT**——1000 个部件不是「引用同一个块再平移」，而是把每个部件的每条线都**展开成绝对坐标的独立多段线**，平铺在模型空间里。所以一个部件在 DXF 里是**一组彼此无关的图元**，靠「图层 + 颜色」把它们归到同一角色。

每个部件由这几样拼成：

| 图元 | 颜色(62) | 闭合(70) | 数量 | 角色 |
|------|---------|---------|------|------|
| LWPOLYLINE | 0 | 闭合 | 1 条/部件 | 外轮廓 |
| LWPOLYLINE | 3 | 开放为主（4300 开 / 100 闭） | 若干条 | 切割线 |
| LWPOLYLINE | 5 | 闭合 | 若干条 | 标记/刀口（小环） |
| TEXT | 8 | — | 1 个/部件 | 尺码标签「40」 |

> 三种线角色（外轮廓 / 切割线 / 标记线）的介绍与真实原文，单独放在最后一章 §14。

## 13. 一张图的拼装关系（总结）

```
幅宽 1380 × 长度 6173 的平面画布（绝对坐标，已排好位）
│
├─ 部件 ×1000（每部件一组图元，颜色区分角色）
│     ├─ 外轮廓  LWPOLYLINE(62=0, 70=闭合)  ×1
│     ├─ 切割线  LWPOLYLINE(62=3, 70=开放)  ×N
│     ├─ 标记线  LWPOLYLINE(62=5, 70=闭合小环)×M
│     └─ 尺码标签 TEXT(62=8, 内容"40")      ×1
│
└─ 全部平铺在 ENTITIES 段落，无块、无引用，坐标即最终位置
```

> 一句话：DXF 用「**颜色码区分线角色** + **绝对坐标直接定位置** + **闭合位区分轮廓/切口**」这三板斧，把整张排样图铺成了 8400 条多段线 + 1000 个文字。
>
> 三种线角色（外轮廓 / 切割线 / 标记线）的图元级解剖与真实原文，单独放在最后一章 §14。

## 14. 线角色详解：外轮廓 / 切割线 / 标记线

这三种「线」在 DXF 里**是同一种图元 LWPOLYLINE（多段线）**，差异只落在两个组码上：`62`（颜色 = 角色）和 `70`（是否闭合）。三者的共同骨架：

```
  0  LWPOLYLINE
  5  <句柄>           每个图元的唯一 ID（十六进制）
330  <归属句柄>
100  AcDbEntity       实体通用属性
  8  0                图层
 62  <0 / 3 / 5>      ★ 颜色码 = 线角色
100  AcDbPolyline     多段线属性
 90  <顶点数>
 70  <0 / 1>          ★ 闭合位（bit1）
 43  0.0              恒定线宽
 10 / 20  …           顶点绝对坐标（重复 N 次）
```

| 角色 | 颜色(62) | 闭合(70) | 数量 | 物理含义 |
|------|---------|---------|------|---------|
| 外轮廓 | 0 | 闭合(1) | 1000 | 裁片边界，沿它切出裁片 |
| 切割线 | 3 | 开放(0) 为主，100 条闭合 | 4400 | 裁片内部的切缝 / 挖孔 |
| 标记线 | 5 | 闭合(1) | 3000 | 刀口 / 定位记号（对齐用） |
