## 0. 总览：一个完整的皮革排样流水线

AXTNester 的排样不是纯矢量几何，而是 **「相机拍照 → 图像识别皮料/瑕疵 → 在皮料图像上做排样 → 输出 DXF」** 的混合流水线：

```
相机(GigE 5184×3456)
  → 图像预处理(OpenCV)：高斯模糊 + 阈值 → 提取皮料轮廓 / 瑕疵 / 孔洞
  → 在皮料图像(降采样到 2500×1600)上做排样（多分辨率 raster + 矢量）
  → 输出 DXF（颜色码区分线角色）→ 交给下游 TroCutCAD 切片
```

证据（事实）：
- `camera_resolution_w/h = 5184/3456`，工作分辨率 `format_width/height = 2500/1600`。
- 图像阈值参数：`gaussian_size_w=7`、`remove_bc_thresh=28`、`holes_thresh=25`、`leather_thresh=38`、`edge_flaw_thresh=36`、`edge_flaw_gauss=9`。
- `relation_exe_path=D:/TroCutCAD/AWCPrograms/TroCutCAD.exe`（下游切片软件）。
- `use_gpu_mem=6`（GPU 内存 6GB）→ 排样/视觉用 GPU 加速。

## 1. 成本函数（优化目标）—— 最核心的「配方」

`[NestOnly]` 里的权重字段直接暴露了评分/成本结构。推断排样评分是**加权线性组合**：

```
Score =   uf_weight        × UF(利用率)
        + level_weight     × 等级匹配度
        + core_weight      × 核心区域评分
        + area_weight      × 面积利用率
        + combine_weight   × 合并收益
        + color_weight     × 颜色一致性
        + quality_weight   × 质量分
        + priority_weight  × 优先级
        + pair_weight      × 配对收益
        + mc_*_weight      × 多联(set/mirror/ml)收益
        − level_penalty_weight      × 等级惩罚
        − core_penalty_weight       × 核心惩罚
        − convexhull_penalty_weight × 凸包惩罚
```

| 参数 | 值 | 事实/推断 |
|---|---|---|
| `uf_weight` | **0.99** | 权重最高 → `UF` 是主导项。推断 `UF` = Utilization Factor（利用率），即排样质量的主指标 |
| `level_weight` | 0.5 | 等级匹配权重（皮料等级 vs 裁片等级） |
| `core_weight` | 0.5 | 「核心」区域评分（皮料中心区域优先排高等级裁片） |
| `combine_weight` | 0.5 | 合并/组合收益（裁片合并成一个块再排） |
| `area_weight` | 0.05 | 纯面积利用率（权重很低，说明不是唯一目标） |
| `color_weight` | 0 | 颜色（当前关闭） |
| `quality_weight` | 0 | 质量（当前关闭） |
| `priority_weight` | 0.5 | 裁片优先级 |
| `level_penalty_weight` | 0.48 | 等级不匹配的惩罚（与 level_weight 相对） |
| `core_penalty_weight` | 0.001 | 核心区误占惩罚 |
| `convexhull_penalty_weight` | 0 | 凸包惩罚（当前关闭） |
| `eat_material_weight` | 0.5 | 「吃料」收益权重（裁片吃掉皮料外部/瑕疵） |
| `pair_weight` / `mc_set_weight` / `mc_mirror_weight` / `mc_ml_weight` | 0 / 0.5 / 0.5 / 0.5 | 配对与「多联」组合权重 |

开关（事实）：`core_base_switch_on=false`、`only_eat_flaw_switch_on=false`、`flaw_mode_switch_on=false`、`mc_forced_pair_switch_on=false` —— 说明这些是**可选成本项**，默认关闭。

**推断：** 该算法是一个**带多目标加权评分 + 时间上限的启发式搜索**，核心目标是利用率（UF=0.99），叠加等级匹配、核心区、合并等软约束。

## 3. 等级体系与约束（A1–F6）

这是排样的**硬约束**，直接决定「哪个裁片能排到哪块皮料」。

### 3.1 等级定义

等级从高到低：**A1 > B2 > C3 > D4 > E5**（另有 F6、E5_FLAW）。

每个等级对应一种**皮料/裁片上的区域语义**（事实，来自 `[Notebook] msg` 原文）：

| 等级 | 皮料侧含义 | 裁片侧含义 |
|---|---|---|
| C3 | 画笔瑕疵区域 | 可排到画笔瑕疵部分的裁片（吃瑕疵） |
| D4 | 皮料外部吃料区（按吃料间距自动生成） | 可缺刀部分（吃皮料外部） |
| E5 | 孔洞瑕疵区域 | — |
| E5_FLAW | 瑕疵 | — |
| A1/B2 | 高等级（干净/核心区） | 高等级裁片 |
| F6 | 最低 | — |

### 3.2 匹配规则（事实，原文）

- 裁片 D4 等级可排到 A1、B2、C3、D4 的皮料上；皮料 D4 区域只能排 D4 裁片。
- 裁片 C3 等级可排到 A1、B2、C3 的皮料上；皮料 C3 区域可排 C3、D4 裁片。
- **即：裁片等级 ≤ 皮料区域等级时才能放置**（等级可向下兼容，皮料等级不够则不能放更高要求的裁片）。

### 3.3 相关参数

| 参数 | 值 | 说明 |
|---|---|---|
| `is_level_nest` | true | 启用分级排样 |
| `level_mode` | 0 | 等级模式 |
| `param_level` | 1 | 等级参数 |
| `g_level_mould_undefine` | 5 | 未定义等级的裁片默认等级 = E5（最低） |
| `g_level_leather_undefine` | 1 | 未定义等级的皮料默认等级 = 1（最高 A1？） |
| `level_area_limit` | 50000 | 等级区域面积限制（超过则不分级？） |
| `min_level_width` | 3 | 最小等级区域宽度 |
| `level_expand_val` | 0 | 等级区域扩展 |
| `auto_level_color_A1…F6` | 1…6 | 自动分级对应的颜色码 |

## 6. 按产品类别的超参（bags / shoes / sofas）

`[NestOnly-SuperParam]` 用 `-bags/-shoes/-sofas` 后缀为**三类产品**分别调参，说明算法对产品形态（包袋/鞋/沙发）有不同的最优超参。关键差异：

| 参数 | bags | shoes | sofas | 推断 |
|---|---|---|---|---|
| `param_class` | 1 | 0 | 2 | 当前激活的类别（当前=0，即 shoes） |
| `area_threshold` | 8000 | 400 | 8000 | 面积阈值差异大（鞋类小，包/沙发大） |
| `persent_threshold` | 0.25 | 0.2 | 0.25 | 百分比阈值 |
| `mag_step` | — | 128 | 64 | 分辨率步长 |
| `is_merge` | false | true | false | 鞋类才启用合并 |
| `nesting_holes_switch_on` | false | true | false | 鞋类才启用孔洞嵌套 |
| `fast_calculate_switch_on` | true | true | false | 沙发关闭快速计算 |
| `level_area_limit` | — | 50000 | 50000 | 等级面积限制 |
| `material_step` / `normal_dir_space` | 6 / 32 | 0 / 0 | 0 / 0 | 包袋类启用法向放置 |

## 7. 推断的算法结构（伪代码）

```
Nest(leather_image, pieces, params):
    # 1. 预处理（视觉层）
    leather_contour, flaws, holes, levels = detect(leather_image)
        # 高斯+阈值分割皮料；CNN 识别瑕疵/等级；提取孔洞

    # 2. 初始布局（粗尺度，A 级优先）
    sort(pieces, by level desc, area desc)          # leveA_first + 优先级
    for piece in pieces:
        cands = gen_candidates(piece)                # 角度分块(angle_block_num=5)、
                                                     # 法向方向(normal_dir)、倾斜范围(±30°)
        place(piece, best_cand by Score)             # 加权成本函数
        if nesting_holes: try place into holes        # 孔洞嵌套
    # 3. 改进循环（限时 anytime）
    while time < nest_time_limit:
        fine_tune()        # 微调位置/角度 (is_fine_tuning_first)
        extrude(step=15)   # 挤紧/推挤
        replace(rule=2)    # 替换已放裁片
        merge()            # 合并成块 (is_merge, combine_weight)
        group_progressive()# 分组渐进
        score = evaluate() # UF(0.99) + level(0.5) + core(0.5) + ...
        keep_best()
    # 4. 输出
    export_dxf(colors by role) → TroCutCAD
```
