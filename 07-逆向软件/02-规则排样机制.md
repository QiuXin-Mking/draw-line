# AXTNester 规则排样机制（阵列排样）

> 来源：
> - `06-首次远程-收集的信息/01-实际测试/01-功能.md`（现场实测笔记，【事实】）
> - `07-逆向软件/AXTNester_extracted/AXTNester/ini/NestOnlyParam.ini`（配置参数，【事实】）
> - 部分为逆向推断，标 `推断：`。
>
> 本文件是对 `01-排样算法参数规格.md` 的**方向性修正**：AXTNester 的排样本质是**规则排样（阵列/规则阵列）**，而非不规则（自由角度）排样。01 文档中「NFP / 法向 / 任意角度」的解读应降级为次要或推断项。

---

## 1. 术语界定：规则排样 vs 不规则排样

| | 规则排样（本软件） | 不规则/自由排样 |
|---|---|---|
| 裁片朝向 | 固定方向：水平 / 垂直 / 水平+垂直 / 固定角度 | 任意角度自由旋转 |
| 排列方式 | 成行成列、阵列、横向排列、填充 | 紧贴轮廓交错咬合 |
| 典型算法 | 网格 / 阵列 / 行列排布 / guillotine | NFP + 遗传/模拟退火 |
| 利用率 | 中等（92% 级别） | 更高，但更慢、更复杂 |

AXTNester 实测证据（事实）：
- CAD 右键菜单只有 **手动排版（F5）/ 区域阵列排版（F7）/ 区域混合排版（F8）** 三种，无「自由排样」。
- 属性窗口「任意角度」实际只能设为 **水平、垂直、水平+垂直、固定角度**；另有「微动角度」上限 360°。
- 工具栏提供 **横向排列** 与 **填充**。

## 2. 排样模式（三种 + 自动）

### 2.1 手动排版（F5）
人工拖拽裁片到 CAD 画布，手动摆放。右键「导到订单」把摆放结果提交为订单。

### 2.2 区域阵列排版（F7）—— 规则排样的核心
在选定区域内，把裁片按**阵列**复制排布。推断：给定一个或多个裁片，按行列间距（`mould_space`、附加间隔）成阵列铺满区域。

### 2.3 区域混合排版（F8）
多个不同裁片**混合**进同一区域做阵列排布（多裁片组合成一个排版单元再阵列）。

### 2.4 自动「新建排版」
新建排版弹窗只要求两个输入（事实）：
1. **版型名称**
2. **版型方向**

随后生成**排版单元**列表，每个单元展示（事实）：
```
序号：1｜面积：13.08m｜使用率：92.0%｜片数：250片｜分辨率：1500*2718*1 - 无限长
```

- `使用率 92%` 是规则排样的典型水平，也是它的**唯一核心质量指标**。
- `分辨率 1500*2718*1`：材料宽 1500 × 长 2718 × **1 层**；`- 无限长` 表示支持**卷料（无限长）**。

## 3. 排样单元 / 数据模型

实测笔记里「码 / 片 / 套 / 组」的层级（事实 + 推断）：

| 术语 | 含义 | 证据 |
|---|---|---|
| 裁片 | 单个被排样对象（DXF 闭包轮廓，对应 长×宽） | 「码数 40 对应 dxf 名称」 |
| 码 | 尺码单位 | 「码 是一个单位」「码数 40」 |
| 鞋面 | 被排样单元（同一鞋款的部件集合） | 「鞋面 = 被排样单元」 |
| 排样组 | 一套鞋面，命名「40」 | 「一套鞋面 = 排样组 命名 40」 |
| 片 | 排出的总片数 | 「片数 250 片」 |

推断：排样以「**组（套）**」为单位，一个组内包含多个码/裁片，按规则阵列铺开；「片数」是输出总件数。

## 4. 角度与翻转约束（规则排样的关键）

| 参数/UI | 值 | 说明 |
|---|---|---|
| 任意角度（UI） | 水平 / 垂直 / 水平+垂直 / 固定角度 | **仅四种朝向**，非自由旋转 |
| 微动角度（UI） | 上限 360.0° | 在基础朝向上的小角度微调 |
| 优先级（UI） | 0 | 用户标注「不理解」，推断为朝向冲突时的裁决权重 |
| `angle_block_num` | 5 | 角度分块数 |
| `angle_incline_range` | 30 | 角度倾斜范围 ±30°（推断为微动范围） |
| `is_limit_flip` | true | **限制翻转**（禁止镜像，只允许旋转） |
| `is_aotu_order` | true | 自动排序（按面积/优先级确定放置顺序） |

**推断：** 规则排样的朝向空间很小——每个裁片只有水平/垂直（+微动）等少数候选，而不是连续角度。这大幅简化了碰撞检测与搜索，也是规则排样快、但利用率上限 92% 左右的原因。

## 5. 阵列与填充机制

### 5.1 横向排列（工具栏）
裁片沿水平方向一行一行排布，行内等间距，行间等间距（`mould_space`）。

### 5.2 填充（工具栏）
勾选后自动把裁片**填满**选定区域（皮料可用区），推断是阵列排布的自动版——把可用区按裁片包围盒切成网格填满。

### 5.3 相关参数（INI）

| 参数 | 值 | 含义 |
|---|---|---|
| `is_tile_first` | false | 是否先平铺（当前关） |
| `is_open_tile_array` | true | 启用平铺阵列 |
| `mould_space` | 0 | 裁片间距（阵列步距） |
| `material_indent_val` | 3 | 材料内缩（皮料边界内缩 3） |
| `adsorb_val` | 20 | 吸附距离（20 内吸附到边/邻件） |
| `extrusion_switch_on` / `extrusion_step` | true / 15 | 推挤挤紧（阵列后挤紧提利用率） |
| `is_merge` | true | 合并成块再阵列 |
| `check_colliding` | true | 碰撞检测 |

## 6. 版型方向与材料

`[DlgTextileBoardSetting]` 与新建排版「版型方向」对应：

| 参数 | 值 | 含义 |
|---|---|---|
| `textile_dir` | 1 | 版型方向（纹路/毛向） |
| `format_width` / `format_height` | 0 / 1360 | 材料尺寸 |
| `layer_num` | 6 | **层数**（多层叠裁，规则排样典型特征） |
| `layer_incomplete` | 1 | 层 incomplete 处理 |
| `mould_space` | 2 | 裁片间距 |

`[TextileParam]` 里的规则排样专用参数（推断其对应阵列/格栅算法）：

| 参数 | 值 | 推断含义 |
|---|---|---|
| `nest_engin` | 0 | 排样引擎选择 |
| `nest_angle` / `nest_angle_range` | 2 / 0 | 固定角度 / 角度范围=0（无自由旋转） |
| `orthLat` | false | 正交格栅 |
| `latOnly` | false | 仅格栅 |
| `latInnerAlign` | 1 | 格内对齐方式 |
| `seqMode` | 3 | 序列模式 |
| `regularTail` | false | 规则尾料 |
| `crossAgminated` | false | 交叉聚集 |
| `genGnf` | false | 生成 GNF（纹路排样因子） |
| `avoid_gaps` | false | 避免间隙 |
| `max_overlap` | 500 | 最大重叠量 |
| `force_complete_groups` | 0 | 强制整组完整 |

## 7. 排样组与订单工作流

实测笔记里的完整链路（事实）：

1. **订单窗口**（左）列出排样组；双击「编辑整组订单」把组内物料导入 CAD 工具。
2. **CAD 工具**里新建/打开/另存、替换皮料；右键「导到订单」把 CAD 内选中设备导入 D 区工作组。
3. 订单窗口提供：切换显示模式、编辑、编辑整体、统一名称、**添加裁片 / 添加镜像 / 删除镜像 / 删除裁片 / 删除余量 / 重置余量 / 旋转裁片 / 设置整组角度 / 修改填充颜色 / 自动填充颜色 / 排序**。
4. 属性窗口：任意角度（水平/垂直/水平+垂直/固定角度）、微动角度 360°、优先级、插刀（单套/套数/余量/附加间隔/偏好量）。

## 8. 与 01 文档的修正对照

| 01 文档原解读 | 修正后 |
|---|---|
| 强调不规则排样（NFP / 法向 / 任意角度） | **规则排样为主**：阵列/横向排列/填充，朝向仅水平/垂直/固定角度 |
| `normal_dir_space` 视为 NFP 法向放置 | 降级为推断项，可能只是特定类别的次要参数 |
