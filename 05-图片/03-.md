# 03-.png 控件与布局拆解

## 统计口径

- 截图分辨率约 1955×1274，竞品实际运行在远程 Windows 桌面中。
- 统计分为“竞品主窗口”和“Windows 原生打开文件对话框”。原生文件对话框应调用系统 API，不需要在 Avalonia 中仿制。
- CAD 微型工具条已用同目录 `10.54.06`、`10.54.10`、`10.54.12`、`10.54.15`、`10.54.18` 等连续截图交叉核对：编辑模式下可见 27 个图标按钮，另有“填充”复选框与数值框，共 29 个交互实例。图标数量可确定，但部分专业语义仍需实机悬停或操作确认。
- `交互控件` 指按钮、菜单、输入框、选择器、树/列表、复选框、单选框等；`展示控件` 还包括标签、标尺、状态条和进度条。

## 总数结论

| 范围 | 可交互控件 | 加上展示控件后的可见元素 |
| --- | ---: | ---: |
| 竞品主窗口 | 约 95–105 | 约 120–135 |
| Windows 原生文件对话框 | 约 35–45 | 约 40–50 |
| 整张截图 | 约 130–150 | 约 160–180 |

因此，这不是一个“左导航 + 12 个现代卡片页面”的界面，而是一个高密度 CAD 单窗口工作台。复刻 UI 时应首先复刻单窗口结构、命令密度和面板比例，再将 12 个业务模块映射到菜单、工具命令、停靠面板和模式切换中。

### 精细计数说明

进一步按“屏幕上每一个独立按钮、输入框、树节点、列表行均计为一个实例”复核后，竞品窗口约有 **102–112 个可交互实例**。前面的 95–105 是将树节点、CAD 连续图标组和颜色格合并为逻辑控件后的保守值。开发排期应采用下面两个口径：

| 口径 | 竞品主窗口数量 | 用途 |
| --- | ---: | --- |
| 逻辑组件 | 约 78–88 | ViewModel、组件类和测试拆分 |
| 屏幕控件实例 | 约 102–112 | UI 工作量、Tab 顺序和视觉验收 |

原生文件对话框覆盖了中央画布约 46% 的可见面积，因此画布中部是否存在浮动菜单、选中对象或其他图形无法从本图确认。

## 信息可信度标记

| 标记 | 含义 | Agent 使用规则 |
| --- | --- | --- |
| `明确` | 文字、边框或状态能从截图直接辨识 | 可直接写入 UI 与验收 |
| `高可信推测` | 图标和所在工具组能够合理确定功能 | 可作为 TODO 名称，不能声称真实功能已确认 |
| `低可信推测` | 仅能看出按钮存在，无法辨识具体语义 | 先用 `CAD 工具 01…` 占位，等待其他截图佐证 |
| `被遮挡` | 被系统文件对话框完全覆盖 | 不得凭空补设计 |

#### 工具条统一状态与验收规则

1. 按钮常态约 22–25 px 方形，浅灰底、1 px 深灰边框；组间使用 3–5 px 空隙或竖分隔线，不使用大圆角卡片。
2. 当前工具用蓝色描边/浅蓝底表示。连续截图中鼠标、范围缩放、多段线、矩形分别出现过蓝色选中边框，可作为视觉基准。
3. 每个按钮必须有 tooltip；明确项使用上表名称，未确认项必须附 `TODO待实机确认`，不得把推测伪装成竞品事实。
4. 绘图工具互斥：任一时刻只能有一个 active tool。切换工具时要取消尚未提交的预览，不产生半成品对象。
5. `Esc` 的第一层行为是取消当前步骤，第二次才回到鼠标选择；圆圈 `×` 与取消当前命令一致，垃圾桶只删除选中对象，两者不可混淆。
6. 撤销、重做、删除、局部擦除都必须由同一历史服务管理；没有历史或选中对象时显示禁用态。
7. 排样/结果模式仅保留选择、撤销、重做、取消、删除、设置，其他 21 个专业编辑工具必须隐藏而非挤成第二行。
8. 演示版允许按钮无真实 CAD 算法，但点击后必须在状态栏或轻量提示中显示 `TODO：功能名`；不得弹出“成功”或产生伪造业务数据。

## Windows 原生打开文件对话框

中央白色窗口不是竞品自绘控件。它约有 35–45 个交互元素：

- 标题与关闭按钮。
- 后退、前进、上一级。
- 地址栏、刷新、搜索框。
- 组织、新建文件夹、视图、帮助。
- 左侧位置导航树约 10 项。
- 文件表格及名称/日期/类型/大小列。
- 文件名输入框。
- 文件类型下拉框。
- 打开、取消。
- 两个滚动条。

复刻方案：使用 Avalonia `StorageProvider.OpenFilePickerAsync` 调用系统文件选择器；Windows 上自然呈现 Windows 对话框，macOS 上呈现 Finder 选择器。不要手工绘制截图中的 Windows 对话框。

## 第一阶段 UI 复刻验收

2. 左侧固定对象/组树约 260 px。
3. 中央黑色画布常驻，占剩余区域主体，带横纵标尺和单行 CAD 图标工具条。
4. 右侧固定参数检查器约 300 px，控件密度和分组与截图一致。
5. 底部显示数量、面积、进度、利用率和版本信息。
6. 所有未实现动作保留 `TODO`，但视觉上使用工具提示/状态栏提示，避免满屏现代 TODO 卡片破坏竞品风格。
7. 文件打开使用系统原生选择器。
