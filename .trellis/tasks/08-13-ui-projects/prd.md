# UI M01 项目订单

## Goal

实现项目与订单中心的演示页：项目摘要、订单信息、版本时间线、变更及导出历史。

## Requirements

- 只拥有 `Modules/Projects/` 与对应测试目录。
- 字段、状态、TODO 行为以父任务 `implement.md` T01 为准。
- 所有写入/审批/恢复动作必须显示 TODO，不能更改真实项目数据。

## Acceptance Criteria

- [ ] UI 数据来自共享 `DemoScenario`。
- [ ] 项目状态和版本时间线完整可读。
- [ ] TODO 操作不写入且显示文本说明。
