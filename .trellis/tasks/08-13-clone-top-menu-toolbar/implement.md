6. 运行 Desktop 测试、解决方案构建及 `git diff --check`；复核 1366×768 视觉结构与未提交用户文件不受影响。

## 风险点与回滚点

- Avalonia 图标几何语法或控件测量可能造成运行时布局问题；每组图标需有构造测试并保持独立文件，便于回滚。
- 工具栏不得直接持有模块页面内部 ViewModel，否则会破坏现有缓存和状态边界。
- `05-图片/` 与 `docs/manual-ui-acceptance.md` 是用户已有未提交内容，不在本任务中修改。
