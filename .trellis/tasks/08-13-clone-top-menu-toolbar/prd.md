# 复刻参考图顶部菜单与图标工具栏

## Goal

以 `05-图片/01-.png` 为视觉基准，把当前 Avalonia 桌面 Shell 顶部区域改造成传统 Windows CAD/排版软件的两级命令区，使用户一眼看到与参考软件一致的信息架构，并能通过图标快速识别常用动作。

## Background

- 当前顶部区域位于 `src/LeatherNesting.Desktop/Shell/AppShellView.cs`，只有“导入、新建、打开、保存、运行、停止、取消、导出”一排纯文字按钮。
- 当前项目未发现现成图标资源或统一图标组件；本任务需提供可跨平台渲染、无需外部图片文件的图标方案。
- Shell 已有 12 个业务模块和统一的 `AppShellViewModel` 导航/TODO 提示机制，可复用这些入口，不能另造一套页面状态。
- 参考截图中的顶部区域由一级菜单与大图标工具栏两层组成。

## Requirements

### R1 一级菜单

- 顶部第一行严格按以下顺序显示：`文件`、`编辑`、`操作`、`绘制`、`数据库`、`工具`、`设置`、`帮助`。
- 菜单行采用紧凑、浅灰背景、传统桌面软件风格，不沿用当前大间距按钮外观。
- 由于目前没有下拉项资料，八个菜单只建立可展开入口；展开后统一显示清楚的 `TODO · 菜单内容待补充` 占位项，不推测或虚构子菜单。

### R2 图标工具栏

- 第二行严格按以下顺序显示：`新建排版`、`订单管理`、`CAD工具`、`开始排版`、`停止排版`、`取消排版`、`范围缩放`、`设置窗口`、`等宽长条`、`发送切割`。
- 十个入口全部具有独立、清晰、与动作语义对应的图标，图标在文字上方，文字在下方。
- 图标统一采用参考图接近的青绿主色，并用少量辅助色区分停止、取消、发送等高辨识动作；尺寸、线宽、按钮宽度和间距保持一致。
- 图标使用 Avalonia 矢量几何或代码绘制，避免依赖字体图标和外部网络资源，保证 macOS/Windows 显示一致。
- 工具栏允许在窗口宽度不足时横向滚动或保持所有命令可访问，不得静默裁掉右侧入口。

### R3 命令行为与诚实演示

- 工具栏入口按现有能力映射：`新建排版`、`订单管理` → M01 项目与订单；`CAD工具` → M02 DXF 模板导入；`范围缩放` → M03 CAD 画布；`开始排版`、`停止排版`、`取消排版` → M08 排样运行；`设置窗口` → M12 管理；`等宽长条` → M05 工艺特征；`发送切割` → M11 导出。
- `CAD工具` 遵循竞品资料 `02-竞品数据分析/02-银象科技/语音正式转文字/01-界面描述.MD:56-59`：先打开模板导入流程，选择并导入当前已支持的 DXF 文件；导入确认后复用页面现有“进入工艺工作台”能力。未知文件格式继续保持 TODO，不推测支持范围。
- 上述入口只负责进入对应业务页面；不跨过页面内已有状态门禁直接模拟执行开始、停止、取消或发送动作。
- 可复用现有模块或真实命令的入口直接导航现有能力，不创建重复业务状态。
- 尚无真实实现的动作继续使用现有 TODO 提示合同，点击后必须说明“演示占位，未接入实际逻辑”，不得显示虚假成功。
- 顶部改造不得破坏现有 12 模块导航、模块 Control 缓存、Workspace snapshot、导入流程及状态栏/检查器刷新。

### R4 视觉边界

- 复刻重点是截图中的顶部两级结构、标签顺序、图标化方式、紧凑尺寸、分隔关系和 Windows CAD 软件质感。
- 删除当前由 M01–M12 纯文字按钮组成的左侧占位导航；顶部工具栏成为主要快捷入口，中央工作区扩展并占用释放的宽度。
- Shell 启动时默认选择 M03 CAD 画布，使 CAD 画布位于顶部命令区下方的正中央主工作区；右侧检查器保持独立窄列。
- 不在本任务中重做参考图中的项目树、中央画布、右侧参数面板、底部状态栏或整个应用主题。

## Acceptance Criteria

- [ ] 1366×768 验收视口下，顶部清晰呈现菜单行和工具栏行，顺序与 R1/R2 完全一致。
- [ ] 十个工具栏入口均同时显示独立图标和中文标签，图标不存在字体缺字或跨平台替换风险。
- [ ] 菜单/工具栏整体外观与参考图同类：浅灰背景、紧凑排列、青绿图标、细分隔线、图标上文字下。
- [ ] 八个一级菜单均可展开，且在缺少资料时只显示明确的 TODO 占位项。
- [ ] 订单管理、CAD工具、范围缩放、设置窗口等可承接入口复用现有模块或能力；其中 CAD工具进入 M02 DXF 模板导入，范围缩放返回 M03 CAD 画布；未实现入口点击后显示标准 TODO 限制说明。
- [ ] 小窗口下十个入口仍可访问。
- [ ] 12 模块发现及切换、M02 真实导入入口、模块实例缓存行为不回归。
- [ ] 左侧不再显示 M01–M12 的 TODO 占位导航，主工作区从窗口左侧开始布局。
- [ ] 启动 Shell 后中央主区域默认显示 M03 CAD 画布；通过其他工具入口切走后，`CAD工具`/`范围缩放`可回到中央 CAD 画布。
- [ ] 增加自动化测试，锁定两级标签集合与顺序、十个图标存在、关键命令映射以及 1366×768 布局合同。
- [ ] Desktop 测试与解决方案构建通过。

## Out of Scope

- 本任务不实现新的排版算法、设备通信、真实切割发送、数据库或等宽长条业务逻辑。
- 本任务不要求逐像素复制第三方商标、专有图标位图或操作系统窗口边框。
- 本任务不新增参考图左侧项目树，也不重构 Shell 之外的业务模块页面。
