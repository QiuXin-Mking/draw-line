# 技术设计

## 边界

改动集中在 Desktop Shell 与 DesignSystem：Shell 负责两级顶部布局及命令路由，DesignSystem 提供统一的矢量图标和顶部区域颜色/尺寸。业务模块保持原样，所有导航继续经过 `AppShellViewModel.Select`，TODO 提示继续经过 `ShowTodo`。

## 组件

- `AppShellView`：把现有单排文字按钮替换为菜单行和横向可访问的图标工具栏。
- 顶部命令描述：用稳定的标签、图标键和目标模块 ID 描述十个入口，作为渲染与测试的单一来源。
- 矢量图标工厂/控件：基于 Avalonia `Path`、`Geometry` 和基础图形构造十个不同图标，不依赖字体或网络资源。
- `AppTheme`：补充传统桌面工具栏所需的浅色背景、边框、悬停及图标色。

## 行为

八个菜单展开时只显示不可误解的 TODO 占位内容。十个工具按钮点击后导航到 PRD 指定模块；开始、停止、取消、发送等按钮不直接操作模块内部状态，避免绕过页面门禁或制造成功假象。

## 兼容与回滚

保留 Shell 的三列工作区、模块缓存、Workspace 订阅与检查器/状态栏逻辑。若新顶部布局出现问题，可独立回滚 Shell 顶部构造和新增图标文件，不涉及业务数据迁移。
