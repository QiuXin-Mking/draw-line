# UI M10 校验审批

## Goal

实现校验问题、审批和质量报告的演示页。

## Requirements

- 只拥有 `Modules/Validation/` 与对应测试。
- 显示阻断/警告/提示、规则、对象定位入口、审批和报告预览。
- 真实全量校验、豁免签名、审批持久化、PDF 均为 TODO。

## Acceptance Criteria

- [ ] 阻断问题使审批/生产导出入口禁用或 TODO。
- [ ] 问题包含对象、规则和建议。
- [ ] 报告显著标记 DEMO。
