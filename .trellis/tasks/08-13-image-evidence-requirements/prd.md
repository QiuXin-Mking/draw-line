# PRD：鞋材 CAD 自动排样桌面软件（截图证据驱动的功能对标版）

**版本**：1.0
**用途**：作为实现 Agent 的唯一验收材料；Agent 可自行选择技术实现，但不得弱化本文的可观察行为。
**证据来源**：`05-图片/` 的 27 张鞋材排样软件截图。此前误放入的两张 KnowLoop 图片已从该目录删除，不属于本系统范围。
**相关证据细节**：`research/image-evidence-software-requirements.md`。

## 1. 目标与成功标准

交付一个可在 macOS 和 Windows x64 运行的本地桌面软件，使鞋材/皮革工厂用户能够从 DXF 裁片完成：**导入诊断 → 工艺检查 → 裁片订单设置 → 材料设置 → 自动排样 → 人工复核 → 校验 → DXF 和报告导出**。

成功不以“有窗口、能画几个形状”衡量，而是以以下结果衡量：

1. 用户可用真实 DXF 创建可保存、可重复打开的项目。
2. 排样结果满足边界、碰撞、间距、数量、方向/镜像等硬约束。
3. 用户能看懂每种裁片要多少、排了多少、还差多少、用了多少材料、为何未完成。
4. 所有生产导出都来自已通过校验的项目版本，并可追溯输入、参数、结果和操作者。
5. UI 达到专业 CAD 工作台应有的信息密度、画布交互、层次和反馈质量；不以第三方产品的品牌/版式/图标/文案像素级复制为验收条件。

## 2. 范围与边界

### 2.1 本期必须交付

- 项目文件及版本化保存。
- DXF 导入、诊断和裁片识别。
- CAD 画布、裁片清单、工艺线可视化。
- 裁片数量、优先级、角度、镜像、间距等订单约束。
- 矩形片料和定宽卷料的材料模型。
- 可取消的自动排样和可解释结果。
- 人工微调与同一套约束校验。
- DXF、JSON/CSV 报告导出；PNG 预览可作为附加导出。
- 规则预设、审计日志、错误处理和中文路径支持。

### 2.2 明确不在本期

- 直接复制 AXTNester 或任何第三方的名称、品牌、图标、配色、排版、菜单文本、资产、私有协议、源代码或未知算法。
- DWG/PLT 的完整读写、切割机/投影仪直连、云协同、视觉瑕疵识别、非矩形真皮边界优化；这些仅可保留可扩展接口。
- 把“AI/智能/最优”等词作为没有可测约束、指标和失败处理的空壳功能。

### 2.3 允许的视觉对标标准

实现须采用原创视觉系统，但须具备截图中所体现的专业能力：深色 CAD 画布、可停靠/可调整的裁片列表和属性面板、清晰的工具状态、缩略图、标尺、图例、运行进度和结果仪表。评审关注工作效率与信息可读性，不做像素级 UI 比对。

## 3. 用户、术语与主流程

| 角色 | 目标 |
| --- | --- |
| 工艺员 | 导入 DXF，识别外轮廓与内部工艺线，修复或标记问题裁片。 |
| 排样员 | 填订单数量与材料条件，运行/停止排样，手工调整方案。 |
| 主管 | 检查完成率、材料利用率、未放置原因，批准和导出。 |
| 管理员 | 维护材料、排样、导出预设和权限。 |

术语：**裁片**为一个可生产的二维形状；**实例**为裁片的一次实际放置；**材料**为可排样的片料或卷料；**方案**为一次完整排样输出；**硬约束**为任何时候都不能违反的几何或订单规则。

```text
项目创建 → 导入 DXF → 诊断/确认单位与裁片 → 编辑工艺与订单约束
→ 配置材料与排样策略 → 运行/停止并保留有效结果 → 人工微调
→ 完整校验 → 批准版本 → 导出 DXF + 生产报告
```

## 4. 交付物

实现 Agent 必须交付：

1. 可构建、可运行的 macOS 与 Windows x64 桌面程序，或明确记录任一平台暂未通过的原因。
2. 自动测试（领域逻辑必须自动化；UI 至少包含关键流程冒烟测试）。
3. `docs/user-guide.md`：从 DXF 导入到生产导出的操作步骤和截图。
4. `docs/acceptance-evidence.md`：逐项填写下文 AC 编号、测试数据、命令/步骤、结果截图或日志、是否通过。
5. 至少 3 个可公开提交的 DXF 测试夹具：合法多裁片、带内部线/孔、包含可诊断异常的数据。
6. 一份可复现的演示项目和其导出 DXF、JSON/CSV 报告、校验报告。
7. `research/image-transcriptions/`：`05-图片/` 中每一张截图对应一份独立 Markdown 转写，包含画面结构、文字、确认事实、功能推测、未证实项与验收启示，并以索引文件关联。

## 5. 功能需求与验收标准

### F01 项目、保存与版本

**行为**

- 用户可新建、打开、保存、另存项目。项目保存原始文件指纹、裁片、订单、材料、规则快照、方案、导出记录和审计记录。
- 项目状态为：草稿、待排样、排样中、已完成、校验失败、已批准、已导出。排样中禁止破坏性编辑。
- 每次自动排样、人工调整、批准、导出形成可追溯版本；历史版本只读，复制后才能继续编辑。
- 取消、文件缺失、权限拒绝、磁盘空间不足、项目格式不兼容，都必须产生用户可理解的错误与恢复建议。

**验收**

| ID | 验收步骤 | 预期结果 |
| --- | --- | --- |
| AC-F01-01 | 新建项目，导入夹具，保存，关闭后重新打开。 | 裁片、材料、订单、方案和指标完全恢复。 |
| AC-F01-02 | 运行排样后修改一个数量并保存。 | 历史方案不被覆盖；新状态显示为待排样/参数已变化。 |
| AC-F01-03 | 把项目引用的原始 DXF 移走后打开项目。 | 提示具体文件缺失，并允许重新定位或使用已锁定副本。 |

### F02 DXF 导入与诊断

**行为**

- 第一版必须支持 DXF 的闭合 `LWPOLYLINE`、旧式 `POLYLINE`、`LINE/ARC` 组合及受控曲线离散化。
- 导入界面/结果必须显示：源文件、单位推断、实体计数、图层、候选外轮廓、孔、内部工艺线、文本/标注、孤立对象和诊断数。
- 对开放轮廓、自交、零面积、重复边、过短边、异常比例、单位缺失或冲突，显示严重性、原因、画布定位和处理选项；禁止无提示丢失或自动封闭。
- 内部统一以毫米工作；源单位、换算因子和用户确认记录在项目中。
- 导入可取消，取消后不得留下半导入裁片。

**验收**

| ID | 验收步骤 | 预期结果 |
| --- | --- | --- |
| AC-F02-01 | 导入合法多裁片 DXF。 | 显示正确的裁片数、缩略图和画布对象。 |
| AC-F02-02 | 导入包含内部线和孔的 DXF。 | 外轮廓、孔、内部工艺线可分别查看和计数。 |
| AC-F02-03 | 导入开放/自交轮廓夹具。 | 显示可定位诊断；无效裁片不能进入排样。 |
| AC-F02-04 | 导入单位缺失或比例异常样本。 | 要求确认单位，保存确认值与换算记录。 |

### F03 CAD 工作台与裁片工艺

**行为**

- 画布支持缩放、平移、缩放到全图/选择、标尺、坐标读数、框选、多选、删除选择、撤销/重做。
- 裁片清单显示缩略图、名称/编码、状态、数量摘要；与画布选择双向同步。
- 用户可按外轮廓、孔、内部工艺线、冲孔/切口、方向线、文字/标记及源图层切换显示、锁定和选择。
- 系统允许映射或调整对象类别；每次修改要保留审计记录并重新做几何有效性检查。
- 颜色只用于辅助，不是唯一业务含义；对象类型、错误和选中状态必须有文字或图例。

**验收**

| ID | 验收步骤 | 预期结果 |
| --- | --- | --- |
| AC-F03-01 | 在列表选择裁片、在画布选择裁片。 | 两个位置高亮同步，缩放到选择对象。 |
| AC-F03-02 | 隐藏内部工艺线并重新显示。 | 仅显示变化；外轮廓和几何数据不改变。 |
| AC-F03-03 | 做一次类别或几何修改后撤销。 | 画布和诊断恢复到修改前状态。 |

### F04 裁片订单与放置约束

**行为**

- 每种裁片提供：启用、名称/编码、尺寸和面积（计算值）、缩略图、需求数、已放数、未放数、优先级、单套数、附加间距、允许角度集合、允许镜像、方向规则、备注。
- 支持批量勾选与统一设置、搜索/排序、仅看未完成项。
- 数量必须是非负整数，所有统计实时更新。若把需求改小于已放数，须要求用户选择保留超额、删除实例或取消。
- “微动、小件填空、凹凸互锁”等能力只有在具备明确输入、输出、算法/规则和测试时才能呈现；不得用无效果按钮代替。

**验收**

| ID | 验收步骤 | 预期结果 |
| --- | --- | --- |
| AC-F04-01 | 设置三种裁片不同数量后运行。 | 每行准确显示需求/已放/未放及总计。 |
| AC-F04-02 | 批量设定方向或间距。 | 仅影响勾选裁片，未勾选裁片保持原值。 |
| AC-F04-03 | 填写负数、小数或文字数量。 | 字段级报错，不能开始排样。 |

### F05 材料与料单

**行为**

- 支持矩形片料（宽×长）和定宽卷料（宽 + 目标/上限长度）。材料包含名称、编号、宽、长、层数、方向、边缘预留、裁片间距、可用区域和备注。
- 支持一张或多张材料；多张材料有消耗顺序和独立统计。
- 所有方向规则以坐标轴、允许角度集合和镜像许可表达，不以含糊的“横向/纵向”标签代替规则。
- 改变材料或约束后，旧方案必须标记过期且不能作为最新生产方案。

**验收**

| ID | 验收步骤 | 预期结果 |
| --- | --- | --- |
| AC-F05-01 | 尝试使用 0、负数或空材料尺寸运行。 | 明确错误并阻止运行。 |
| AC-F05-02 | 为同项目添加两张材料运行。 | 输出中每张材料都有独立面积、利用率和实例清单。 |
| AC-F05-03 | 改变已完成方案的宽度。 | 方案过期，必须重新排样或恢复旧材料快照。 |

### F06 自动排样与任务控制

**行为**

- 输入为有效裁片、订单、材料和策略；输出为每个实例的材料 ID、坐标、角度、镜像、层号和验证状态。
- 必须严格满足：不超材料可用区、不相交、满足边缘及裁片间距、不超过需求数、遵守方向/旋转/镜像规则。
- 优化目标和优先级必须在 UI 或方案详情可见，最少包括完成率、材料利用率、总用料长度；不得宣称不可验证的“全局最优”。
- 支持时间预算、可用角度、排放顺序、小件填空开关、随机种子或确定性模式。
- 运行状态：准备、运行、发现更优、取消中、完成、未完全满足、失败；UI 不冻结，用户可取消。取消只允许保留已经全量验证的最佳方案。

**验收**

| ID | 验收步骤 | 预期结果 |
| --- | --- | --- |
| AC-F06-01 | 固定同一夹具、参数和种子，连续运行两次。 | 确定性模式产生相同放置和指标。 |
| AC-F06-02 | 运行大夹具后立即点击取消。 | 5 秒内进入取消结果；可编辑项目，无半写入实例。 |
| AC-F06-03 | 使用空间明显不足的材料运行。 | 产生已验证的部分方案，列出未放置裁片与原因。 |
| AC-F06-04 | 对结果运行完整几何校验。 | 0 个碰撞、0 个越界、0 个间距和方向违反。 |

### F07 结果复核与人工微调

**行为**

- 画布应显示材料边界、裁片实例、标签、空余区域、未放置项；支持全局和局部视图。
- 显示已用/未用面积、利用率、材料尺寸/实际用长、计划/已放/未放数量、运行时间、策略、校验结果。若有多材料，分别显示并总计。
- 用户可移动、旋转、镜像、删除、锁定实例；每个动作使用与自动排样完全相同的碰撞、边界、间距、方向、镜像、数量验证器。
- 未完成或低利用率应展示原因和建议；人工调整产生新版本，不覆盖旧方案。

**验收**

| ID | 验收步骤 | 预期结果 |
| --- | --- | --- |
| AC-F07-01 | 手动把一个实例拖至与另一实例重叠。 | 拒绝放置或明确标红；不能批准/导出。 |
| AC-F07-02 | 手动旋转一个方向受限实例。 | 不允许不合法角度；允许的角度会立即重新校验。 |
| AC-F07-03 | 比较自动方案与手动调整后方案。 | 两版本的指标、参数和生成时间可见且可恢复。 |

### F08 校验、批准与导出交接

**行为**

- 生产前校验至少覆盖：几何有效、边界、碰撞、间距、方向、镜像、数量、内部工艺线关联、导出图层/线型映射。
- 严重问题存在时禁止批准和生产 DXF 导出；问题按严重性、对象和可定位链接呈现。
- 必须导出 DXF 以及 JSON 或 CSV 生产报告；DXF 保留/映射外轮廓、孔、内部工艺线、标记、裁片标识和材料边界。
- 报告包含项目版本、输入指纹、材料与订单摘要、策略、利用率、未完成项、校验结论、导出时间、操作者、文件哈希。
- 导出前允许预览单位、坐标原点、旋转、镜像、文字大小、文件名与图层模板。输出使用安全写入，失败不得注册为成功。

**验收**

| ID | 验收步骤 | 预期结果 |
| --- | --- | --- |
| AC-F08-01 | 对含碰撞的手调方案执行导出。 | 导出按钮禁用或失败，且给出碰撞对象定位。 |
| AC-F08-02 | 导出有效演示项目的 DXF 和报告。 | 两文件生成；报告版本和哈希可对应项目。 |
| AC-F08-03 | 在独立 CAD 查看器/解析器加载导出 DXF。 | 可打开；轮廓、孔、内部线和材料边界数量/坐标在定义容差内一致。 |
| AC-F08-04 | 设定不可写目录导出。 | 显示可操作错误，不留下被登记为成功的不完整文件。 |

### F09 规则库、设置与审计

**行为**

- 材料预设、排样预设、导出模板、图层映射、单位策略均可版本化；项目使用规则快照，而非可变的全局引用。
- 审计记录导入、诊断确认、关键参数变更、运行、停止、手调、批准、导出和失败。
- 对外部程序/格式适配仅能配置已注册且经验证的适配器；不能执行用户任意输入的可执行路径。

**验收**

| ID | 验收步骤 | 预期结果 |
| --- | --- | --- |
| AC-F09-01 | 修改材料预设后打开历史项目。 | 历史项目仍使用保存时的规则快照。 |
| AC-F09-02 | 查看已导出项目的审计日志。 | 可追溯何人何时以何参数导出了什么文件。 |

## 6. 非功能质量门

| 领域 | 验收标准 |
| --- | --- |
| 平台 | macOS、Windows x64 能构建与启动；窗口在 1366×768、100%/125%/150% 缩放下没有关键控件被截断。 |
| 响应性 | 导入、排样、导出均不阻塞 UI；长任务显示进度且支持取消。 |
| 精度 | 内部统一毫米与双精度；几何/导出容差写入配置和报告，不可隐式依赖浮点相等。 |
| 可靠性 | 异常退出后仅恢复最后一致状态；项目与导出采用防半写入策略。 |
| 可访问性 | 状态不只用颜色表达；主要功能可键盘聚焦、操作并有可读名称。 |
| 中文环境 | 中文路径、中文文件名、中文裁片名和中文报告正常保存、加载、导出。 |
| 性能基线 | 提交方须公布所用机器、夹具复杂度、导入时长、排样时长、内存峰值；未达成目标不能伪称完成。 |

## 7. 禁止的“假完成”

以下任何一种都视为未完成：

- 只展示静态 UI 或硬编码截图/矩形，不加载并处理真实 DXF。
- “自动排样”只随机摆放、忽略碰撞/间距/边界/方向，或失败时无说明。
- 人工调整绕过与自动排样不同的验证器。
- 改材料/订单后继续把旧方案称为有效。
- 导出按钮始终可用，或可导出无效方案。
- 仅用颜色、无文字/图例表达错误和状态。
- 未记录版本、输入、规则、导出记录，导致无法重现生产输出。
- 用竞品名称、图标、截图、原始文案或像素级界面仿制充当“样式一致”。

## 8. 验收执行顺序与完成定义

验收 Agent 必须按顺序执行：

1. 运行构建与全量自动测试；记录命令、环境、输出。
2. 使用合法 DXF 执行 AC-F01-01、AC-F02-01、AC-F03-01、AC-F04-01、AC-F05-01。
