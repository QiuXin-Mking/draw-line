# 产品功能说明表：鞋材 CAD 与自动排样桌面软件

**版本**：1.0（2026-08-13）
**定位**：面向鞋材、皮革及柔性材料裁切场景的本地桌面软件。将 DXF 裁片转为受工艺、订单和材料约束控制的排样方案，并产出可审计的生产交接文件。
**依据**：`05-图片/` 的 27 张截图及其逐图转写、当前项目 PRD、现有 UI/功能证据模型。截图只证明可见工作流；无法从证据确定的参数语义，均被设计为可配置且待工厂验证，而非硬编码复刻。

## 1. 产品目标与北极星指标

| 目标 | 产品必须实现的结果 | 核心指标 | 不可接受的替代 |
| --- | --- | --- | --- |
| 快速建单 | 用户从 DXF 到可排样项目有明确、可恢复的步骤 | 合法样本导入成功率；阻断错误可定位率 | 只加载图形，不报告单位/轮廓问题 |
| 可生产排样 | 每个输出实例均满足可验证的几何与订单约束 | 碰撞/越界/间距/方向违反数均为 0 | 只追求高利用率，忽略硬约束 |
| 节材可解释 | 用户能理解材料耗用、未放件和结果差异 | 利用率、完成率、实际用长、未放原因齐全 | 只显示一个饼图百分比 |
| 人工可控 | 自动结果可检查、调整、撤销、比较和恢复 | 手动操作与自动校验一致 | 画布上能拖动但导出时失败 |
| 可交接生产 | 导出结果能被目标 CAD/下游流程验证，且可追溯 | 导出文件可独立加载；导出清单完整 | 仅生成不可验证的文件或执行任意外部程序 |

## 2. 信息架构与模块地图

```text
项目/订单中心
  ├─ CAD 导入与诊断
  ├─ 裁片与工艺工作台
  │    ├─ 轮廓诊断/修复
  │    ├─ 工艺特征（内线、冲孔、剪口、码齿）
  │    └─ 裁片/尺码/数量与放置约束
  ├─ 材料与规则库
  ├─ 排样运行控制
  ├─ 排样画布与人工微调
  ├─ 结果校验与版本审批
  └─ 导出与生产交接
        └─ 审计、预设和系统设置贯穿全流程
```

## 3. 详细功能说明表

### M01 项目与订单中心

| 项目 | 规划 |
| --- | --- |
| 用户目标 | 建立一个可重复打开的生产任务，统一管理款号、客户、输入 CAD、订单数量、材料、规则、排样结果与导出历史。 |
| 入口/页面 | 启动页最近项目；“新建项目”；项目详情页；订单摘要侧栏。 |
| 必填数据 | 项目名、项目编号（自动生成）、创建人；可选订单号、客户、款号、交期、优先级、备注。 |
| 主要操作 | 新建、打开、保存、另存、复制版本、关闭、恢复自动保存、查看变更和导出历史。 |
| 状态机 | `草稿 → 导入待确认 → 可配置 → 排样中 → 已完成/未完全满足 → 校验失败/校验通过 → 已批准 → 已导出`。任意输入变更使已完成方案变为“已过期”。 |
| 规则 | 排样中锁定影响几何、订单、材料和策略的编辑；历史版本只读；项目保存规则快照而非仅保存预设名称。 |
| 异常处理 | 项目损坏、版本不兼容、源文件丢失、目标目录不可写、磁盘不足均要说明对象、原因和恢复动作。 |
| 验收 | 关闭重开恢复完全一致的订单、材料和方案；改数量后旧方案保留但不可导出为最新；源 DXF 丢失时可重新定位或使用缓存副本。 |
| 优先级 | P0。 |

### M02 DXF 导入与诊断

| 项目 | 规划 |
| --- | --- |
| 用户目标 | 从真实 CAD 文件可靠识别裁片和工艺数据，避免无提示漏件或错误尺寸。 |
| 入口/页面 | 项目内“导入 CAD”；四步向导：选择文件 → 单位/比例确认 → 识别结果 → 问题处理与提交。 |
| 输入 | DXF 文件、默认单位、曲线离散化容差、导入图层规则。第一版支持 LWPOLYLINE、POLYLINE、LINE/ARC 组合及受控曲线离散化。 |
| 输出 | 原始文件指纹、实体统计、图层清单、规范化对象、候选裁片、诊断报告、用户决策日志。 |
| 应识别对象 | 外轮廓、孔、内部工艺线、文字/标记、方向线、孤立对象、开放路径、重复线、零长线、自交和单位异常。 |
| 关键规则 | 内部统一毫米；单位不明或比例异常必须确认；禁止自动封闭开放轮廓或静默删除异常实体；取消不产生半导入项目。 |
| 异常处理 | 按阻断/警告/提示分级，列出位置、对象 ID、原因、建议（忽略/映射/修复/重新导入）；阻断问题未解决不能进入排样。 |
| 验收 | 合法多裁片样本显示正确数量和缩略图；含孔/内线样本分层可见；开放/自交样本有定位诊断；单位冲突会要求用户确认。 |
| 优先级 | P0。 |

### M03 CAD 画布、选择与显示

| 项目 | 规划 |
| --- | --- |
| 用户目标 | 快速理解 CAD 几何、检查细节并在列表与画布间高效定位。 |
| 页面结构 | 中央深色画布；左侧项目树/裁片列表；右侧属性与图层；底部坐标、缩放、选择和诊断摘要。视觉风格原创，但具备专业 CAD 信息密度。 |
| 基础操作 | 平移、鼠标中心缩放、全图、缩放到选择、标尺、坐标读数、单选、框选、多选、取消选择、撤销/重做。 |
| 显示控制 | 外轮廓、孔、内部线、冲孔/剪口、方向线、文字/标记、源图层可独立显示、隐藏、锁定和筛选。 |
| 关联规则 | 画布选择与裁片列表、属性面板双向同步；颜色只作辅助，所有对象类型、选中、错误均有文字/图例。 |
| 数据 | `GeometryObject`（稳定 ID、源实体、类别、图层、几何、可见/锁定）、`SelectionSet`、视图状态。 |
| 异常处理 | 无选择时选择性工具禁用；无法命中、超大坐标、损坏几何给出提示；每次修改后重新验证。 |
| 验收 | 从列表定位到画布，从画布选择回显列表；隐藏内线不影响外轮廓或导出源数据；撤销恢复相同几何/诊断。 |
| 优先级 | P0。 |

### M04 轮廓诊断与几何修复

| 项目 | 规划 |
| --- | --- |
| 用户目标 | 把“可画出但不可切割/不可排样”的 CAD 边界修复为有明确来源和可验证性的裁片轮廓。 |
| 子能力 | 闭合单条开放路径；容差连接端点；从边界集生成候选闭环；节点插入/移动/删除；单点剪断/两点去段；内缩/外扩预览。 |
| 交互流程 | 选择对象 → 分析 → 以新增/沿用/冲突颜色预览 → 显示面积、环数、最窄处和拓扑变化 → 确认或取消。 |
| 硬规则 | 仅允许 simple、closed、continuous、共面轮廓成为可排样外轮廓；孔必须完全包含或完全分离；不以凸包或最大面积替代正确边界。 |
| 工艺安全 | 内缩/外扩必须选择材料内外、距离、圆角/斜接/倒角；结果可变为 0 或多个轮廓时必须确认；默认保留源对象。 |
| 数据 | 原始几何永不覆盖；每步为可撤销 `GeometryOperation`，记录输入、参数、输出和验证结果。 |
| 异常处理 | 自交、T 型支路、过小特征、孔穿透、偏移崩解、工艺锚点失效必须阻止或标记待修复。 |
| 验收 | 闭合、容差连接、嵌套孔、自交、偏移导致分裂/消失等样本有确定结果；所有操作可撤销并重放。 |
| 优先级 | P1（导入诊断 P0；实际编辑可分阶段）。 |

### M05 工艺特征与码齿规则

| 项目 | 规划 |
| --- | --- |
| 用户目标 | 在不污染外轮廓的前提下维护裁切、标记、冲孔、剪口和尺码编码等生产语义。 |
| 普通工艺特征 | 内部线、冲孔、切口、文字、Mark 点；每项关联轮廓 ID、弧长锚点/坐标、类别、几何、刀具/图层、状态。 |
| 普通剪口 | 选择锚点 → 显示切线/材料法线 → 指定凹/凸、宽/深、Cut/Mark → 预览 → 提交。形状可先支持 V/方/U/半圆/划线。 |
| 码齿规则库 | 独立于普通剪口：库版本、尺码键、齿序列、间距、半码间距、起始锚点、方向、目标裁片/锚边。支持库选择、预览、复制新版本、锁定到项目。 |
| 关键边界 | 码齿是尺码编码，普通剪口是工艺定位，两者不得共用模糊 DTO；截图里的精确码数与模式尚未验证，不得写死业务公式。 |
| 异常处理 | 锚点过近、特征重叠、穿孔、深度超局部材料、缺尺码、库版本冲突必须提示并禁止生产导出。 |
| 验收 | Cut 与 Mark 具有不同导出语义；改变规则库不影响历史项目；工艺锚点在几何变换后可重映射或明确变成待修复。 |
| 优先级 | P1；码齿生产规则 P2，待工厂证据。 |

### M06 裁片、尺码与订单数量

| 项目 | 规划 |
| --- | --- |
| 用户目标 | 将 CAD 裁片变为可排样的订单清单，明确每种形状应该生产多少及其放置限制。 |
| 页面结构 | 左侧缩略图卡片/表格；中间当前裁片预览；右侧详情与批量设置；支持未完成筛选。 |
| 每行字段 | 启用、缩略图、名称/编码、尺码、左右件、尺寸、面积、需求数、已放数、未放数、单套数、优先级、附加间距、允许角度、镜像许可、方向、成组、备注。 |
| 批量能力 | 勾选、多选、统一数量/优先级/角度/间距、按名称/面积/未完成排序、筛选禁用或冲突项。 |
| 计算规则 | 数量为非负整数；`未放 = max(需求 - 已放, 0)`；面积和尺寸为几何计算值，禁止人工伪改；降需求到小于已放时要求选择保留超额/删除多余/取消。 |
| 约束建模 | “任意角度、微动、小件填空、凹凸互锁”等截图术语仅能在被转成可测规则后出现；第一版用允许角度集合、小件填空开关、优先级等通用字段。 |
| 异常处理 | 负数、小数、重复裁片 ID、缺尺码、左右关系不完整、矛盾约束均做字段级错误。 |
| 验收 | 三种裁片不同数量可得到准确计划/已放/未放；批量修改不影响未勾选项；非法数量不能运行。 |
| 优先级 | P0。 |

### M07 材料、料单与约束

| 项目 | 规划 |
| --- | --- |
| 用户目标 | 准确描述可用材料空间及生产边距，使排样结果可真实落料。 |
| 材料类型 | P0：矩形片料（宽×长）、定宽卷料（宽+目标/最大长度）。P2：不规则真皮边界、瑕疵区、质量等级区。 |
| 字段 | 名称、编号、类型、宽、长/上限、层数、材料方向、边缘预留、默认裁片间距、可用区域、消耗顺序、备注。 |
| 操作 | 新增/复制/删除材料；多个材料排序；导入/绘制可用区（后续）；保存为版本化预设。 |
| 规则 | 宽/长/间距/边缘必须满足正负范围；方向被转换为允许角度集合；材料改变使旧方案“已过期”；多材料独立统计后再汇总。 |
| 指标 | 可用面积、已用面积、余料面积、利用率、实际用长、材料张数、每材料放置实例/未放数量。 |
| 异常处理 | 空材料、0/负尺寸、材料不足、卷材突破最大长度、约束不兼容都必须阻止或解释。 |
| 验收 | 双材料结果可分别展示面积/利用率/实例；改变宽度后旧方案不能继续批准；卷料可报告真实用长。 |
| 优先级 | P0。 |

### M08 排样策略与运行控制

| 项目 | 规划 |
| --- | --- |
| 用户目标 | 在可理解、可中断的条件下生成有效方案，并在时间预算内持续改善。 |
| 输入 | 有效裁片与数量、材料、间距/边缘、角度/镜像/方向、优先级、策略预设、时间预算、随机种子/确定性模式。 |
| 输出 | 每个放置实例的裁片 ID、材料 ID、X/Y、角度、镜像、层号、锁定状态、验证结果；方案级指标与日志。 |
| P0 算法基线 | 确定性启发式：按优先级/面积排序、候选点/角度搜索、精确碰撞与边界验证；输出可解释但不声称全局最优。 |
| P1 优化 | 时间预算内多轮改善，支持小件填空、局部重排、连续保存当前最佳；预设为快速/均衡/精细。 |
| 状态机 | `Ready → Preparing → Running → BestImproved* → Completed | StoppedWithBest | Cancelled | Failed`。停止保留最后完整有效方案；取消回滚本次运行的临时结果。 |
| UI 反馈 | 已用时间、当前/最佳利用率、已放/未放、材料张数、候选数或进度、停止/取消按钮、日志和失败原因。 |
| 硬规则 | 不越界、不重叠、满足边距/间距、数量上限、角度、镜像、方向和锁定实例规则。所有结果先经过独立验证器。 |
| 异常处理 | 无解、超时、取消、算法异常、内存/性能过载均保留日志且不半写项目；后台运行不得冻结界面。 |
| 验收 | 相同种子得到相同方案；取消 5 秒内响应；材料不足时输出有效部分方案并说明原因；完整校验为 0 违反。 |
| 优先级 | P0。 |

### M09 结果画布与人工微调

| 项目 | 规划 |
| --- | --- |
| 用户目标 | 复核自动方案、处理现场例外，并在不破坏生产规则的前提下调整。 |
| 页面结构 | 中央材料画布；左侧材料/未放裁片；右侧选中实例与校验；底部汇总指标；支持全局视图和局部放大。 |
| 可见信息 | 材料边界、可用/禁用区、实例、标签、方向、锁定、内部工艺线、空余区、未放项、错误标记、图例。 |
| 操作 | 选择/框选、拖动、定角旋转、镜像、删除、锁定/解锁、贴边、成组、撤销/重做、仅排剩余、局部重排、比较和恢复版本。 |
| 统一验证 | 手动操作调用与自动排样相同的碰撞、边界、间距、角度、镜像、数量验证器；任何无效操作要拒绝或显式标为未通过。 |
| 结果指标 | 已用/未用面积、利用率、材料尺寸/用长、计划/已放/未放、运行时间、策略、校验结果、未放原因。 |
| 异常处理 | 重叠、越界、角度不合法、已锁定、超数量、材料已过期均给出对象级解释与定位；不得只用颜色。 |
| 验收 | 拖至碰撞位置会拒绝或标红并禁导出；手调创建新版本；可比较两版指标并恢复旧版。 |
| 优先级 | P0。 |

### M10 校验、审批与质量报告

| 项目 | 规划 |
| --- | --- |
| 用户目标 | 在进入生产前确认方案真实可用，并让主管可审查例外和责任。 |
| 自动校验 | 几何有效、边界、实例碰撞、边距/间距、角度、镜像、方向、数量、锁定规则、工艺锚点、导出映射。 |
| 页面内容 | 总体结论；阻断/警告/提示计数；每项的对象、材料、坐标、规则、建议；单击定位到画布。 |
| 审批规则 | 存在阻断项禁止批准和生产导出；警告需要有原因/豁免人/时间；批准版本只读。 |
| 质量报告 | 项目版本、输入指纹、裁片/订单、材料、策略、指标、未放件、所有校验项、豁免、操作者、时间。 |
| 异常处理 | 无法计算/配置缺失的规则必须显示“不完整校验”，禁止伪造通过。 |
| 验收 | 碰撞/越界/未放项均可定位；含阻断错误不能批准；审批后改输入会使批准失效。 |
| 优先级 | P0。 |

### M11 导出与生产交接

| 项目 | 规划 |
| --- | --- |
| 用户目标 | 生成可供 CAD/生产下游验证的文件包，准确映射几何和工艺语义。 |
| P0 输出 | 项目文件、DXF、JSON/CSV 生产报告；可选 PNG/PDF 预览。 |
| 导出设置 | 文件夹、命名模板、单位、原点、旋转/镜像、标签文字、图层/线型映射、曲线离散化容差、包含的工艺类型。 |
| 输出要求 | DXF 需保留/映射外轮廓、孔、内部线、冲孔/标记、裁片标识、材料边界；报告附项目版本、输入/输出哈希、规则、指标和文件角色。 |
| 交接包 | `项目号/版本/时间戳/` 下有 DXF、报告、manifest；应用可打开目录和预览 manifest。 |
| 未来扩展 | PLT/DWG/设备直连须各自实现版本化适配器、许可/格式验证和端到端样本验证；不得根据截图自行推断协议。 |
| 安全与失败 | 导出前强制校验；使用临时文件再原子提交；不可写目录、磁盘满、文件名非法、接收格式不支持时不产生“成功”记录。 |
| 验收 | 有效方案导出后可由独立 CAD 查看器/解析器打开；几何在容差内一致；无效方案无法导出；报告可对应唯一版本。 |
| 优先级 | P0。 |

### M12 规则库、审计、权限与系统设置

| 项目 | 规划 |
| --- | --- |
| 用户目标 | 在多订单、多操作员环境中稳定复用规则，同时保证历史输出可重现。 |
| 规则库 | 材料预设、排样预设、导出模板、图层映射、单位策略、工艺/码齿规则；均包含 ID、名称、版本、状态、创建人、修改说明。 |
| 审计 | 记录导入、单位确认、几何修复、约束变更、排样开始/停止/取消、手调、校验豁免、批准、导出和失败。 |
| 权限 | 工艺员可编辑裁片；排样员可运行/手调；主管可审批；管理员管理预设和外部适配器。MVP 可先用本地角色，保留未来账号扩展。 |
| 设置 | 单位、精度/容差、自动保存、性能诊断、主题/可访问性、日志目录、已注册导出适配器。 |
| 核心规则 | 项目存储实际使用的规则快照；库更新永远不回写历史项目；不允许执行任意用户输入的外部可执行路径。 |
| 验收 | 修改材料预设后旧项目结果不变；审计可回答谁、何时、以何规则导出何文件；角色不足时相关操作禁用并说明。 |
| 优先级 | P1；规则快照与基本审计 P0。 |

## 4. 关键数据对象与关系

## 9. 质量红线

1. 不以静态截图、硬编码矩形、假进度或无校验随机摆放冒充产品功能。
2. 不允许手工编辑绕过自动排样使用的验证规则。
3. 不导出校验失败或已过期方案。
4. 不把图片中模糊的参数、颜色或竞品文案误当成已确认业务规则。
5. 不复制第三方名称、图标、品牌、整体界面排布、原始文案、素材、私有格式协议或未知算法；目标是同等级的专业能力和可测工作流。
