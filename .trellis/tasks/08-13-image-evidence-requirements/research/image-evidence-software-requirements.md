### 证据使用原则

1. **事实**：图片中可见的对象、字段、状态和结果。
2. **需求推断**：为完成该工作流所必需、且可独立验证的能力；例如“有多裁片缩略图”可推导“系统应管理裁片清单”。
3. **待确认**：默认值、精确算法、下拉选项语义、颜色含义、私有文件格式、第三方设备协议。不得以推断填入黄金行为。

## 2. 产品定位与用户

### 2.1 目标问题

面向鞋材/皮革裁切工厂，把一组带尺码和工艺线的二维 CAD 裁片，按订单数量和材料约束自动排布到一张片料或一段卷料中，使用户能复核、调整并导出可供下游 CAD 或设备使用的生产文件，同时透明地看到材料利用率和未完成数量。

### 2.2 主要角色

| 角色 | 核心目标 | 权限建议 |
| --- | --- | --- |
| 版师/工艺员 | 导入、检查并修复裁片，定义工艺线和方向限制 | 编辑裁片、规则库 |
| 排样员 | 填写订单数量、材料参数，运行/停止排样、手工调整 | 创建和调整方案、导出 |
| 主管/报价员 | 比较材料耗用和完成率，审批生产方案 | 只读、锁定/批准、查看报告 |
| 管理员 | 管理格式映射、导出模板、算法预设和用户 | 系统配置 |

## 3. 端到端工作流

```text
新建项目 → 导入 DXF → 导入诊断/裁片识别 → 裁片工艺与方向确认
        → 订单数量/优先级 → 材料定义 → 设置排样策略 → 运行/取消/保留最佳方案
        → 自动校验 → 人工微调并再次校验 → 保存版本 → 导出 DXF/报告/交接包
```

任一环节未完成时，系统必须把后续操作禁用并说明缺少什么，而不是产出错误排样。例如：没有合格闭合轮廓不可运行；材料宽度无效不可开始；存在碰撞或超界不可导出生产文件。

## 4. 功能需求

### FR-01 项目、版本与文件管理

**目的**：将一次排样的输入、规则、参数、结果和导出记录为可重现项目。

- 用户可新建、打开、另存、保存项目；项目拥有唯一 ID、名称、创建人、创建/更新时间和备注。
- 项目保存原始输入文件的路径、校验指纹、导入时间和规范化后的几何；原始文件变化时必须提示重新导入或继续使用已锁定副本。
- 项目至少有“草稿、待排样、排样中、已完成、校验失败、已批准、已导出”状态；排样中不允许覆盖性编辑。
- 每次排样、人工调整和导出都创建可追溯版本。已批准或已导出的版本不可静默改变；复制后才可继续编辑。
- 支持中文文件名和中文路径；打开、保存、取消、文件不存在、权限拒绝、磁盘已满都要显示可操作错误信息。

**验收**：关闭并重新打开项目后，能复现同一裁片、订单、材料、规则和排样结果；原文件被移动后，项目仍可说明缺失路径和恢复动作。

### FR-02 CAD/DXF 导入与诊断

**目的**：将生产裁片 CAD 转为可信的领域模型，不因格式问题静默漏件。

- 第一版必须读取 DXF；支持闭合 `LWPOLYLINE`、旧式 `POLYLINE`、`LINE/ARC` 组合及受控离散化曲线。DWG/PLT 仅在验证库、许可和样本后列为可选导入能力。
- 导入界面显示文件、大小、时间、单位推断、实体计数、图层列表和解析进度；支持取消，取消后不应创建半成品项目数据。
- 识别候选外轮廓、孔、内部工艺线、文字/标注和孤立对象；给出数量和定位链接。
- 对开放轮廓、自交、零面积、重复边、过短线段、异常比例、单位缺失或冲突，必须给出严重级别、原因、画布定位和建议动作（忽略、修复、手工确认、终止导入）。不得自动封闭或丢弃而不留痕。
- 用户确认单位后，内部坐标统一使用毫米；保留源单位和换算因子。
- 导入完成后生成裁片清单与缩略图，并可点击定位到 CAD 画布。

**验收**：对合法 DXF 能显示裁片数；对含断线或单位缺失样本显示可定位诊断，不会显示“成功”但裁片为空。

### FR-03 CAD 工作台与裁片编辑

**目的**：让工艺员在非破坏式工作台检查和定义排样所需几何与工艺信息。

- 画布应支持平移、缩放至鼠标、缩放到全部/选择、标尺、坐标读数、选择框、多选和取消选择；选中项与列表双向同步高亮。
- 显示裁片外轮廓、孔、内部线、方向标记、标签与材料边界；用户可按类型/图层切换可见性和锁定状态。
- 提供裁片分组、重命名、缩略图、启用/禁用和排序；一件裁片的变化必须在订单与排样引用中受控传播或提示冲突。
- 允许定义“外轮廓、孔、内部工艺线、切口/冲孔、文本/标记、方向线”类别；原始图层映射到这些类别并允许用户覆写。
- 几何修改需要撤销/重做、变更记录和有效性重检。不能通过有效性检查的裁片不得参与自动排样。
- 提供合理的显示颜色，但颜色不得作为唯一业务语义；必须有文字图例、对象类型和可访问的选择状态。

**验收**：选中列表项时画布对象高亮；隐藏内部线不改变外轮廓；撤销修改后恢复相同几何；无效裁片被阻止进入排样。

### FR-04 裁片订单与约束表

**目的**：将“有哪些形状”转为“本次要做多少、如何允许放置”。

- 为每个裁片提供：启用、名称/编码、来源、尺寸（只读计算）、面积（只读计算）、缩略图、数量、已放置数、未放置数、优先级、单套数量、附加间距、方向/镜像许可、旋转许可、备注。
- 支持批量勾选、统一设置、按名称/面积/优先级排序、筛选未完成项和导出订单清单。
- 数量必须是非负整数；总量、余量和完成率实时计算。编辑时不能把已放置数量变成超过新目标数量而不提示用户选择“保留超额、删除多余、取消”。
- 允许维护尺码、左/右脚、款号、材料类别等扩展字段，但其数据来源、是否参与排样、是否写入导出文件必须显式配置。
- “微动”“小片插入”“凹凸匹配”等截图可见概念，本产品需先定义成可测的通用策略（如局部位置优化、小件优先、互锁奖励）；未定义前不可作为伪功能按钮。

**验收**：设置三种裁片不同需求数后，运行结果逐项显示计划/已放/未放；批量修改仅影响勾选项；任何非法数量都有字段级错误提示。

### FR-05 材料与料单

**目的**：定义可利用空间和生产边界。

- 支持至少两类材料：矩形片料（宽×长）和定宽卷料（宽度 + 最大长度/无限长策略）。每张材料记录名称、编号、宽、长、层数、方向、边缘预留、裁片间距、可用区域、备注。
- 支持材料方向（横向/纵向）和裁片方向约束；实现含义以坐标轴、允许角度集合和镜像许可定义，不能只显示中文标签。
- 对卷料提供“目标长度、自动延展上限、分段/分卷”策略；对片料提供固定边界。任何层数/套数的面积核算必须明确是逻辑数量还是实际叠料数量。
- 支持多个材料候选；排样可选择一个或按顺序消耗多个材料。剩余材料须单独记录，不能与裁片余量混淆。
- 材料参数改变会使现有结果过期；系统必须要求重新排样或保留旧版本，不得将旧结果标作最新。

**验收**：无效尺寸、负间距、未选材料时无法运行；改变宽度后旧方案标为“参数已变化”；结果报告列出每张材料的已用面积和余料。

### FR-06 自动排样运行

**目的**：在明确几何和约束下，产生有效且尽量节材的方案。

- 输入为已通过诊断的裁片、订单约束、材料约束和策略预设；输出为每个裁片实例的材料 ID、位置、角度、镜像状态、层号与验证状态。
- 硬约束：所有放置实例在材料可用区内；任意两实例不重叠；满足边缘和裁片间最小间距；符合各自允许角度、方向和镜像规则；放置数不超过需求。
- 软目标按可配置顺序优化：完成率优先、材料利用率、总用料长度、裁片间空隙、同类集中度、工艺/切割顺序便利性。第一版应公开采用的目标与权重，不声称“最优”。
- 运行设置至少包含：时间预算、可用角度/旋转策略、排放顺序、是否允许小件填空、随机种子或确定性模式。截图中的“裁片类型、凹凸比例、强制阵列”等不可直接复制；只有形成明确模型和测试后才能加入。
- 运行过程应在 UI 中显示状态（排队、准备、运行、发现新最佳、取消中、完成、失败）、已用时间、当前最好指标和停止操作。用户停止时保留最后一个已通过完整验证的方案，不保存未验证中间状态。
- 排样任务必须异步执行，界面仍能取消、查看日志和切换到其他无冲突页面。

**验收**：对固定种子和输入，确定性模式得到相同结果；取消任务后可继续编辑，且项目不含半写入实例；任何输出结果通过边界/碰撞/间距验证。

### FR-07 结果浏览、质量反馈与人工微调

**目的**：让用户理解利用率、缺口和异常，并能在同一约束下修正结果。

- 画布显示材料边界、放置裁片、颜色/图例、裁片标签、未放置项和空余区域；支持全局视图与局部放大。
- 右侧或独立结果页显示：已用面积、未用面积、利用率、材料尺寸/实际用长、放置数/计划数、未放置清单、运行时间、算法预设、校验结果。饼图可使用，但数值文本必须同样可读。
- 若使用多材料，展示每张材料的独立缩略预览及选择；概览同时展示总计。
- 用户可移动、旋转、镜像、删除、锁定一个放置实例，并在提交前实时运行与自动排样相同的碰撞、边界、间距、方向和数量校验。
- 结果中出现未完成量、异常或低利用率时，解释原因（材料不足、方向限制、间距、禁用裁片、时间预算等）并提供可操作建议，不把空白区域误报为算法失败。
- 方案可比较：至少保留指标、参数与生成时间；用户可选定一个版本导出。

**验收**：手工拖动造成碰撞会即时阻止或标红并不允许批准；报告的利用率可由面积数据复算；未放置项能按原因筛选。

### FR-08 生产前校验、审批与导出

**目的**：只让可生产的、可追溯的方案离开系统。

- 强制校验项：轮廓有效、材料边界、实例互不重叠、间距、方向、镜像、数量、内部工艺线与外轮廓关联、导出图层/线型映射完整。阻断问题存在时禁用生产导出。
- 第一版导出 DXF 与 CSV/JSON 报告。每次导出生成清单：项目版本、源文件指纹、材料参数、订单摘要、算法参数、利用率、未完成项、导出时间、操作者、文件哈希。
- DXF 导出必须保留或明确映射外轮廓、孔、内部工艺线、标记、裁片标识、材料边界；图层命名/颜色/线型通过本产品的导出模板配置，避免硬编码竞品约定。
- 可选导出 PNG/PDF 预览和面向外部程序的“交接包”。若日后支持 PLT、DWG、JSON 或调用外部 CAD，须通过版本化适配器、路径校验、格式能力声明及模拟测试实现；绝不执行项目中未验证的任意程序路径。
- 导出前可预览输出范围、单位、坐标原点、旋转、镜像、文字大小和文件名规则。所有转换必须可审计、可重复。

**验收**：DXF 可被目标 CAD 打开，且用样本几何对比外轮廓与工艺线数量/位置在定义容差内一致；存在碰撞时导出按钮禁用；导出报告能对应唯一项目版本。

### FR-09 配置、规则库与审计

- 规则库至少包含材料预设、排样预设、导出模板、图层映射与单位换算策略；每项具有名称、版本、状态、创建人和修改记录。
- 项目保存实际引用的规则快照；库的后续修改不得改变已有项目复现结果。
- 显示操作日志：导入、诊断确认、关键参数更改、运行、取消、人工调整、批准、导出及失败原因。
- 管理员可控制用户对规则库编辑和导出模板编辑的权限。

**验收**：修改材料预设后，历史项目仍显示旧快照；审核日志能回答“谁在何时用什么参数导出了哪个文件”。

## 5. 状态和错误处理合同

| 场景 | 必须状态 | 用户可见行为 | 数据要求 |
| --- | --- | --- | --- |
| DXF 解析失败 | 导入失败 | 列出文件、错误、定位/建议，允许重试或取消 | 不创建可排样裁片 |
| 发现可修复几何问题 | 待确认 | 显示问题清单和每项处理选择 | 保存原始几何与处理日志 |
| 排样运行 | 运行中 | 时间、当前最好指标、停止按钮可用 | 不覆盖上一个有效方案 |
| 用户取消 | 已取消/保留最佳 | 明示是否保留最后有效方案 | 仅写入完整验证过的版本 |
| 无法完整放置 | 已完成但未满足 | 显示完成率和未放置原因 | 结果可保存，不可伪装为已批准 |
| 校验失败 | 校验失败 | 按严重性显示问题，支持定位 | 禁止生产导出 |
| 导出失败 | 导出失败 | 指出目标文件、权限/格式/映射问题 | 不把不完整文件登记为成功 |

## 6. 非功能需求

- **平台**：优先支持 macOS 和 Windows x64；核心几何与项目格式不依赖 UI 框架。适配 1366×768、100%/125%/150% 缩放、中文输入和路径。
- **性能**：导入、排样和导出均提供进度与取消；长任务不阻塞界面。性能目标应按裁片数量、实例数量、边数和硬件建立基准，不能只用“很快”。
- **可靠性**：自动保存草稿；异常退出后可恢复到最后一致项目状态；任何导出均以临时文件+原子替换或等价机制避免半文件。
- **精度**：内部统一毫米和双精度坐标；定义几何容差、曲线离散化误差、DXF 往返误差和验证容差，并显示给用户。
- **可访问性**：颜色之外用文字、图标说明和可聚焦控件传达状态；主要操作可键盘访问。
- **安全与隐私**：不上传客户 CAD、订单或材料数据，除非用户显式选择的后续云功能；外部程序关联、导出目录和文件名必须校验，操作记入日志。
