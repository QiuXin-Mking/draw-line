# 图片 AI 转写索引

此目录把 `05-图片/` 现存的 27 张 PNG 一对一转写为 AI 可读取的 Markdown。每份文件均为对可见内容的结构化描述，而非 OCR 原文的保证；模糊或无法从单张图确认的信息会明确标为“未证实”。

## 统一阅读约定

- **确认事实**：可从该图片直接看见的对象、状态、文字或流程结果。
- **功能推测**：由画面支撑、但需要后续样本或现场验证的合理产品能力；不得直接当成竞品内部事实。
- **验收启示**：我们自己的软件可被观察与测试的独立能力，不要求复制第三方外观或文案。
- 图片内的 AXTNester 名称、图标、菜单、色彩、布局、文案以及可能的私有协议仅用于识别业务问题，不能直接复刻。
