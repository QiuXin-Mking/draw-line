# 25 — 源/导出文件对照

- **源图**：`05-图片/截屏2026-08-12 11.16.07.png`
- **流程位置**：人工检查输入与交接结果文件。

## 画面转写

桌面上同时打开两个资源管理器窗口：左窗口像是包含若干文件夹和少量大文件的源/结果目录，右窗口为大量 JSON 和若干 DXF 的输出目录。窗口底部能读到被选文件约 41.8 MB，说明 CAD 交接文件可能较大。

## 确认事实

- 用户需要在文件系统层面对照源文件与输出产物。
- 单一任务会涉及多个 JSON 与至少一个 DXF，且文件可能较大。

## 功能推测

- 交接包应形成清晰的目录结构，而非散落到难以追踪的临时目录。

## 未证实项

- 两窗口的每个目录角色、文件具体是否一一对应。

## 验收启示

导出目录采用 `项目/版本/时间戳` 或等价结构；在应用内提供“打开导出目录”和 manifest 预览，避免用户仅凭文件大小猜测成功。
