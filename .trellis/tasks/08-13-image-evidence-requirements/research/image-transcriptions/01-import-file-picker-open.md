# 01 — 导入文件选择器：初始状态

- **源图**：`05-图片/截屏2026-08-12 10.45.28.png`
- **流程位置**：项目中执行“打开/导入 CAD”后的第一步。

## 画面转写

Windows 桌面应用置于远程桌面窗口中。顶部有文件、编辑、操作、绘制、数据库、工具、设置、帮助等菜单及新建排版、订单管理、CAD 工具、开始/停止/取消排版、缩放、设置窗口、发送等工具入口。中央是黑色 CAD 画布，前景为标准 Windows 文件选择器；文件列表包含多种 CAD 文件，底部文件名输入框和“打开/取消”按钮可见。左侧是项目/订单树，右侧是属性或绘图设置面板，尚未有明显有效的裁片内容。

## 确认事实

- 用户通过系统文件选择器从磁盘选择 CAD 文件。
- 文件类型过滤至少包含 DXF；截图还显示其他扩展名候选，但支持范围不能由本图断定。
- 导入入口并非独立页面，导入后将回到主 CAD 工作台。

## 功能推测

- 导入流程应支持文件筛选、路径导航、取消与最近目录。
- 工程可能允许从订单/项目树关联多个输入文件。

## 未证实项

- 文件是否允许多选、是否导入 DWG/PLT、单位如何判断、导入失败如何反馈。

## 验收启示

我们的产品应提供真实文件选择器、DXF 过滤、取消不写入项目、中文路径支持及导入后的明确诊断结果。
