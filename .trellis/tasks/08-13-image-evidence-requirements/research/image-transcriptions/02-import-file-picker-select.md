# 02 — 导入文件选择器：选择 DXF

- **源图**：`05-图片/截屏2026-08-12 10.45.42.png`
- **流程位置**：在文件列表中定位待导入的 CAD 文件。

## 画面转写

主工作台背景保持黑色画布。文件选择器中一条 `.dxf` 文件被蓝色选中；列表同时显示名称、修改日期、类型和大小。底部文件名框已回填所选文件名，右下角“打开”可提交选择，“取消”可退出。

## 确认事实

- 用户可见文件的元信息并选择单个 DXF。
- 提交前文件名会反映当前选择。

## 功能推测

- 导入器应在选择后验证扩展名、可访问性和基础文件完整性。
- 文件选择与实际解析应分离：选择成功不等于导入成功。

## 未证实项

- 是否支持拖放、批量选择、导入预览或预扫描。

## 验收启示

选择无权访问、已删除或格式不符的文件时，必须有可理解的失败信息；不能以空白画布伪装导入成功。
