# 23 — 导出目录中的 JSON 与 DXF 工件

- **源图**：`05-图片/截屏2026-08-12 11.10.43.png`
- **流程位置**：检查发送/导出产生的文件。

## 画面转写

Windows 资源管理器打开一个输出目录，文件列表主体由按数字命名的 `.json` 文件组成，底部有一个较大的 `.dxf` 文件。背景还能看到另一资源管理器窗口。文件按修改时间和大小展示。

## 确认事实

- 排样/交接流程会在文件系统生成 JSON 与 DXF 两类产物。
- JSON 可能按多次任务或多份材料产生多个文件，DXF 文件体积较大。

## 功能推测

- JSON 是机器/下游程序消费的结构化中间数据，DXF 是 CAD 几何交换文件。

## 未证实项

- JSON 结构、每个文件与方案/材料的对应关系、文件命名规则和是否包含完整生产数据。

## 验收启示

导出包应使用可预测命名，并含 manifest：项目版本、导出时间、输入/输出哈希、文件角色。每项产物都应在写入成功后才登记；失败必须可重试。
