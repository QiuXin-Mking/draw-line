# 恢复 CAD 面板可用性

## Goal

让主工作站中的 CAD 区域从“外观复刻但几乎所有操作都是 TODO”恢复为用户可以完成真实 CAD 工作的入口，并消除当前同时存在三个互不连通 CAD 表面的架构断裂。

## Background and confirmed facts

- 当前 Shell 启动时选择 M03，但 `AppShellView.RefreshModuleOverlay` 只允许 M02 可见，所以已实现的 `CadCanvasView` 虽被创建却始终隐藏。
- 主界面中央实际显示 `CadWorkspaceHost` + `CadEvidenceCanvas`。后者只有绘制与重新失效，没有滚轮缩放、平移、选择、编辑或命令会话。
- `CadWorkspaceHost` 除“打开文件”“关闭”“范围缩放”外，绘制多段线、矩形、选择和删除都明确转到 `CadHostState.ReportUnsupported`。
- 右侧 `CadPropertyPane` 的操作按钮同样全部转到 `ReportUnsupported`；文本框、单选框和复选框没有把值写回任何 CAD 状态或命令。
- 已有 `CanvasView` 支持缩放、平移、点击命中、拖动和选中高亮；已有 `CadWorkbenchViewModel` / `CadOperationSession` 支持部分修复、偏移、节点、剪断、剪口、变换、预览、提交、撤销与重做。
- 已有 `CadWorkbenchView` 只在 M02 导入页的“工艺工作台”二级标签中创建，主工作站 CAD 面板没有复用它，也没有共享同一编辑会话。
- 现有 Shell 测试将“隐藏完整 M03 页面”和“未支持工具只报告 TODO”固化为预期，因此测试全绿不能代表 CAD 可用。
- 关键退化来自提交 `74ade97`：为贴合参考截图引入常驻只读 CAD 宿主，并明确隐藏 M03 页面；不是最近的颜色修复引入。

## Requirements

- **R1 单一 CAD 会话**：确认导入的几何、主画布、工具栏、右侧参数和撤销/重做必须操作同一份会话状态。
- **R2 可达性**：用户从主工作站可直接进入真实 CAD 画布与编辑能力，不依赖隐藏的 M02 二级标签。
- **R3 基础视图交互**：至少支持全图、滚轮缩放、空白平移、对象点击选择与选中高亮。
- **R4 真实编辑闭环**：纳入本任务的工具必须完成“输入参数 → 预览 → 提交/取消 → 撤销/重做”，不能再以 `ReportUnsupported` 伪装为可用按钮。
- **R5 明确降级**：未纳入本次实现的控件必须禁用或明确标注 TODO，不能看起来可操作但只改一条状态文本。
- **R6 导入衔接**：M02 确认毫米后，真实轮廓进入同一个 CAD 会话，并在主画布可见、可选、可编辑。
- **R7 回归保护**：自动化测试必须验证 Shell 中的可达性和命令后的几何/会话变化，而不只验证按钮顺序和 TODO 文案。
- **R8 视觉约束**：保留当前五区工作站框架和已完成的颜色修复，不以恢复旧版全屏 Tab UI 作为最终方案。
- **R9 本轮工具范围**：接通确认导入、全图/缩放/平移、选择高亮、拖动移动、固定角度旋转、闭合轮廓、内缩/外扩，以及预览、会话提交、取消、撤销和重做。
- **R10 会话边界**：本轮“提交”指写入可撤销的 CAD 编辑会话；项目几何持久化与编辑后 DXF 导出另立任务。界面必须明确该边界，不能暗示已永久保存。

## Acceptance Criteria

- [ ] 完成一次 DXF 毫米确认后，主 CAD 画布显示当前会话几何；未确认文件时显示明确导入引导。
- [ ] 用户可在主画布执行全图、缩放、平移、选择，且状态和高亮可观察。
- [ ] 至少一条代表性真实编辑链路可从主面板完成参数输入、预览、提交、取消、撤销和重做。
- [ ] 闭合轮廓、内缩/外扩、拖动移动和固定角度旋转均从主面板可达；失败时显示诊断且不破坏上一次稳定几何。
- [ ] 已接入工具会改变预览/提交几何或会话状态；未接入工具不可伪装为已实现。
- [ ] M02 与主 CAD 面板共享会话，不产生“导入一份、编辑另一份”的副本漂移。
- [ ] Desktop 自动化覆盖导航可达性、共享会话、视图交互契约和编辑事务。
- [ ] 原生 1366×768 窗口完成手工交互验收，CAD 核心控件无不可见或不可点击问题。
- [ ] Desktop 测试、解决方案构建和格式检查通过；并行 DXF 任务的改动不混入本任务。

## Out of Scope

- 排样算法、切割发送和机器通信。
- DXF 解析器/导出器本身的重构；本任务只消费其确认导入结果。
- 在未确认范围前一次性实现右侧参考面板的全部三十余项专业命令。
- 将会话编辑写回 `ProjectDocument`，或导出编辑后的 DXF。
- 改动 `05-图片/` 或其他并行任务文件。

## Decisions

- 用户确认采用“核心可用编辑闭环”，不在本轮实现右侧面板展示的全部 CAD 工具。
- 主工作站保持五区结构；旧的全页 `CadCanvasView` / `CadWorkbenchView` 仅作为能力来源，不作为最终嵌入形态。
- 未接入能力使用禁用态和明确 TODO；不再用可点击按钮加状态文案模拟成功。
