# 排样算法升级：0°/90° 位姿 + Clipper2 NFP/GA

## 1. 背景与动机

皮革排样的核心价值是**材料利用率**：把鞋面、皮包等不规则裁片尽可能紧密地排在大张皮革上，减少废料。当前系统的排样能力只存在于 Python demo `leather_nesting_demo.py`，是确定性的「货架填充」（shelf packing）启发式，存在两个硬伤：

1. **位姿受限**：只支持 0° / 180° 两种姿态，无法横竖旋转，浪费大量可省材料。
2. **不可集成**：纯 Python，不在 .NET/Avalonia 主代码里，无法被 CAD 工作台和输出层调用。

本任务把排样能力迁入 C# 生产代码，位姿升级为 **0° / 90°**，并复刻 DeepNest 的算法思路（No-Fit Polygon + 遗传/局部搜索）用 Clipper2 实现，最终产出一个可被应用层与输出层消费的排样引擎。

## 2. 目标

- 在 `LeatherNesting.Geometry` 交付一个可复用的排样引擎，输入裁片集合 + 材料轮廓，输出每个裁片的位姿与利用率。
- 位姿支持 **0° / 90°**。
- 碰撞 / 间隙判定**精确到边缘**（不再用 bounding box 近似）。
- 利用率不低于现有货架填充基线，并具备后续优化（NFP + 遗传算法）的扩展点。

## 3. 术语定义

| 术语 | 定义 |
|---|---|
| 裁片（piece） | 一个待放置的闭合轮廓 `Loop2D`（鞋面/皮包裁片），可能带洞（`LoopRole.Hole`） |
| 材料（material） | 待放置的皮革轮廓 `Loop2D`，首版为矩形，接口上允许任意闭合形状 |
| 位姿（placement） | 一个裁片的最终摆放，由平移 `(x, y)` + 旋转角 `rotation ∈ {0°, 90°}` 描述 |
| 间隙（gap） | 裁片边缘到边缘的最小允许距离（毫米）；裁片到材料边缘同样适用 |
| 利用率（utilization） | `已放置裁片面积之和 / 材料面积`（百分比） |
| 未放置（unplaced） | 无法在剩余空间装入的裁片 |

## 4. 现状与差距

| 项 | 现状 | 目标 |
|---|---|---|
| 排样实现 | 仅 Python demo（货架填充） | C# `Nesting/` 引擎 |
| 位姿 | 0° / 180° | 0° / 90° |
| 碰撞判定 | bounding box 近似（`PlacementValidator`） | Clipper2 精确布尔 |
| 优化 | 无（贪心一次通过） | 贪心保底 + NFP/GA 优化 |
| 可集成性 | 不可（Python） | 可（.NET 类型，应用层可编排） |

## 5. 功能需求（FR）

### FR-1 位姿：0° / 90°
- 每个裁片允许以 **0°** 或 **90°** 两种旋转放置。
- 旋转不改变裁片几何（面积、边长不变），仅改变朝向。
- 首版**不支持** 180°（点对称）、自由角度、镜像——这些是后续方向，接口需为它们预留扩展（旋转角用数值而非枚举表达）。

### FR-2 碰撞检测（精确）
- 任意两个已放置裁片**不得重叠**（边缘相切允许，面积相交不允许）。
- 判定基于裁片真实几何（多边形/曲线），不是外接矩形。

### FR-3 间隙约束
- 任意两个已放置裁片的**边缘最小距离 ≥ gap**。
- 裁片边缘到材料边缘的最小距离 ≥ gap。
- gap 为可配置参数（默认 5 mm，沿用现有约定）。

### FR-4 边界约束
- 每个已放置裁片必须**整体位于材料轮廓内**，不得越界。
- 首版材料为矩形；接口需支持任意闭合材料轮廓（Clipper2 布尔天然支持）。

### FR-5 放置策略
- 首版采用**贪心 bottom-left-fill（BLF）**：按确定顺序（默认面积降序）逐个放置，每个裁片在 0°/90° 两种位姿里选「最靠左下且合法」的位置。
- 放置顺序**确定且可复现**：同输入 ⇒ 同输出。

### FR-6 优化目标
- 首版以「贪心 BLF」为基线，保证结果合法、可复现。
- 后续阶段用 **NFP + 遗传算法 / 模拟退火**在合法前提下最大化利用率。
- 任何优化解都必须同样满足 FR-2 / FR-3 / FR-4（合法性优先于利用率）。

### FR-7 输入 / 输出契约
- **输入**：裁片 `IReadOnlyList<Loop2D>`、材料 `Loop2D`、`gapMm`、允许角度集合。
- **输出**：`placements`（每个裁片 id + x/y/rotation + 放置后轮廓）、`unplaced`（未放置裁片 id）、`utilization`。
- 输出不直接落盘；DXF/JSON 序列化由输出层（另立任务）消费 `NestResult`。

### FR-8 分层
- 几何与碰撞、放置算法在 **Geometry 层**（新增 `Nesting/` 命名空间）。
- 应用层的编排（use case / command）在 **Application 层**，负责装配输入、调用引擎、返回结果。

## 6. 非功能需求（NFR）

- **确定性**：同输入 ⇒ 同输出（可复现，便于测试与审计）。
- **精度**：沿用 `GeometryConstants.IntegerScale = 1e6`（≈ 纳米级），坐标在 `MaxSafeMillimetreCoordinate` 内不溢出。
- **性能**：首版目标支撑约 100 片量级在秒级完成；布尔碰撞 + 位姿枚举不做指数级穷举。
- **健壮性**：非法输入（空集合、非正 gap、非法角度）不崩溃，返回明确结果或抛带语义的异常。

## 7. 约束（Constraints）

- 技术栈：.NET 10 / Clipper2 2.0 / Avalonia 12。
- 单位：业务内部一律毫米（`GeometryConstants` 约定）。
- 不引入新第三方依赖（Clipper2 已存在；NFP 用 Clipper2 的 MinkowskiSum 而非新库）。
- 不改动现有 `Loop2D` / `PlacementValidator` 语义，只新增。

## 8. 验收标准（AC）

> 以「Given / When / Then」表述，均可写成单元测试。

### AC-1 位姿正确性
- **Given** 一个非对称裁片；**When** 以 90° 放置；**Then** 放置后轮廓面积与边长与 0° 一致，朝向差 90°。

### AC-2 无重叠
- **Given** 两个会重叠的位姿；**When** 用碰撞检测判定；**Then** 返回「重叠」。
- **Given** 两个仅边缘相切（重叠面积为 0）的位姿；**Then** 返回「不重叠」（相切合法）。

### AC-3 间隙达标
- **Given** 两个裁片边缘距离为 d；**When** 判定是否满足间隙 gap；**Then** d ≥ gap 合法，d < gap 不合法。

### AC-4 边界约束
- **Given** 一个部分越出材料边缘的位姿；**When** 判定；**Then** 返回「越界」，该位姿不可用。

### AC-5 0°/90° 枚举
- **Given** 一个非对称裁片；**When** 生成位姿候选；**Then** 产出恰好 {0°, 90°} 两种旋转候选。

### AC-6 无法装入
- **Given** 一个面积大于材料、或剩余空间无法容纳的裁片；**When** 排样；**Then** 该裁片进入 `unplaced`，不阻塞其余裁片。

### AC-7 利用率基线
- **Given** 与 Python 货架填充相同的输入（9 个鞋面 + 矩形料 + gap 5）；**When** 用 C# BLF 排样；**Then** 利用率 ≥ 货架填充基线（0°/180° 结果）。

### AC-8 可复现
- **Given** 相同输入运行两次；**When** 排样；**Then** 两次输出逐位姿一致。

### AC-9 边界输入
- 空裁片集合、单裁片、gap 为 0、gap 大于材料短边、允许角度为空——均不崩溃，行为符合预期。

## 9. 边界情况（Edge Cases）

1. **空输入**：裁片列表为空 → 返回空结果，利用率为 0，不抛异常。
2. **单裁片**：一个裁片直接放（若合法）。
3. **超大裁片**：任何位姿都放不下 → `unplaced`，不崩溃。
4. **gap = 0**：允许边缘相切，无额外膨胀。
5. **gap 大于材料短边**：明确报错或返回全 `unplaced`（二选一，实现时定，测试覆盖）。
6. **带洞裁片**（`LoopRole.Hole`）：碰撞/面积计算需正确处理洞（首版至少不因洞崩溃；洞参与面积扣除）。
7. **非矩形材料**：接口支持，首版只保证矩形材料下的正确性。
8. **允许角度为空**：报错（非法输入），而非静默按 0° 处理。

## 10. 范围外（Out of Scope）

- 自由角度旋转、镜像、part-in-part 嵌套（后续方向，接口预留）。
- 真皮瑕疵区、纹路/毛向约束。
- 订单数量配比、多材料批量排样调度。
- DXF / JSON 输出落盘（另立任务，消费 `NestResult`）。

## 11. 成功度量

- 阶段 A：BLF 结果合法（无重叠、间隙达标、全部在料内），可复现，利用率 ≥ Python 货架填充基线。
- 阶段 B：NFP + 遗传/局部搜索结果利用率 ≥ BLF 基线，且合法性无回归。
