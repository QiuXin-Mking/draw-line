# 银象界面证据与功能自洽模型

> 调研日期：2026-08-10  
> 用途：为 `prd.md`、`design.md` 和 `implement.md` 提供可追溯依据；本文不是银象软件说明书。  
> 结论：采用 clean-room 功能对标，只复现经过独立定义和验证的业务能力，不复制商标、图标、素材、文案、窗口排布或未知算法。

## 1. 调研方法

本轮采用三条相互独立的证据链：

1. **仓库一手材料**：银象操作录音转写、界面描述、待确认概念和竞品 DXF 样本。
2. **银象公开资料**：只用来确认设备级能力；未找到足以证明每个软件按钮行为的公开正式手册。
3. **行业官方资料**：用 Zünd、Comelz、Teseo、Lectra/Gerber、Autodesk 等官方页面验证工作流和 CAD 语义是否自洽。行业共性不能反推为银象已有功能。

证据等级：

- A：仓库录屏/截图可直接观察，或厂商官方文档直接陈述。
- B：两个以上独立官方行业资料共同支持，可作为产品设计依据。
- C：根据转写或单一资料推断，只能做可配置方案，不能写死。
- D：证据冲突或缺失，必须现场验证后才能进入生产验收。

## 2. 总体判断

专业排样软件的稳定主流程应为：

`项目/订单 → CAD 导入与诊断 → 裁片/尺码/数量 → 工艺特征 → 材料与排样约束 → 自动排样 → 人工微调 → 统一校验 → 导出/生产交接`

银象转写中的“订单管理、CAD 工具、开始排版、停止排版、取消排版”等可以证明用户入口存在，但不能据此把 CAD 导入、轮廓修复、码齿和排样做成一个混合窗口。规划应按领域状态拆分，同时保留工厂用户熟悉的简短工作流导航。

## 3. 已确认、可推导和待确认的边界

| 主题 | 结论 | 等级 | 规划处理 |
|---|---|---:|---|
| 顶层菜单和快捷入口 | 文件、编辑、操作、绘制、数据库、工具、设置、帮助，以及订单/CAD/排版快捷入口可从本地材料观察 | A | 作为功能清单线索，不复制视觉排布和文案 |
| CAD 导入 | 必须识别外轮廓、内线、孔、文字、图层、单位和开放路径 | A/B | 独立四步导入向导，生成诊断报告 |
| 轮廓修复 | 闭合、容差连接和从边界集生成轮廓是三个不同命令 | B | 分开建模，全部先预览再提交 |
| 内缩生成线 | 需要选择材料内/外、距离、拐角方式；可能产生 0 或多个结果 | A/B | 不直接暴露带符号距离；拓扑改变必须确认 |
| 节点和剪断 | 显示、插入、移动、删除节点及剪断是可确认能力 | A/B | 每次手势形成一条可撤销命令 |
| 普通剪口 | V/方/U/半圆/划线是工艺定位特征 | B | 保留语义实体，导出时展开几何/图层 |
| 码齿/马牙 | 银象界面存在码数、方向、宽高、间距、半码间距和牙型计数 | A | 建独立码齿规则和版本库，不与普通剪口共用 DTO |
| 码数和牙型计数 | 19.50、0.0–6.5、31–37 以及 10/5/1、1/1/1 互相不能解释 | D | 数据模型允许精确字符串/十进制键；现场确认前不推导公式 |
| 三种码齿模式 | 常规、使用库、自定义可观察，但默认值和互斥语义冲突 | C/D | 暂定义为当前参数、版本库规则、逐点编辑；需录屏确认 |
| 自动排样控制 | 行业资料支持持续优化、停止后保留最佳方案 | B | 建议“停止=保留当前最佳”，“取消=回滚运行前”；待产品确认 |
| `替换反` | 标签截断且功能未知 | D | 不实现、不猜测，列入现场验证 |
| 切割机交接 | 银象设备支持投影、送料、切割、进度；PC 软件协议未知 | A/D | MVP 只做经过约定的文件包导出；直连另立软硬件任务 |
| 视觉系统 | 银象官方说明为选配 | A | 不作为离线排样 MVP 的前置条件 |

## 4. 九个 UI 模块及功能合同

每个模块都必须定义前置条件、输入、动作、状态、输出和失败路径；“窗口能打开”不构成功能完成。

### U1 项目/订单中心

- **输入**：订单号、客户、款号、材料、尺码配比、左右件数量、交期、优先级。
- **动作**：新建、打开、复制、保存、另存为、恢复未保存版本、查看导出历史。
- **输出**：带版本号的项目文件；项目引用固定版本的裁片、规则库和算法配置。
- **状态**：草稿、输入待修复、可排样、排样中、有结果、已导出。
- **失败路径**：项目损坏、引用规则缺失、保存目录不可写、外部修改冲突；不得静默覆盖。

### U2 CAD 导入与诊断向导

- **步骤**：选择文件 → 确认单位/比例 → 查看识别结果 → 修复或确认。
- **识别项**：外环、孔、内线、文字、图层、开放路径、重复线、零长线、自交、不同 Z/OCS。
- **输出**：规范化裁片模型、原始文件指纹、导入报告和未解决问题列表。
- **失败路径**：单位未知时必须人工确认；存在阻断错误时禁止标记为“可排样”。
- **真实样本要求**：既支持 `凉鞋.dxf` 的闭合 `LWPOLYLINE`，也要诊断 38–45.DXF 的旧式开放 `POLYLINE`，不得丢弃后者。

### U3 裁片、尺码与订单明细

- **布局**：裁片缩略图/列表、当前裁片画布、属性表。
- **字段**：名称、尺码、左/右数量、已放/未放、材料、允许角度、镜像、纹向、质量等级、成组关系。
- **规则**：订单数量是排样需求的唯一来源；画布上的件数不能反向篡改订单。
- **失败路径**：重复裁片 ID、缺尺码、数量为负、左右件关系不完整、约束冲突。

### U4 CAD 修复与工艺编辑器

#### U4.1 轮廓诊断和生成

状态机：

`选择边界集 → 点选内部/选择候选 → 分析 → 彩色预览 → 校验 → 提交或取消`

- 绿色：沿用；橙色：新增桥接；红色：错误/冲突。
- “闭合”只补当前开放路径的首尾段。
- “连接/补缝”按容差连接端点，并明确 Extend、Trim 或 Add。
- “强制生成轮廓”从平面曲线图追踪候选闭环，不得用凸包或无条件取最大面积。
- 提交前必须满足 simple、closed、continuous、coplanar；孔洞要完全包含或完全分离。

#### U4.2 内缩/外扩

状态机：

`选择有效闭环 → 输入正距离和材料方向 → 选择圆/斜接/倒角 → 预览 → 确认拓扑变化 → 生成新线或替换`

- 界面显示原/结果面积、轮廓数量和最窄区域告警。
- “向内”按材料拓扑计算，不依赖输入 winding。
- 结果可能从 1 个轮廓变成 0 个或多个；默认保留源轮廓并生成语义图层。

#### U4.3 节点和剪断

- 显示、插入、移动、删除节点；单点剪断；两点去段。
- 插入点按曲线最近投影拆分，圆弧拆分后形状不变。
- MVP 删除节点只支持 polyline 直线重连；不足 3 个唯一点的闭环禁止删除。
- 变换后必须重映射工艺锚点；失败时标记为待修复 orphan，不能悄悄漂移。

#### U4.4 普通工艺剪口

- 流程：选轮廓锚点 → 显示切线和材料法线 → 选凹入/凸出材料 → 宽/深 → Cut/Mark → 预览 → 提交。
- 领域对象保留 `contourId`、弧长锚点、形状、宽深、材料方向、Cut/Mark、刀具/图层。
- 与角点过近、互相重叠、穿孔、深度超过局部材料或低于刀具能力时阻止或警告。

### U5 码齿规则与版本库

- **布局**：左侧库/版本，中间尺码行，右侧有序齿序列和裁片预览。
- **数据**：鞋码体系、精确尺码键、有序齿 token、宽高、齿间距、半码间距、起始锚点、方向、生效版本。
- **流程**：选择库版本 → 选择目标裁片/尺码/锚边 → 全尺码预览 → 校验缺码和冲突 → 生成派生裁片 → 锁定库版本。
- **版本规则**：修改库不能改变已生成订单；必须复制为新版本。计数只是快捷编辑方式，保存时转换为有序序列。
- **阻塞项**：码数含义、排列顺序、半码含义和“向外”几何方向未确认前，只允许实验性配置，不进入生产黄金样本。

### U6 材料和排样约束

- **MVP 材料**：矩形片材或卷材，宽、高/无限长、边距、裁片间距、纹向、允许旋转。
- **裁片规则**：允许角度、镜像、成组、固定/锁定、同形聚集、优先级。
- **参数呈现**：普通用户只见快速/均衡/精细、间距、边距、角度等业务参数；种群、变异等算法参数放在高级诊断中。
- **后续真皮**：不规则边界、缺陷、质量区和拉伸方向单独扩展，不能混入矩形料 MVP 验收。

### U7 排样运行控制

- **显示**：状态、耗时、当前最佳利用率、已放/未放、材料张数、进度或已评估方案数。
- **建议状态机**：`Ready → Running → Completed | StoppedWithBest | Cancelled | Failed`。
- **建议语义**：停止会请求算法安全终止并保留当前最佳完整方案；取消会丢弃本次临时结果并恢复运行前快照。
- **约束**：运行中锁定会改变输入的字段；后台计算不得阻塞 UI；失败不得写入半成品项目。

### U8 排样画布与人工微调

- **布局**：中央材料画布；左侧未放裁片/材料页；右侧选择属性和校验；底部显示利用率、坐标、角度、重叠和越界。
- **第一版动作**：选择/框选、拖动、定角旋转、镜像、贴边、锁定、成组、撤销/重做、仅排剩余、局部重排。
- **统一规则**：自动排样和手工编辑使用同一个碰撞/边界/间距/方向验证器，避免“画布能放但导出失败”。
- **失败路径**：禁止操作要解释具体规则；不能只用红色表达，需兼顾老显示器和色觉差异。

### U9 结果校验、导出和生产交接

- **阻断检查**：重叠、越界、间距、数量、未放件、禁止旋转/镜像、开放轮廓、工艺锚点失效。
- **结果摘要**：材料张数、利用率、废料率、未放件、耗时、输入指纹、规则/算法版本。
- **MVP 输出**：可继续编辑的项目文件、DXF、PNG、PDF 报告、CSV/JSON 数据。
- **生产交接**：先导出经过接收方验证的文件包；设备在线状态、刀具映射、队列、暂停/恢复、报警、补切必须另立软硬件集成任务。
- **失败路径**：取消导出不得留残文件；目录不可写、中文路径、磁盘满和接收方格式不支持均需明确错误。

## 5. 关键领域边界

1. DXF 适配层与领域模型分离。DXF 的线段不是业务对象；裁片、孔、普通剪口和码齿要有稳定 ID 与语义。
2. 普通剪口 `NotchFeature` 与尺码编码 `SizeToothRule` 分离，避免今后无法区分工艺定位和尺码标记。
3. 原始 CAD 永久保留；每次修复生成操作记录，可撤销、可重演、可审计。
4. 通用 DXF 可能无法完整保存业务语义；采用标准图层和几何保证兼容，同时用 sidecar JSON 或受控 XDATA 保存 feature ID、锚点和库版本。
5. Clipper2 可承担多边形布尔和偏移，但会离散曲线；必须定义 chord/Hausdorff 公差并用真实切割样件验证。

## 6. 必须现场确认的阻塞问题

在这些问题得到录屏、截图或输入/输出文件证明前，不得把答案写入生产规格：

1. “码数 19.50”、库中的 0.0–6.5 与实际 31–37 鞋码分别代表什么？
2. 方形、半圆、尖角和半码的数量如何决定有序排列、起点和方向？
3. 常规、使用库、自定义三种模式是否互斥，默认模式是什么，会覆盖哪些数据？
4. 码齿所说“向内/向外”是相对裁片材料、刀路，还是屏幕视觉法线？
5. “停止排版”是暂停、接受当前最佳结果，还是停止并清空？“取消排版”回滚到哪里？
6. `替换反` 的完整标签、前置条件、输入和结果是什么？
7. 银象软件原生项目格式、DXF 版本/图层规则、设备通信协议和断网行为是什么？
8. 真实切割机对最小齿宽/深、刀缝、圆弧公差和图层/刀具映射的限制是什么？

现场证据包至少包含：完整操作录屏（新建订单到发送切割）、关于页、全部菜单和弹窗、三类输入/输出 DXF、设备设置、图层/刀具映射、报警日志和一次断网测试。

## 7. 阶段测试母表

以下测试将在 `implement.md` 中按阶段分配固定 ID 和命令：

### 导入和轮廓

- 闭合矩形不变；gap=0.05、tol=0.1 可预览补缝，gap=0.11 拒绝。
- 多候选环必须由用户选择；T 形支路不进边界；bow-tie 自交报错；嵌套环识别孔。
- `LWPOLYLINE`、旧式 `POLYLINE`、ARC bulge、SPLINE、不同单位/Z/OCS 有明确结果或诊断。
- 导入→修复→导出→重载后，环数、面积、方向和最大几何误差符合公差。

### 偏移、节点和剪断

- 100×50 矩形向内 1 得到 98×48；外环缩而孔扩大；反转 winding 后材料空间结果相同。
- 凹 L、尖角、圆角、细颈 1→2、小岛 1→0 均有确定预览和告警。
- 在线/圆弧插点前后形状在公差内不变；移动导致自交时结果不可切割。
- 开放/闭合路径剪断长度守恒；撤销恢复相同业务模型；语义锚点可重映射或明确失效。

### 剪口和码齿

- 水平、垂直、圆弧、外环、孔、镜像和反 winding 的材料侧一致。
- 宽 2、深 0.8 的黄金几何，以及 0、负数、NaN、超大值、重叠、穿孔等异常。
- Cut 与 Mark 输出不同图层/工具语义；重载后 feature 可恢复。
- 半码键精确排序；重复码、缺码、非法计数、序列过长、版本迁移均有明确结果。
- 修改码齿库后旧任务重开仍复现原输出。

### 排样和 UI

- 开始后冲突参数禁用；停止保留当前最佳完整结果；取消恢复运行前快照。
- 超时、无解、算法异常和低性能 Windows 下 UI 仍可响应，项目不会半写。
- 拖动/旋转/镜像/锁定/局部重排与统一验证器一致；缩放后命中准确。
- 未放件和阻断错误禁止导出；导出取消无残文件；中文路径和不可写目录有明确反馈。
- Windows 10 LTSC 2019/2021、Windows 11 和 macOS 执行安装、启动、导入、排样、导出冒烟测试。

## 9. 置信度与缺口

- **高置信**：行业主流程、CAD 轮廓/偏移/节点的语义边界、自动结果需要人工校验和导出前统一验证。
- **中高置信**：九个 UI 模块及其依赖顺序，来自多个官方系统交叉验证。
- **中置信**：建议的停止/取消语义和码齿版本库模型；逻辑自洽，但仍需用户/现场确认。
- **低置信**：银象码数、牙型排列、半码、`替换反`、设备协议和刀具参数；不能靠现有材料补齐。
