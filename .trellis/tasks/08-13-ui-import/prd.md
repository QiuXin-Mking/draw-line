# UI M02 导入诊断

## Goal

实现 DXF 导入与诊断页，包装现有真实导入、单位确认和取消能力。

## Requirements

- 只拥有 `Modules/Import/` 与对应测试目录。
- 显示步骤、单位、图层/实体统计、诊断等级与定位入口。
- 自动修复、批量映射、多文件和非 DXF 均为 TODO。

## Acceptance Criteria

- [ ] 现有选择、检查、毫米确认、取消能力仍可执行。
- [ ] 未确认单位不能显示为可排样。
- [ ] 所有未接入能力有 TODO 文本。
